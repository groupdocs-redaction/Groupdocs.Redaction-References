## TextRedaction class

Representa una clase abstracta base para redacciones de texto de documentos.

Aprende más

- More details about applying redactions: https://docs.groupdocs.com/redaction/net/redaction-basics/
- More details about document text redactions: https://docs.groupdocs.com/redaction/net/text-redactions/

| [apply_to_document_format_instance](/redaction/python-net/groupdocs.redaction/redaction/apply_to_document_format_instance/) | (heredado de [`Redaction`](/redaction/python-net/groupdocs.redaction/redaction/)) |

| Propiedad | Descripción |
