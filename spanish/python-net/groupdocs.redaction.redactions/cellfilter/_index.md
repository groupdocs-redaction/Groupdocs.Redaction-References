## CellFilter class

Proporciona una opción para limitar el alcance de un [`CellColumnRedaction`](/redaction/python-net/groupdocs.redaction.redactions/cellcolumnredaction/) a una hoja de cálculo y una columna.

Aprende más

- More details about spreadsheet redactions: https://docs.groupdocs.com/redaction/net/spreadsheet-redactions/

El tipo CellFilter expone los siguientes miembros:

### Constructores
| Constructor | Descripción |
| :- | :- |
| [__init__](/redaction/python-net/groupdocs.redaction.redactions/cellfilter/__init__/) | Inicializa una nueva instancia de CellFilter. |

### Propiedades
| Propiedad | Descripción |
| :- | :- |
| [column_index](/redaction/python-net/groupdocs.redaction.redactions/cellfilter/column_index/) | El índice de columna basado en cero. |
| [has_work_sheet_index](/redaction/python-net/groupdocs.redaction.redactions/cellfilter/has_work_sheet_index/) | La propiedad indica si el WorkSheetIndex está establecido. |
| [work_sheet_index](/redaction/python-net/groupdocs.redaction.redactions/cellfilter/work_sheet_index/) | El índice de la hoja de cálculo (basado en cero). |
| [work_sheet_name](/redaction/python-net/groupdocs.redaction.redactions/cellfilter/work_sheet_name/) | El nombre de la hoja de cálculo, si corresponde. |

### Campos
| Campo | Descripción |
| :- | :- |
| [NO_INDEX](/redaction/python-net/groupdocs.redaction.redactions/cellfilter/no_index/) | Representa un valor predeterminado para el filtro, que es -1. |
