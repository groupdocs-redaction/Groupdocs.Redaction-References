## IOcrConnector class

Representa un conector que proporciona los métodos necesarios para aplicar redacciones textuales a documentos de imagen e imágenes incrustadas.

- An example of implementation using Aspose.OCR for Cloud: https://docs.groupdocs.com/redaction/net/use-aspose-ocr-for-cloud/
