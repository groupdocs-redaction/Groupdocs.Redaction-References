## IAnnotatedDocument class

Define los métodos necesarios para acceder a anotaciones, como comentarios, y debe ser implementado por una clase derivada de [`DocumentFormatInstance`](/redaction/python-net/groupdocs.redaction.integration/documentformatinstance/) para realizar redactados de anotaciones.

Más información:
- More details about applying redactions: https://docs.groupdocs.com/redaction/net/redaction-basics/
- More details about document annotation redactions: https://docs.groupdocs.com/redaction/net/annotation-redactions/
- More details about implementing custom formats: https://docs.groupdocs.com/redaction/net/create-custom-format-handler/

El tipo IAnnotatedDocument expone los siguientes miembros:

| Método | Descripción |
| :- | :- |
| [delete_annotations](/redaction/python-net/groupdocs.redaction.integration/iannotateddocument/delete_annotations/#regular_expression) | Elimina todas las anotaciones que coinciden con la expresión regular dentro del documento. |
| [delete_annotations_regex](/redaction/python-net/groupdocs.redaction.integration/iannotateddocument/delete_annotations_regex/) |  |
| [redact_annotation](/redaction/python-net/groupdocs.redaction.integration/iannotateddocument/redact_annotation/#regular_expression-replacement) | Reemplaza el texto coincidente en todas las anotaciones dentro del documento. |
