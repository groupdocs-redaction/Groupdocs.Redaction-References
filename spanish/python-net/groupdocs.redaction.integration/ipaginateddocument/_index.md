## IPaginatedDocument class

Define los métodos necesarios para manipular las páginas de un documento. Debe ser implementado por una clase derivada de [`DocumentFormatInstance`](/redaction/python-net/groupdocs.redaction.integration/documentformatinstance/) para realizar redactados de páginas.

- More details about applying redactions: https://docs.groupdocs.com/redaction/net/redaction-basics/
- More details about manipulating pages: https://docs.groupdocs.com/redaction/net/remove-page-redaction/

El tipo IPaginatedDocument expone los siguientes miembros:

### Métodos
| Método | Descripción |
| :- | :- |
| [remove_pages](/redaction/python-net/groupdocs.redaction.integration/ipaginateddocument/remove_pages/#origin-index-count) | Elimina una o varias páginas según su posición inicial, desplazamiento y cantidad. |
| [remove_pages_page_seek_origin](/redaction/python-net/groupdocs.redaction.integration/ipaginateddocument/remove_pages_page_seek_origin/) |  |
