## DocumentInfo class

Representa información sobre un documento.

Más información:

- Get file info: https://docs.groupdocs.com/redaction/net/get-file-info/

El tipo DocumentInfo expone los siguientes miembros:

### Propiedades
| Propiedad | Descripción |
| :- | :- |
| [file_type](/redaction/python-net/groupdocs.redaction/documentinfo/file_type/) | La descripción del formato de archivo. |
| [page_count](/redaction/python-net/groupdocs.redaction/documentinfo/page_count/) | El recuento total de páginas. |
| [pages](/redaction/python-net/groupdocs.redaction/documentinfo/pages/) | La lista de información de página [`PageInfo`](/redaction/python-net/groupdocs.redaction/pageinfo/). |
| [size](/redaction/python-net/groupdocs.redaction/documentinfo/size/) | El tamaño del documento en bytes. |
