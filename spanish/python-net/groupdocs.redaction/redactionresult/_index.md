## RedactionResult class

Representa un resultado de la operación de redacción.

Aprende más

- More details about redaction results: https://docs.groupdocs.com/redaction/net/redaction-basics/

El tipo RedactionResult expone los siguientes miembros:

### Métodos
| Método | Descripción |
| :- | :- |
| [failed](/redaction/python-net/groupdocs.redaction/redactionresult/failed/#description) | Inicializa una nueva instancia de RedactionResult con un estado fallido. |
| [partial](/redaction/python-net/groupdocs.redaction/redactionresult/partial/#description) | Crea una nueva instancia de [`RedactionResult`](/redaction/python-net/groupdocs.redaction/redactionresult/) con un estado parcialmente aplicado. |
| [skipped](/redaction/python-net/groupdocs.redaction/redactionresult/skipped/#description) | Inicializa una nueva instancia de la clase RedactionResult con estado Omitido. |
| [successful](/redaction/python-net/groupdocs.redaction/redactionresult/successful/) | Inicializa una nueva instancia de RedactionResult con un estado aplicado (exitoso). |

### Propiedades
| Propiedad | Descripción |
| :- | :- |
| [error_message](/redaction/python-net/groupdocs.redaction/redactionresult/error_message/) | El mensaje de error para diagnóstico. |
| [status](/redaction/python-net/groupdocs.redaction/redactionresult/status/) | El estado de ejecución. |
