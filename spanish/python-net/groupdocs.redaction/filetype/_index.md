## FileType class

Representa un tipo de archivo.

Más información:
- https://docs.groupdocs.com/redaction/net/supported-document-formats/
- https://docs.groupdocs.com/redaction/net/get-supported-file-formats/
- https://docs.groupdocs.com/redaction/net/get-file-info/

El tipo FileType expone los siguientes miembros:

### Métodos
| Método | Descripción |
| :- | :- |
| [equals](/redaction/python-net/groupdocs.redaction/filetype/equals/#other) | Determina si el FileType actual es el mismo que el objeto FileType especificado. |
| [equals](/redaction/python-net/groupdocs.redaction/filetype/equals/#obj) | Determina si el [`FileType`](/redaction/python-net/groupdocs.redaction/filetype/) actual es el mismo que el objeto especificado. |
| [equals_file_type](/redaction/python-net/groupdocs.redaction/filetype/equals_file_type/) |  |
| [equals_object](/redaction/python-net/groupdocs.redaction/filetype/equals_object/) |  |
| [from_extension](/redaction/python-net/groupdocs.redaction/filetype/from_extension/#extension) | Mapea la extensión de archivo al tipo de archivo. |
| [get_hash_code](/redaction/python-net/groupdocs.redaction/filetype/get_hash_code/) | Devuelve el código hash para el objeto [`FileType`](/redaction/python-net/groupdocs.redaction/filetype/) actual. |
| [get_supported_file_types](/redaction/python-net/groupdocs.redaction/filetype/get_supported_file_types/) | Recupera los tipos de archivo compatibles. |
| [to_string](/redaction/python-net/groupdocs.redaction/filetype/to_string/) | Devuelve una cadena que representa el objeto actual. |

### Propiedades
| Propiedad | Descripción |
| :- | :- |
| [extension](/redaction/python-net/groupdocs.redaction/filetype/extension/) | El sufijo del nombre de archivo, incluyendo el punto inicial, p. ej., \".doc\". |
| [file_format](/redaction/python-net/groupdocs.redaction/filetype/file_format/) | El nombre del formato de archivo, por ejemplo \"Microsoft Word Document\". |
