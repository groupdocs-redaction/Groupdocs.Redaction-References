## TextRedaction class

문서 텍스트 편집을 위한 기본 추상 클래스를 나타냅니다.

자세히 알아보기

- More details about applying redactions: https://docs.groupdocs.com/redaction/net/redaction-basics/
- More details about document text redactions: https://docs.groupdocs.com/redaction/net/text-redactions/

TextRedaction 형식은 다음 멤버를 노출합니다:

### 메서드
| 메서드 | 설명 |
| :- | :- |
| [apply_to](/redaction/python-net/groupdocs.redaction/redaction/apply_to/) | 주어진 포맷 인스턴스에 레드랙션을 적용합니다. ([`Redaction`](/redaction/python-net/groupdocs.redaction/redaction/)에서 상속됨) |
| [apply_to_document_format_instance](/redaction/python-net/groupdocs.redaction/redaction/apply_to_document_format_instance/) | ([`Redaction`](/redaction/python-net/groupdocs.redaction/redaction/)에서 상속됨) |

### 속성
| 속성 | 설명 |
| :- | :- |
| [action_options](/redaction/python-net/groupdocs.redaction.redactions/textredaction/action_options/) | [`ReplacementOptions`](/redaction/python-net/groupdocs.redaction.redactions/replacementoptions/) 인스턴스는 텍스트 교체 유형을 지정합니다. |
| [ocr_connector](/redaction/python-net/groupdocs.redaction.redactions/textredaction/ocr_connector/) | 그래픽 콘텐츠에서 텍스트를 추출하는 데 사용되는 IOcrConnector 구현체. |
| [description](/redaction/python-net/groupdocs.redaction/redaction/description/) | 레드랙션에 대한 설명으로, 이름과 매개변수를 포함합니다. ([`Redaction`](/redaction/python-net/groupdocs.redaction/redaction/)에서 상속됨) |
