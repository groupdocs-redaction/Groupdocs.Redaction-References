최상위 API 클래스를 포함하는 주요 GroupDocs.Redaction 네임스페이스.

### 클래스
| 클래스 | 설명 |
| :- | :- |
| [`DocumentInfo`](/redaction/python-net/groupdocs.redaction/documentinfo/) | 문서에 대한 정보를 나타냅니다. |
| [`FileType`](/redaction/python-net/groupdocs.redaction/filetype/) | 파일 유형을 나타냅니다. |
| [`IDocumentInfo`](/redaction/python-net/groupdocs.redaction/idocumentinfo/) | 기본 문서 정보를 가져오는 데 필요한 메서드를 제공합니다. |

| [`PageInfo`](/redaction/python-net/groupdocs.redaction/pageinfo/) | 간략한 페이지 정보를 나타냅니다. |
| [`Redaction`](/redaction/python-net/groupdocs.redaction/redaction/) | 모든 삭제 유형에 대한 기본 추상 클래스를 나타냅니다. |
| [`RedactionPolicy`](/redaction/python-net/groupdocs.redaction/redactionpolicy/) | 적용할 특정 삭제 집합을 포함하는 정화 정책을 나타냅니다. |
| [`RedactionResult`](/redaction/python-net/groupdocs.redaction/redactionresult/) | 삭제 작업의 결과를 나타냅니다. |
| [`Redactor`](/redaction/python-net/groupdocs.redaction/redactor/) | 문서 삭제 프로세스를 제어하고 문서를 열고, 삭제하고, 저장할 수 있는 주요 클래스를 나타냅니다. |
| [`RedactorChangeLog`](/redaction/python-net/groupdocs.redaction/redactorchangelog/) | `Redactor.apply()` 메서드에 전달된 삭제 목록에 대한 결과를 나타냅니다. |
| [`RedactorLogEntry`](/redaction/python-net/groupdocs.redaction/redactorlogentry/) | 레드액션 적용 결과를 나타냅니다. |
