| 속성 | 설명 |
| :- | :- |
| [extension](/redaction/python-net/groupdocs.redaction/filetype/extension/) | 파일 이름 접미사이며, 앞에 오는 점을 포함합니다. 예: ".doc". |
| [file_format](/redaction/python-net/groupdocs.redaction/filetype/file_format/) | 파일 형식 이름, 예: "Microsoft Word Document". |
