## RedactionResult class

삭제 작업의 결과를 나타냅니다.

자세히 알아보기

- More details about redaction results: https://docs.groupdocs.com/redaction/net/redaction-basics/

RedactionResult 유형은 다음 멤버를 노출합니다:

### 메서드
| 메서드 | 설명 |
| :- | :- |
| [failed](/redaction/python-net/groupdocs.redaction/redactionresult/failed/#description) | 실패 상태로 새로운 RedactionResult 인스턴스를 초기화합니다. |
| [partial](/redaction/python-net/groupdocs.redaction/redactionresult/partial/#description) | 부분 적용된 상태로 새로운 [`RedactionResult`](/redaction/python-net/groupdocs.redaction/redactionresult/) 인스턴스를 생성합니다. |
| [skipped](/redaction/python-net/groupdocs.redaction/redactionresult/skipped/#description) | Skipped 상태로 RedactionResult 클래스의 새로운 인스턴스를 초기화합니다. |
| [successful](/redaction/python-net/groupdocs.redaction/redactionresult/successful/) | 적용된(성공적인) 상태로 RedactionResult의 새로운 인스턴스를 초기화합니다. |

### 속성
| 속성 | 설명 |
| :- | :- |
| [error_message](/redaction/python-net/groupdocs.redaction/redactionresult/error_message/) | 진단을 위한 오류 메시지. |
| [status](/redaction/python-net/groupdocs.redaction/redactionresult/status/) | 실행 상태. |
