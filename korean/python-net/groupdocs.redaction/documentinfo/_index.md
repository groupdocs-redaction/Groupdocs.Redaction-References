## DocumentInfo class

문서에 대한 정보를 나타냅니다.

자세히 보기:

- Get file info: https://docs.groupdocs.com/redaction/net/get-file-info/

DocumentInfo 형식은 다음 멤버를 노출합니다:

### 속성
| 속성 | 설명 |
| :- | :- |
| [file_type](/redaction/python-net/groupdocs.redaction/documentinfo/file_type/) | 파일 형식 설명입니다. |
| [page_count](/redaction/python-net/groupdocs.redaction/documentinfo/page_count/) | 전체 페이지 수입니다. |
| [pages](/redaction/python-net/groupdocs.redaction/documentinfo/pages/) | 다음은 [`PageInfo`](/redaction/python-net/groupdocs.redaction/pageinfo/) 페이지 정보 목록입니다. |
| [size](/redaction/python-net/groupdocs.redaction/documentinfo/size/) | 문서 크기(바이트)입니다. |
