## RedactionStatus class

RedactionStatus 유형은 다음 멤버를 노출합니다:

### 필드
| 필드 | 설명 |
| :- | :- |
| [APPLIED](/redaction/python-net/groupdocs.redaction/redactionstatus/applied/) | Redaction이 완전하고 성공적으로 적용되었습니다. |
| [PARTIALLY_APPLIED](/redaction/python-net/groupdocs.redaction/redactionstatus/partially_applied/) | Redaction이 일치 항목 중 일부에만 적용되었습니다. |
| [SKIPPED](/redaction/python-net/groupdocs.redaction/redactionstatus/skipped/) | Redaction이 건너뛰어졌습니다(적용되지 않음). |
| [FAILED](/redaction/python-net/groupdocs.redaction/redactionstatus/failed/) | Redaction이 예외와 함께 실패했습니다. |
