## replace_text {#regular_expression-options}

```python
def replace_text(self, regular_expression, options):
    ...
```

| 매개변수 | 유형 | 설명 |
| :- | :- | :- |
| regular_expression | `System.Text.RegularExpressions.Regex` | 검색 및 교체를 위한 정규식. |
| options | `ReplacementOptions` | 편집 차단에 대한 텍스트 교체 또는 색상을 설정할 수 있습니다. |

**Returns:** Text replacement result.
