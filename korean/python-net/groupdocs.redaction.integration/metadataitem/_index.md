## MetadataItem class

지원되는 모든 형식에 공통이며 메타데이터 삭제에 사용되는 메타데이터 항목을 나타냅니다.

MetadataItem 형식은 다음 멤버를 노출합니다:

| :- | :- |
| [__init__](/redaction/python-net/groupdocs.redaction.integration/metadataitem/__init__/) | 새 인스턴스를 초기화합니다. |

| 메서드 | 설명 |

| [get_object_data](/redaction/python-net/groupdocs.redaction.integration/metadataitem/get_object_data/#info-context) | 직렬화 가능한 속성에 대한 정보를 반환합니다. |

| 속성 | 설명 |
| :- | :- |

| [category](/redaction/python-net/groupdocs.redaction.integration/metadataitem/category/) | 메타데이터 항목의 카테고리이며, 예를 들어 포함된 리소스 메타데이터 항목의 리소스 ID가 있습니다. |
| [dictionary_key](/redaction/python-net/groupdocs.redaction.integration/metadataitem/dictionary_key/) | [`MetadataCollection`](/redaction/python-net/groupdocs.redaction.integration/metadatacollection/)에 대한 사전 키는 OriginalName 및 기타 데이터에서 파생됩니다. |
