Redaction 네임스페이스는 PDF, 래스터 이미지 및 오피스 문서 형식의 문서에서 민감한 정보를 가리는 클래스를 제공합니다. 이 네임스페이스의 주요 클래스는 다음과 같습니다:

## 클래스

| 클래스 | 설명 |
| --- | --- |
| [DocumentInfo](./documentinfo) | 문서에 대한 정보를 나타냅니다. IDocumentInfo 인터페이스를 구현합니다. 예제는 [`IDocumentInfo`](../groupdocs.redaction/idocumentinfo)를 참조하십시오. |
| [FileType](./filetype) | 파일 형식을 나타냅니다. GroupDocs.Redaction에서 지원하는 모든 파일 형식 목록을 가져오고, 확장자를 통해 파일 형식을 감지하는 등의 메서드를 제공합니다. |
| [License](./license) | 라이선스를 적용하기 위한 메서드를 제공합니다. |
| [Metered](./metered) | Metered 라이선스로 제품을 활성화하고 처리된 MB 양을 검색할 수 있는 메서드를 제공합니다. Metered 라이선스에 대해 자세히 알아보려면 [여기](https://purchase.groupdocs.com/faqs/licensing/metered)를 방문하세요. |
| [PageInfo](./pageinfo) | 간략한 페이지 정보를 나타냅니다. |
| [Redaction](./redaction) | 모든 리다크션 유형에 대한 기본 추상 클래스를 나타냅니다. |
| [RedactionPolicy](./redactionpolicy) | 적용할 특정 리다크션 집합을 포함하는 정화 정책을 나타냅니다. |
| [RedactionResult](./redactionresult) | 리다크션 작업의 결과를 나타냅니다. |
| [Redactor](./redactor) | 문서 리다크션 프로세스를 제어하는 주요 클래스를 나타내며, 문서를 열고, 리다크션하고, 저장할 수 있게 합니다. |
| [RedactorChangeLog](./redactorchangelog) | Apply() 메서드에 전달되는 리다크션 목록에 대한 결과를 [`Redactor`](../groupdocs.redaction/redactor) 클래스가 나타냅니다. |
| [RedactorLogEntry](./redactorlogentry) | 리다크션 적용 결과를 나타냅니다. |
