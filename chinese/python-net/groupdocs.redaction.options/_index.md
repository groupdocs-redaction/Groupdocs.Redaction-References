用于配置转换和操作的选项类。

### 类
| 类 | 描述 |
| :- | :- |
| [`CreatePageStream`](/redaction/python-net/groupdocs.redaction.options/createpagestream/) | 表示一个返回用于写入页面预览数据的流的方法。 |
| [`ILogger`](/redaction/python-net/groupdocs.redaction.options/ilogger/) | 定义用于在编辑过程中记录事件和错误的日志记录器接口。 |
| [`LoadOptions`](/redaction/python-net/groupdocs.redaction.options/loadoptions/) | 提供用于打开文件的选项。 |
| [`PreviewOptions`](/redaction/python-net/groupdocs.redaction.options/previewoptions/) | 提供设置预览生成的需求和流委托的选项。 |
| [`RasterizationOptions`](/redaction/python-net/groupdocs.redaction.options/rasterizationoptions/) | 提供将文件转换为 PDF 的选项。 |
| [`RedactorSettings`](/redaction/python-net/groupdocs.redaction.options/redactorsettings/) | 表示编辑设置，允许自定义编辑过程。 |
| [`ReleasePageStream`](/redaction/python-net/groupdocs.redaction.options/releasepagestream/) | 表示一个释放由[`CreatePageStream`](/redaction/python-net/groupdocs.redaction.options/createpagestream/)委托创建的流的方法。 |
| [`SaveOptions`](/redaction/python-net/groupdocs.redaction.options/saveoptions/) | 提供更改输出文件名和/或将文档转换为基于图像的 PDF（光栅化）的选项。 |
