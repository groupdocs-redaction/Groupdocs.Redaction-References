Redaction 命名空间提供用于从 PDF、光栅图像和办公文档格式的文档中编辑（遮蔽）敏感信息的类。该命名空间中的主要类包括：

## 类

| 类 | 描述 |
| --- | --- |
| [DocumentInfo](./documentinfo) | 表示有关文档的信息。实现 IDocumentInfo 接口。请参阅[`IDocumentInfo`](../groupdocs.redaction/idocumentinfo) 获取示例。 |
| [FileType](./filetype) | 表示一种文件类型。提供获取 GroupDocs.Redaction 支持的所有文件类型列表、通过扩展名检测文件类型等方法。 |
| [License](./license) | 提供用于应用许可证的方法。 |
| [Metered](./metered) | 提供允许使用计量许可证激活产品并检索已处理 MB 数量的方法。了解有关计量许可证的更多信息[此处](https://purchase.groupdocs.com/faqs/licensing/metered)。 |
| [PageInfo](./pageinfo) | 表示简要的页面信息。 |
| [Redaction](./redaction) | 表示所有编辑类型的基础抽象类。 |
| [RedactionPolicy](./redactionpolicy) | 表示消毒策略，包含一组要应用的特定编辑。 |
| [RedactionResult](./redactionresult) | 表示编辑操作的结果。 |
| [Redactor](./redactor) | 表示控制文档编辑过程的主类，允许打开、编辑和保存文档。 |
| [RedactorChangeLog](./redactorchangelog) | 表示传递给 [`Redactor`](../groupdocs.redaction/redactor) 类的 Apply() 方法的编辑列表的结果。 |
| [RedactorLogEntry](./redactorlogentry) | 表示应用编辑的结果。 |
