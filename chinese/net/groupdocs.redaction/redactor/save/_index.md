## Save(SaveOptions) {#save_1}

将文档保存到文件。

```csharp
public string Save(SaveOptions saveOptions)
```

| 参数 | 类型 | 描述 |
| --- | --- | --- |
| saveOptions | SaveOptions | 添加后缀或光栅化的选项 |

### 返回值

已编辑文档的路径

### 示例

以下示例演示如何使用 SaveOptions 保存文档。

```csharp
    using (Redactor redactor = new Redactor(@"C:\sample.pdf"))
    {
       // 文档脱敏在此处
       // ...
    
       // 使用默认选项保存文档（将页面转换为图像，保存为 PDF）
       redactor.Save();
    
       // 以原始格式保存文档，覆盖原文件
       redactor.Save(new SaveOptions() { AddSuffix = false, RasterizeToPDF = false });
    
       // 以原始格式将文档保存为 "*_Redacted.*" 文件
       redactor.Save(new SaveOptions() { AddSuffix = true, RasterizeToPDF = false });
    
       // 在文件名中不进行光栅化，将文档保存为 "*_AnyText.*"（例如将 "AnyText" 替换为时间戳）
       redactor.Save(new SaveOptions(false, "AnyText"));
    }    
```
