## RedactorConfiguration.FindFormat method

指定されたファイル拡張子に対する形式構成を検索します。

```csharp
public DocumentFormatConfiguration FindFormat(string fileExtension)
```

| パラメータ | 型 | 説明 |
| --- | --- | --- |
| fileExtension | String | ファイル拡張子、形式は ".ext" です |

### 戻り値

見つかった場合は [`DocumentFormatConfiguration`](../../documentformatconfiguration) のインスタンス、見つからない場合は null

### 例

```csharp

var formatSettings = configuration.FindFormat(".psd");
```
