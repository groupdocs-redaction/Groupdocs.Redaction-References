Integration 名前空間は、さまざまな形式のドキュメントを GroupDocs.Redaction と統合するために使用されるインターフェイスとクラスを提供します。

## クラス

| クラス | 説明 |
| --- | --- |
| [DocumentFormatInstance](./documentformatinstance) | ドキュメントの特定の形式を表します。このクラスを実装して、独自のドキュメントタイプを追加します。 |
| [MetadataCollection](./metadatacollection) | タイトルをキーとした [`MetadataItem`](../groupdocs.redaction.integration/metadataitem) の辞書を表します。 |
| [MetadataItem](./metadataitem) | すべてのサポート対象形式で共通のメタデータ項目を表し、メタデータのマスク処理で使用されます。 |
## インターフェイス

| インターフェイス | 説明 |
| --- | --- |
| [IAnnotatedDocument](./iannotateddocument) | コメントなどのアノテーションにアクセスするために必要なメソッドを定義します。アノテーションのマスク処理を実行するために、[`DocumentFormatInstance`](../groupdocs.redaction.integration/documentformatinstance) 派生クラスで実装する必要があります。 |
| [ICellularFormatInstance](./icellularformatinstance) | 1 つまたは複数のワークシートを持つスプレッドシート形式にアクセスするために必要なメソッドを定義します。 |
| [IFixedFormatDocument](./ifixedformatdocument) | PDFやプレゼンテーションなど、固定構造のアクセス形式に必要なメソッドを定義します。 |
| [IImageFormatInstance](./iimageformatinstance) | ラスター画像形式の編集に必要なメソッドを定義します。 |
| [IMetadataAccess](./imetadataaccess) | 形式がサポートしている場合、ドキュメントのメタデータへのアクセスに必要なメソッドを定義します。 |
| [IPaginatedDocument](./ipaginateddocument) | ドキュメントのページを操作するために必要なメソッドを定義します。ページの編集を実行するには、[`DocumentFormatInstance`](../groupdocs.redaction.integration/documentformatinstance)から派生したクラスで実装する必要があります。 |
| [IPreviewable](./ipreviewable) | ドキュメントのプレビューを作成するメソッドを定義します。 |
| [IRasterizableDocument](./irasterizabledocument) | 任意のバイナリ形式でドキュメントを保存するために必要なメソッドを定義します。組み込みタイプは、ページの画像を含む PDF としてドキュメントを保存します。 |
| [ITextualFormatInstance](./itextualformatinstance) | テキストを含む任意のドキュメントのテキストデータを編集するために必要なメソッドを定義します。 |
