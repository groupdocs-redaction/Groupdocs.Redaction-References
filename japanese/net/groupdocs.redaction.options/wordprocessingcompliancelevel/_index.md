## WordProcessingComplianceLevel enumeration

ワードプロセッシング ドキュメント向けにサポートされている OOXML コンプライアンス レベルを表します。Strict レベルは Transitional へはダウングレードできますが、Ecma へはダウングレードできません。

```csharp
public enum WordProcessingComplianceLevel
```

### 値

| 名前 | 値 | 説明 |
| --- | --- | --- |
| Ecma | `0` | ECMA-376 第1版（2006年）準拠レベルを指定します。 |
| Transitional | `1` | ISO/IEC 2950:2008 Transitional 準拠レベルを指定します。 |
| Strict | `2` | ISO/IEC 29500:2008 Strict コンプライアンスレベルを指定します。 |
