Ocr 名前空間は、光学文字認識（OCR）サポートに必要なインターフェイスとクラスを提供します。

## クラス

| クラス | 説明 |
| --- | --- |
| [RecognizedImage](./recognizedimage) | 画像から認識プロセスの結果として抽出されたテキストを表します。 |
| [TextFragment](./textfragment) | OCR エンジンによって抽出された、認識されたテキスト（単語、記号など）の一部を表します。 |
| [TextLine](./textline) | OCR エンジンが画像から抽出したテキスト行を表します。 |
## インターフェイス

| インターフェイス | 説明 |
| --- | --- |
| [IOcrConnector](./iocrconnector) | 画像ドキュメントや埋め込み画像にテキスト赤字を適用するために必要なメソッドを定義します。 |
