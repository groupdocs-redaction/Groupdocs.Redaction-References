Redaction 名前空間は、PDF、ラスタ画像、オフィス文書形式のドキュメントから機密情報をマスクするためのクラスを提供します。この名前空間の主なクラスは次のとおりです：

## クラス

| クラス | 説明 |
| --- | --- |
| [DocumentInfo](./documentinfo) | ドキュメントに関する情報を表します。IDocumentInfo インターフェイスを実装しています。例については [`IDocumentInfo`](../groupdocs.redaction/idocumentinfo) を参照してください。 |
| [FileType](./filetype) | ファイルタイプを表します。GroupDocs.Redaction がサポートするすべてのファイルタイプの一覧を取得したり、拡張子でファイルタイプを検出したりするメソッドを提供します。 |
| [License](./license) | ライセンスを適用するためのメソッドを提供します。 |
| [Metered](./metered) | Metered ライセンスで製品をアクティブ化し、処理された MB 数を取得できるメソッドを提供します。Metered ライセンスの詳細は[こちら](https://purchase.groupdocs.com/faqs/licensing/metered)をご覧ください。 |
| [PageInfo](./pageinfo) | 簡潔なページ情報を表します。 |
| [Redaction](./redaction) | すべての赤字タイプの基底抽象クラスを表します。 |
| [RedactionPolicy](./redactionpolicy) | 適用すべき特定の赤字のセットを含むサニタイズポリシーを表します。 |
| [RedactionResult](./redactionresult) | 赤字操作の結果を表します。 |
| [Redactor](./redactor) | ドキュメントの赤字プロセスを制御し、開く、赤字化、保存を可能にするメインクラスを表します。 |
| [RedactorChangeLog](./redactorchangelog) | [`Redactor`](../groupdocs.redaction/redactor) クラスの Apply() メソッドに渡される赤字リストの結果を表します。 |
| [RedactorLogEntry](./redactorlogentry) | 赤字適用の結果を表します。 |
