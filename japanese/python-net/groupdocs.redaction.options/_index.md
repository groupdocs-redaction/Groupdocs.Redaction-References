変換と操作を構成するためのオプション クラス。

### クラス
| クラス | 説明 |
| :- | :- |
| [`CreatePageStream`](/redaction/python-net/groupdocs.redaction.options/createpagestream/) | ページプレビュー データを書き込むためのストリームを返すメソッドを表します。 |
| [`ILogger`](/redaction/python-net/groupdocs.redaction.options/ilogger/) | 編集中のイベントやエラーを記録するために使用されるロガーのインターフェイスを定義します。 |
| [`LoadOptions`](/redaction/python-net/groupdocs.redaction.options/loadoptions/) | ファイルを開く際に使用されるオプションを提供します。 |
| [`PreviewOptions`](/redaction/python-net/groupdocs.redaction.options/previewoptions/) | プレビュー生成のための要件とストリーム デリゲートを設定するオプションを提供します。 |
| [`RasterizationOptions`](/redaction/python-net/groupdocs.redaction.options/rasterizationoptions/) | ファイルを PDF に変換するためのオプションを提供します。 |
| [`RedactorSettings`](/redaction/python-net/groupdocs.redaction.options/redactorsettings/) | 編集設定を表し、編集プロセスをカスタマイズできるようにします。 |
| [`ReleasePageStream`](/redaction/python-net/groupdocs.redaction.options/releasepagestream/) | [`CreatePageStream`](/redaction/python-net/groupdocs.redaction.options/createpagestream/) デリゲートによって作成されたストリームを解放するメソッドを表します。 |
| [`SaveOptions`](/redaction/python-net/groupdocs.redaction.options/saveoptions/) | 出力ファイル名の変更や、ドキュメントを画像ベースの PDF（ラスタライズ）に変換するためのオプションを提供します。 |
