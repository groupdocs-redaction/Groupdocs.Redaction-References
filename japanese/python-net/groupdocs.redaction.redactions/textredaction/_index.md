## TextRedaction class

ドキュメントテキスト赤字のための基底抽象クラスを表します。

詳細を見る

- More details about applying redactions: https://docs.groupdocs.com/redaction/net/redaction-basics/
- More details about document text redactions: https://docs.groupdocs.com/redaction/net/text-redactions/

TextRedaction 型は次のメンバーを公開します:

### メソッド
| メソッド | 説明 |
| :- | :- |
| [apply_to](/redaction/python-net/groupdocs.redaction/redaction/apply_to/) | 指定されたフォーマットインスタンスに対してリダクションを適用します。( [`Redaction`](/redaction/python-net/groupdocs.redaction/redaction/) から継承) |
| [apply_to_document_format_instance](/redaction/python-net/groupdocs.redaction/redaction/apply_to_document_format_instance/) | ( [`Redaction`](/redaction/python-net/groupdocs.redaction/redaction/) から継承) |

### プロパティ
| プロパティ | 説明 |
| :- | :- |
| [action_options](/redaction/python-net/groupdocs.redaction.redactions/textredaction/action_options/) | テキスト置換のタイプを指定する [`ReplacementOptions`](/redaction/python-net/groupdocs.redaction.redactions/replacementoptions/) インスタンスです。 |
| [ocr_connector](/redaction/python-net/groupdocs.redaction.redactions/textredaction/ocr_connector/) | グラフィックコンテンツからテキストを抽出するために使用される IOcrConnector 実装です。 |
| [description](/redaction/python-net/groupdocs.redaction/redaction/description/) | リダクションの説明で、名前とパラメータを含みます。( [`Redaction`](/redaction/python-net/groupdocs.redaction/redaction/) から継承) |
