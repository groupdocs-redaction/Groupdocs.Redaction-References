## MetadataRedaction class

ドキュメントメタデータの赤字処理のための基底抽象クラスを表します。

詳細を見る

- More details about document metadata redactions: https://docs.groupdocs.com/redaction/net/metadata-redactions/

MetadataRedaction タイプは次のメンバーを公開します：

### メソッド
| メソッド | 説明 |
| :- | :- |
| [apply_to](/redaction/python-net/groupdocs.redaction.redactions/metadataredaction/apply_to/#format_instance) | 指定されたフォーマット インスタンスに対してリダクションを適用します。 |
| [apply_to_document_format_instance](/redaction/python-net/groupdocs.redaction.redactions/metadataredaction/apply_to_document_format_instance/) |  |

| プロパティ | 説明 |
| :- | :- |
| [filter](/redaction/python-net/groupdocs.redaction.redactions/metadataredaction/filter/) | Author や Company など、すべてまたは特定のメタデータを選択するために使用されるフィルター。 |
| [description](/redaction/python-net/groupdocs.redaction/redaction/description/) | リダクションの説明で、名前とパラメータを含みます。( [`Redaction`](/redaction/python-net/groupdocs.redaction/redaction/) から継承) |
