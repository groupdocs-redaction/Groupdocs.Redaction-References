`groupdocs.redaction.integration` の型。

### クラス
| クラス | 説明 |
| :- | :- |
| [`DocumentFormatInstance`](/redaction/python-net/groupdocs.redaction.integration/documentformatinstance/) | ドキュメントの特定のフォーマットを表し、カスタム ドキュメント タイプを追加するために実装できます。 |
| [`IAnnotatedDocument`](/redaction/python-net/groupdocs.redaction.integration/iannotateddocument/) | コメントなどのアノテーションにアクセスするために必要なメソッドを定義し、アノテーションの編集を実行するために [`DocumentFormatInstance`](/redaction/python-net/groupdocs.redaction.integration/documentformatinstance/)-派生クラスで実装する必要があります。 |
| [`ICellularFormatInstance`](/redaction/python-net/groupdocs.redaction.integration/icellularformatinstance/) | 1 つまたは複数のワークシートを含むスプレッドシート形式にアクセスするために必要なメソッドを定義します。 |
| [`IFixedFormatDocument`](/redaction/python-net/groupdocs.redaction.integration/ifixedformatdocument/) | PDF やプレゼンテーションなど、固定構造のフォーマットにアクセスするために必要なメソッドを定義します。 |
| [`IImageFormatInstance`](/redaction/python-net/groupdocs.redaction.integration/iimageformatinstance/) | ラスタ画像フォーマットの編集に必要なメソッドを定義します。 |
| [`IMetadataAccess`](/redaction/python-net/groupdocs.redaction.integration/imetadataaccess/) | フォーマットがサポートしている場合、ドキュメントのメタデータにアクセスするために必要なメソッドを定義します。 |
| [`IPaginatedDocument`](/redaction/python-net/groupdocs.redaction.integration/ipaginateddocument/) | ドキュメントのページを操作するために必要なメソッドを定義します。ページの編集を実行するには [`DocumentFormatInstance`](/redaction/python-net/groupdocs.redaction.integration/documentformatinstance/)-派生クラスで実装する必要があります。 |
| [`IPreviewable`](/redaction/python-net/groupdocs.redaction.integration/ipreviewable/) | ドキュメントのプレビューを作成するためのメソッドを定義します。 |
| [`IRasterizableDocument`](/redaction/python-net/groupdocs.redaction.integration/irasterizabledocument/) | 任意のバイナリ形式でドキュメントを保存するために必要なメソッドを定義します。組み込み型はページの画像を含む PDF としてドキュメントを保存します。 |
| [`ITextualFormatInstance`](/redaction/python-net/groupdocs.redaction.integration/itextualformatinstance/) | テキストを含む任意のドキュメントのテキストデータを編集するために必要なメソッドを定義するインターフェイスを表します。 |
| [`MetadataCollection`](/redaction/python-net/groupdocs.redaction.integration/metadatacollection/) | タイトルをキーとする[`MetadataItem`](/redaction/python-net/groupdocs.redaction.integration/metadataitem/) の辞書を表します。 |
| [`MetadataItem`](/redaction/python-net/groupdocs.redaction.integration/metadataitem/) | すべてのサポートされている形式で共通のメタデータ項目を表し、メタデータの編集に使用されます。 |
