## MetadataItem class

すべてのサポートされている形式で共通のメタデータ項目を表し、メタデータの編集に使用されます。

MetadataItem 型は次のメンバーを公開します:

### コンストラクター
| コンストラクター | 説明 |
| :- | :- |
| [__init__](/redaction/python-net/groupdocs.redaction.integration/metadataitem/__init__/) | 新しいインスタンスを初期化します。 |

### メソッド
| メソッド | 説明 |
| :- | :- |
| [create_clone](/redaction/python-net/groupdocs.redaction.integration/metadataitem/create_clone/) | 現在のインスタンスのディープクローンを作成します。 |
| [get_object_data](/redaction/python-net/groupdocs.redaction.integration/metadataitem/get_object_data/#info-context) | シリアライズ可能なプロパティに関する情報を返します。 |
| [get_object_data_serialization_info](/redaction/python-net/groupdocs.redaction.integration/metadataitem/get_object_data_serialization_info/) |  |

### プロパティ
| プロパティ | 説明 |
| :- | :- |
| [actual_value](/redaction/python-net/groupdocs.redaction.integration/metadataitem/actual_value/) | メタデータ項目の値の文字列表現です。 |
| [category](/redaction/python-net/groupdocs.redaction.integration/metadataitem/category/) | メタデータ項目のカテゴリです。たとえば、埋め込みリソースのメタデータ項目のリソース ID などです。 |
| [dictionary_key](/redaction/python-net/groupdocs.redaction.integration/metadataitem/dictionary_key/) | `[`MetadataCollection`](/redaction/python-net/groupdocs.redaction.integration/metadatacollection/) の辞書キーで、OriginalName などのデータから派生します。 |
| [filter](/redaction/python-net/groupdocs.redaction.integration/metadataitem/filter/) | このメタデータ項目に割り当てられたフィルターで、`MetadataFilters` 値で表され、項目のフィルタリングに使用されます。 |
| [is_custom](/redaction/python-net/groupdocs.redaction.integration/metadataitem/is_custom/) | この項目はカスタムです（ドキュメントの作成者によって追加されました）。 |
| [original_name](/redaction/python-net/groupdocs.redaction.integration/metadataitem/original_name/) | メタデータ項目の元の名前（ドキュメントに表示される通り）。 |
| [values](/redaction/python-net/groupdocs.redaction.integration/metadataitem/values/) | メタデータ項目の値。 |
