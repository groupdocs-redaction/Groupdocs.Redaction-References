## IRasterizableDocument class

任意のバイナリ形式でドキュメントを保存するために必要なメソッドを定義します。組み込み型はページの画像を含む PDF としてドキュメントを保存します。

詳細を見る

- More details about applying redactions: https://docs.groupdocs.com/redaction/net/redaction-basics/
- More details about saving document as a rasterized PDF: https://docs.groupdocs.com/redaction/net/save-in-rasterized-pdf/
- More details about rasterization options: https://docs.groupdocs.com/redaction/net/select-specific-pages-for-rasterized-pdf/
- More details about implementing custom formats: https://docs.groupdocs.com/redaction/net/create-custom-format-handler/

IRasterizableDocument 型は次のメンバーを公開します:

| [rasterize](/redaction/python-net/groupdocs.redaction.integration/irasterizabledocument/rasterize/#output) | ドキュメントを PDF としてストリームに保存します。 |
| [rasterize](/redaction/python-net/groupdocs.redaction.integration/irasterizabledocument/rasterize/#output-options) | ページ範囲と準拠オプションを指定して、ドキュメントを PDF としてストリームに保存します。 |
