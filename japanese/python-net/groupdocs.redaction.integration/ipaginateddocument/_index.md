## IPaginatedDocument class

ドキュメントのページを操作するために必要なメソッドを定義します。ページの編集を実行するには [`DocumentFormatInstance`](/redaction/python-net/groupdocs.redaction.integration/documentformatinstance/)-派生クラスで実装する必要があります。

- More details about applying redactions: https://docs.groupdocs.com/redaction/net/redaction-basics/
- More details about manipulating pages: https://docs.groupdocs.com/redaction/net/remove-page-redaction/

IPaginatedDocument 型は次のメンバーを公開します:

### メソッド
| メソッド | 説明 |
| :- | :- |
| [remove_pages](/redaction/python-net/groupdocs.redaction.integration/ipaginateddocument/remove_pages/#origin-index-count) | 開始位置、オフセット、カウントに応じて、1ページまたは複数ページを削除します。 |
| [remove_pages_page_seek_origin](/redaction/python-net/groupdocs.redaction.integration/ipaginateddocument/remove_pages_page_seek_origin/) |  |
