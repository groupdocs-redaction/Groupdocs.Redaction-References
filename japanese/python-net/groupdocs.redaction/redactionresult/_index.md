## RedactionResult class

編集操作の結果を表します。

詳細を見る

- More details about redaction results: https://docs.groupdocs.com/redaction/net/redaction-basics/

RedactionResult 型は次のメンバーを公開します:

### メソッド
| メソッド | 説明 |
| :- | :- |
| [failed](/redaction/python-net/groupdocs.redaction/redactionresult/failed/#description) | 失敗ステータスで新しい RedactionResult インスタンスを初期化します。 |
| [partial](/redaction/python-net/groupdocs.redaction/redactionresult/partial/#description) | 部分的に適用されたステータスで新しい [`RedactionResult`](/redaction/python-net/groupdocs.redaction/redactionresult/) インスタンスを作成します。 |
| [skipped](/redaction/python-net/groupdocs.redaction/redactionresult/skipped/#description) | スキップされたステータスで RedactionResult クラスの新しいインスタンスを初期化します。 |
| [successful](/redaction/python-net/groupdocs.redaction/redactionresult/successful/) | 適用（成功）ステータスで RedactionResult の新しいインスタンスを初期化します。 |

### プロパティ
| プロパティ | 説明 |
| :- | :- |
| [error_message](/redaction/python-net/groupdocs.redaction/redactionresult/error_message/) | 診断用のエラーメッセージです。 |
| [status](/redaction/python-net/groupdocs.redaction/redactionresult/status/) | 実行ステータスです。 |
