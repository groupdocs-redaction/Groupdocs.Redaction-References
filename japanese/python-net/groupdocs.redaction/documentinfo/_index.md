## DocumentInfo class

ドキュメントに関する情報を表します。

詳しく読む：

- Get file info: https://docs.groupdocs.com/redaction/net/get-file-info/

DocumentInfo 型は次のメンバーを公開します：

### プロパティ
| プロパティ | 説明 |
| :- | :- |
| [file_type](/redaction/python-net/groupdocs.redaction/documentinfo/file_type/) | ファイル形式の説明です。 |
| [page_count](/redaction/python-net/groupdocs.redaction/documentinfo/page_count/) | 総ページ数です。 |
| [pages](/redaction/python-net/groupdocs.redaction/documentinfo/pages/) | [`PageInfo`](/redaction/python-net/groupdocs.redaction/pageinfo/) ページ情報のリストです。 |
| [size](/redaction/python-net/groupdocs.redaction/documentinfo/size/) | ドキュメントのサイズ（バイト単位）です。 |
