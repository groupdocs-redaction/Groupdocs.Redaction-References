## RedactionStatus class

RedactionStatus 型は次のメンバーを公開します:

### フィールド
| フィールド | 説明 |
| :- | :- |
| [APPLIED](/redaction/python-net/groupdocs.redaction/redactionstatus/applied/) | Redaction は完全にかつ成功裏に適用されました。 |
| [PARTIALLY_APPLIED](/redaction/python-net/groupdocs.redaction/redactionstatus/partially_applied/) | Redaction は一致の一部にのみ適用されました。 |
| [SKIPPED](/redaction/python-net/groupdocs.redaction/redactionstatus/skipped/) | Redaction はスキップされました（適用されません）。 |
| [FAILED](/redaction/python-net/groupdocs.redaction/redactionstatus/failed/) | Redaction は例外により失敗しました。 |
