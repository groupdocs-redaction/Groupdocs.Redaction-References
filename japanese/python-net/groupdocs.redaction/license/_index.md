## License class

GroupDocs.Redaction のライセンスを管理します。

ライセンス認証されたビルドは、ラッパーの完全な機能セットを
ランタイムで利用できます。未ライセンスのビルドは、同じ API を使用した評価モードで実行されます。
ただし、出力サイズと透かし付きコンテンツに制限があります。

License 型は次のメンバーを公開します：

### メソッド
| メソッド | 説明 |
| :- | :- |
| [set_license](/redaction/python-net/groupdocs.redaction/license/set_license/#license_source) | 現在のプロセスにライセンスを適用します。 |
