GroupDocs.Redaction のメイン名前空間で、トップレベルの API クラスが含まれます。

### クラス
| クラス | 説明 |
| :- | :- |
| [`DocumentInfo`](/redaction/python-net/groupdocs.redaction/documentinfo/) | ドキュメントに関する情報を表します。 |
| [`FileType`](/redaction/python-net/groupdocs.redaction/filetype/) | ファイルタイプを表します。 |
| [`IDocumentInfo`](/redaction/python-net/groupdocs.redaction/idocumentinfo/) | 基本的なドキュメント情報を取得するために必要なメソッドを提供します。 |
| [`License`](/redaction/python-net/groupdocs.redaction/license/) | GroupDocs.Redaction のライセンスを管理します。 |
| [`Metered`](/redaction/python-net/groupdocs.redaction/metered/) | 従量課金（使用量に応じた支払い）ライセンスを管理します。 |
| [`PageInfo`](/redaction/python-net/groupdocs.redaction/pageinfo/) | 簡潔なページ情報を表します。 |
| [`Redaction`](/redaction/python-net/groupdocs.redaction/redaction/) | すべての編集タイプの基底抽象クラスを表します。 |
| [`RedactionPolicy`](/redaction/python-net/groupdocs.redaction/redactionpolicy/) | 適用する特定の編集セットを含むサニタイズ ポリシーを表します。 |
| [`RedactionResult`](/redaction/python-net/groupdocs.redaction/redactionresult/) | 編集操作の結果を表します。 |
| [`Redactor`](/redaction/python-net/groupdocs.redaction/redactor/) | ドキュメントの編集プロセスを制御し、開く、編集する、保存することを可能にするメイン クラスを表します。 |
| [`RedactorChangeLog`](/redaction/python-net/groupdocs.redaction/redactorchangelog/) | `Redactor.apply()` メソッドに渡された編集リストの結果を表します。 |
| [`RedactorLogEntry`](/redaction/python-net/groupdocs.redaction/redactorlogentry/) | レダクション適用の結果を表します。 |
