## FileType class

ファイルタイプを表します。

詳しく読む：
- https://docs.groupdocs.com/redaction/net/supported-document-formats/
- https://docs.groupdocs.com/redaction/net/get-supported-file-formats/
- https://docs.groupdocs.com/redaction/net/get-file-info/

FileType 型は次のメンバーを公開します:

### メソッド
| メソッド | 説明 |
| :- | :- |
| [equals](/redaction/python-net/groupdocs.redaction/filetype/equals/#other) | 現在の FileType が指定された FileType オブジェクトと同じかどうかを判断します。 |
| [equals](/redaction/python-net/groupdocs.redaction/filetype/equals/#obj) | 現在の [`FileType`](/redaction/python-net/groupdocs.redaction/filetype/) が指定されたオブジェクトと同じかどうかを判断します。 |
| [equals_file_type](/redaction/python-net/groupdocs.redaction/filetype/equals_file_type/) |  |
| [equals_object](/redaction/python-net/groupdocs.redaction/filetype/equals_object/) |  |
| [from_extension](/redaction/python-net/groupdocs.redaction/filetype/from_extension/#extension) | ファイル拡張子をファイルタイプにマッピングします。 |
| [get_hash_code](/redaction/python-net/groupdocs.redaction/filetype/get_hash_code/) | 現在の [`FileType`](/redaction/python-net/groupdocs.redaction/filetype/) オブジェクトのハッシュコードを返します。 |
| [get_supported_file_types](/redaction/python-net/groupdocs.redaction/filetype/get_supported_file_types/) | サポートされているファイルタイプを取得します。 |
| [to_string](/redaction/python-net/groupdocs.redaction/filetype/to_string/) | 現在のオブジェクトを表す文字列を返します。 |

### プロパティ
| プロパティ | 説明 |
| :- | :- |
| [extension](/redaction/python-net/groupdocs.redaction/filetype/extension/) | 先頭のピリオドを含むファイル名のサフィックス、例: ".doc"。 |
| [file_format](/redaction/python-net/groupdocs.redaction/filetype/file_format/) | ファイル形式名、例: "Microsoft Word Document"。 |
