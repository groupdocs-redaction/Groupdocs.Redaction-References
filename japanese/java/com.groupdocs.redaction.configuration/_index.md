このパッケージは、文書形式設定クラスを提供します。



## クラス

| クラス | 説明 |
| --- | --- |
| [DocumentFormatConfiguration](../com.groupdocs.redaction.configuration/documentformatconfiguration) | DocumentFormatInstance 派生クラスの型参照と、より高速な形式検出のためのサポートされるファイル拡張子リストを表します。 |
| [RedactorConfiguration](../com.groupdocs.redaction.configuration/redactorconfiguration) | 組み込みおよびカスタムユーザー形式を含む、サポートされる形式のリストへのアクセスを提供します。 |
