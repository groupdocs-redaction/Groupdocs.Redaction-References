このパッケージは、さまざまな例外クラスを提供します。



## クラス

| クラス | 説明 |
| --- | --- |
| [DocumentFormatException](../com.groupdocs.redaction.exceptions/documentformatexception) | ドキュメント形式が認識されない、または無効な場合にスローされる例外です。 |
| [GroupDocsRedactionException](../com.groupdocs.redaction.exceptions/groupdocsredactionexception) | すべての GroupDocs.Redaction 例外の基本例外を表します。 |
| [IncorrectPasswordException](../com.groupdocs.redaction.exceptions/incorrectpasswordexception) | 指定されたパスワードが正しくない場合にスローされる例外です。 |
| [PasswordRequiredException](../com.groupdocs.redaction.exceptions/passwordrequiredexception) | ドキュメントのロードにパスワードが必要な場合にスローされる例外です。 |
| [TrialLimitationsException](../com.groupdocs.redaction.exceptions/triallimitationsexception) | ユーザーがトライアルモードの制限に違反した場合にスローされる例外です。 |
