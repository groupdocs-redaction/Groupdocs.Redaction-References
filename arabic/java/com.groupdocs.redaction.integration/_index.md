توفر الحزمة الواجهات والفئات، المستخدمة لدمج المستندات بصيغ مختلفة مع GroupDocs.Redactions.



## الفئات

| الفئة | الوصف |
| --- | --- |
| [DocumentFormatInstance](../com.groupdocs.redaction.integration/documentformatinstance) | يمثل تنسيقًا محددًا للمستند. |
| [MetadataCollection](../com.groupdocs.redaction.integration/metadatacollection) | يمثل قاموسًا من MetadataItem بعنوانه كمفتاح. |
| [MetadataItem](../com.groupdocs.redaction.integration/metadataitem) | يمثل عنصرًا من البيانات الوصفية، شائعًا لجميع الصيغ المدعومة ويُستخدم في تعديل البيانات الوصفية. |
| [RecognizedImage](../com.groupdocs.redaction.integration/recognizedimage) | يمثل النص المستخرج من صورة نتيجة عملية التعرف عليها. |
| [RedactableImage](../com.groupdocs.redaction.integration/redactableimage) | يوفر واجهة لجميع عمليات تعديل الصور النقطية. |
| [TextFragment](../com.groupdocs.redaction.integration/textfragment) | يمثل جزءًا من النص المُعترف به (كلمة، رمز، إلخ)، مستخرجًا بواسطة محرك OCR. |
| [TextLine](../com.groupdocs.redaction.integration/textline) | يمثل سطرًا من النص، مستخرجًا بواسطة محرك OCR من صورة. |

## الواجهات

| الواجهة | الوصف |
| --- | --- |
| [IAnnotatedDocument](../com.groupdocs.redaction.integration/iannotateddocument) | يحدد الطرق المطلوبة للوصول إلى التعليقات التوضيحية، مثل التعليقات. |
| [ICellularFormatInstance](../com.groupdocs.redaction.integration/icellularformatinstance) | يحدد الطرق المطلوبة للوصول إلى صيغ الجداول الإلكترونية التي تحتوي على ورقة عمل واحدة أو متعددة. |
| [IFixedFormatDocument](../com.groupdocs.redaction.integration/ifixedformatdocument) | يحدد الطرق المطلوبة للوصول إلى صيغ ذات بنية ثابتة، مثل PDF أو العروض التقديمية. |
| [IImageFormatInstance](../com.groupdocs.redaction.integration/iimageformatinstance) | يحدد الطرق المطلوبة لتعديل صيغ الصور النقطية. |
| [IMetadataAccess](../com.groupdocs.redaction.integration/imetadataaccess) | يحدد الطرق المطلوبة للوصول إلى البيانات الوصفية لمستند، إذا كانت الصيغة تدعم ذلك. |
| [IMultipleAreaRedactable](../com.groupdocs.redaction.integration/imultiplearearedactable) | يحدد الطرق المطلوبة لتعديل مناطق متعددة في الصورة مرة واحدة بنفس اللون. |
| [IOcrConnector](../com.groupdocs.redaction.integration/iocrconnector) | يحدد الطرق المطلوبة لتطبيق تعديلات نصية على مستندات الصور والصور المدمجة. |
| [IPaginatedDocument](../com.groupdocs.redaction.integration/ipaginateddocument) | يحدد الطرق المطلوبة للتعامل مع صفحات المستند. |
| [IPreviewable](../com.groupdocs.redaction.integration/ipreviewable) | يحدد الطرق لإنشاء معاينة للمستند. |
| [IRasterizableDocument](../com.groupdocs.redaction.integration/irasterizabledocument) | يحدد الطرق المطلوبة لحفظ المستند بأي صيغة ثنائية. |
| [ITextualFormatInstance](../com.groupdocs.redaction.integration/itextualformatinstance) | يحدد الطرق المطلوبة لتعديل البيانات النصية في أي مستند يحتوي على نص. |
