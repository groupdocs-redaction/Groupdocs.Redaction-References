توفر الحزمة فئات لحذف المعلومات الحساسة من المستندات بصيغ PDF، الصورة النقطية، وصيغ مستندات المكتب.

الفئات الرئيسية في هذه الحزمة هي:

<br />

* [Redactor](../../com.groupdocs.redaction/redactor) is the entry point for redaction process.
* [Redaction](../../com.groupdocs.redaction/redaction) is abstract base class for all types of document redactions.
* [RedactionPolicy](../../com.groupdocs.redaction/redactionpolicy) is pre-configured in XML set of redaction rules.
* [RedactorChangeLog](../../com.groupdocs.redaction/redactorchangelog) provides information about redaction process results.

<br />




## الفئات

| الفئة | الوصف |
| --- | --- |
| [DocumentInfo](../com.groupdocs.redaction/documentinfo) | يمثل معلومات عن المستند. |
| [FileType](../com.groupdocs.redaction/filetype) | يمثل نوع ملف. |
| [PageInfo](../com.groupdocs.redaction/pageinfo) | يمثل معلومات صفحة مختصرة. |
| [Redaction](../com.groupdocs.redaction/redaction) | يمثل الفئة الأساسية المجردة لجميع أنواع التمويه. |
| [RedactionPolicy](../com.groupdocs.redaction/redactionpolicy) | يمثل سياسة التطهير، تحتوي على مجموعة من عمليات التمويه المحددة لتطبيقها. |
| [RedactionResult](../com.groupdocs.redaction/redactionresult) | يمثل نتيجة عملية التمويه. |
| [Redactor](../com.groupdocs.redaction/redactor) | يمثل الفئة الرئيسية التي تتحكم في عملية تمويه المستند، وتسمح بفتح، تمويه وحفظ المستندات. |
| [RedactorChangeLog](../com.groupdocs.redaction/redactorchangelog) | يمثل النتائج لقائمة من عمليات التمويه، التي تُمرّر إلى طريقة Apply() في فئة Redactor. |
| [RedactorLogEntry](../com.groupdocs.redaction/redactorlogentry) | يمثل نتائج تطبيق التمويه. |
