### أمثلة

المثال التالي يوضح كيفية استبدال الاسم "John" بـ "[redacted]" في جميع التعليقات التوضيحية.

```csharp
using (Redactor redactor = new Redactor(@"C:\test.pdf"))
{
   redactor.Apply(new AnnotationRedaction("(?im:john)", "[redacted]"));
   redactor.Save()
}
```
