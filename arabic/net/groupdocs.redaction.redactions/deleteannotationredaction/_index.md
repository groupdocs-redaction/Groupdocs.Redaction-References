### أمثلة

يوضح المثال التالي كيفية إزالة جميع التعليقات التوضيحية التي تحتوي على الكلمات "use" و "show" أو "describe" من المستند (مع إبقاء الأخرى).

```csharp
using (Redactor redactor = new Redactor(@"D:\test.docx"))
{
   redactor.Apply(new DeleteAnnotationRedaction("(?im:(use|show|describe))"));
   redactor.Save()
}
```
