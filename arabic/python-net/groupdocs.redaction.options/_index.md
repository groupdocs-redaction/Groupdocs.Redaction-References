فئات الخيارات لتكوين التحويلات والعمليات.

### الفئات
| الفئة | الوصف |
| :- | :- |
| [`CreatePageStream`](/redaction/python-net/groupdocs.redaction.options/createpagestream/) | يمثل طريقة تُعيد تدفقًا لكتابة بيانات معاينة الصفحة. |
| [`ILogger`](/redaction/python-net/groupdocs.redaction.options/ilogger/) | يُعرّف واجهة لمُسجِّل تُستخدم لتسجيل الأحداث والأخطاء أثناء الإخفاء. |
| [`LoadOptions`](/redaction/python-net/groupdocs.redaction.options/loadoptions/) | يوفر خيارات سيتم استخدامها لفتح ملف. |
| [`PreviewOptions`](/redaction/python-net/groupdocs.redaction.options/previewoptions/) | يوفر خيارات لتعيين المتطلبات ومندوبات التدفق لإنشاء المعاينات. |
| [`RasterizationOptions`](/redaction/python-net/groupdocs.redaction.options/rasterizationoptions/) | يوفر خيارات لتحويل الملفات إلى PDF. |
| [`RedactorSettings`](/redaction/python-net/groupdocs.redaction.options/redactorsettings/) | يمثل إعدادات الإخفاء، مما يسمح بتخصيص عملية الإخفاء. |
| [`ReleasePageStream`](/redaction/python-net/groupdocs.redaction.options/releasepagestream/) | يمثل طريقة تُفرج عن تدفق تم إنشاؤه بواسطة المندوب [`CreatePageStream`](/redaction/python-net/groupdocs.redaction.options/createpagestream/). |
| [`SaveOptions`](/redaction/python-net/groupdocs.redaction.options/saveoptions/) | يوفر خيارات لتغيير اسم ملف الإخراج و/أو تحويل المستند إلى PDF قائم على الصور (التصوير النقطي). |
