يقوم GroupDocs.Redaction for Python عبر .NET بإزالة أو إخفاء المعلومات الحساسة بشكل دائم عبر مجموعة واسعة من [supported document formats](). يتبع كل إخفاء نفس سير العمل: افتح مستندًا باستخدام [`Redactor`](/redaction/python-net/groupdocs.redaction/redactor/)، طبّق إخفاءً أو أكثر باستخدام `apply()`، ثم `save()` النتيجة المنقاة إما بصيغتها الأصلية أو كملف PDF مُنقّى. يمكن دمج القدرات أدناه بحرية في تمريرة واحدة.

## Text redaction

ابحث واستبدل النص بعبارة دقيقة أو بتعبير نمطي، مع تغطية كل الكلمات الكاملة والأنماط المعقدة مثل عناوين البريد الإلكتروني، أرقام الهواتف، أو أرقام الهوية الوطنية. يمكن استبدال النص المطابق بنص بديل أو تغطيته بمربع ملون بحيث لا يمكن استعادة المحتوى الأصلي. في جداول البيانات يمكنك تضييق البحث إلى ورقة عمل واحدة أو عمود. راجع [Text Redactions]().

## Metadata redaction

امسح أو أعد كتابة بيانات التعريف للوثيقة — المؤلف، العنوان، الشركة، التعليقات، وبيانات EXIF على الصور — بحيث لا تتسرب أي تفاصيل حساسة عبر خصائص الوثيقة. يمكنك مسح جميع بيانات التعريف، استهداف حقول معينة، أو استبدال القيم بأخرى جديدة. راجع [Metadata Redactions]().

## Image-area redaction

قم بتغطية منطقة مستطيلة من صورة مدمجة أو صفحة ممسوحة ضوئياً برسم مربع مملوء فوق المنطقة المحددة — مفيد لإخفاء التوقيعات، الصور، الرؤوس، أو التذييلات حيث من المتوقع ظهور بيانات سرية. راجع [Image Redactions]().

## Annotation redaction

أعد كتابة أو احذف التعليقات التوضيحية، التعليقات، والملاحظات. يمكنك إزالة كل التعليقات التوضيحية أو استخدام تعبير نمطي لمطابقة فقط تلك التي تحتوي على نص حساس. راجع [Annotation Redactions]().

## Page removal

أزل صفحات كاملة من مستندات PDF، شرائح من العروض التقديمية، وأوراق عمل من جداول البيانات. تحدد صفحة البداية والعدد، مع الاتجاه بالنسبة لنقطة البداية. راجع [Remove Page Redactions]().

## Rasterization to PDF

احفظ الوثيقة المنقاة كملف PDF تُعرض صفحاته كصور نقطية. الملف الناتج لا يحتوي على نص قابل للبحث ولا أي من بيانات التعريف الأصلية، لذا لا يمكن استعادة المحتوى المحذوف. التحويل إلى نقطية هو الخيار الصحيح عندما تحتاج إلى تسليم الوثيقة لأطراف ثالثة أو الامتثال للأنظمة التي تتطلب PDF. يمكنك اختيار صفحات محددة وطلب توافق PDF/A عبر خيارات التحويل المتقدمة. راجع [Save in Rasterized PDF]() و[Advanced Rasterization Options]().

## Redaction policies

اجمع عدة عمليات تنقيح في سياسة قابلة لإعادة الاستخدام وطبق نفس مجموعة القواعد بشكل ثابت عبر العديد من الوثائق — مثالي للمهام المتكررة مثل مسح مجموعة قياسية من الحقول قبل النشر. راجع [Use Redaction Policies]().

## Loading and saving

حمّل الوثائق من مسار محلي أو من تدفق، بما في ذلك الملفات المحمية بكلمة مرور، واختياريًا قم بتحويل الوثيقة إلى نقطية قبل التنقيح. عند الحفظ، احتفظ بالتنسيق الأصلي لمزيد من التحرير، أو استبدل الملف الأصلي، أو حوله إلى PDF نقطي، أو اكتب إلى تدفق. راجع [Loading Documents]() و[Saving Documents]().

## On-premise

GroupDocs.Redaction for Python via .NET يعمل بالكامل على بنيتك التحتية الخاصة — لا تغادر وثائقك بيئتك. الحزمة هي عجلة مستقلة تضم كل ما تحتاجه، لذا لا يلزم تثبيت Microsoft Office أو OpenOffice أو Adobe Acrobat أو أي بيئة تشغيل منفصلة. راجع [System Requirements]() للمنصات المدعومة والاعتمادات الأصلية.
