मुख्य GroupDocs.Redaction नेमस्पेस जिसमें शीर्ष-स्तर के API क्लासेस हैं।

### क्लासेस
| क्लास | विवरण |
| :- | :- |
| [`DocumentInfo`](/redaction/python-net/groupdocs.redaction/documentinfo/) | दस्तावेज़ के बारे में जानकारी को दर्शाता है। |
| [`FileType`](/redaction/python-net/groupdocs.redaction/filetype/) | फ़ाइल प्रकार को दर्शाता है। |
| [`IDocumentInfo`](/redaction/python-net/groupdocs.redaction/idocumentinfo/) | बुनियादी दस्तावेज़ जानकारी प्राप्त करने के लिए आवश्यक मेथड्स प्रदान करता है। |
| [`License`](/redaction/python-net/groupdocs.redaction/license/) | GroupDocs.Redaction लाइसेंसिंग को प्रबंधित करता है। |
| [`Metered`](/redaction/python-net/groupdocs.redaction/metered/) | मीटरड (पे‑पर‑यूज़) लाइसेंसिंग को प्रबंधित करता है। |
| [`PageInfo`](/redaction/python-net/groupdocs.redaction/pageinfo/) | संक्षिप्त पेज जानकारी को दर्शाता है। |
| [`Redaction`](/redaction/python-net/groupdocs.redaction/redaction/) | सभी रेडैक्शन प्रकारों के लिए बेस एब्स्ट्रैक्ट क्लास को दर्शाता है। |
| [`RedactionPolicy`](/redaction/python-net/groupdocs.redaction/redactionpolicy/) | एक सैनिटाइज़ेशन पॉलिसी को दर्शाता है, जिसमें लागू करने के लिए विशिष्ट रेडैक्शन का सेट शामिल है। |
| [`RedactionResult`](/redaction/python-net/groupdocs.redaction/redactionresult/) | रेडैक्शन ऑपरेशन के परिणाम को दर्शाता है। |
| [`Redactor`](/redaction/python-net/groupdocs.redaction/redactor/) | एक मुख्य क्लास को दर्शाता है जो दस्तावेज़ रेडैक्शन प्रक्रिया को नियंत्रित करती है, जिससे दस्तावेज़ खोलना, रेडैक्ट करना और सहेजना संभव होता है। |
| [`RedactorChangeLog`](/redaction/python-net/groupdocs.redaction/redactorchangelog/) | `Redactor.apply()` मेथड को पास किए गए रेडैक्शन की सूची के परिणामों को दर्शाता है। |
| [`RedactorLogEntry`](/redaction/python-net/groupdocs.redaction/redactorlogentry/) | रेडैक्शन लागू करने के परिणामों का प्रतिनिधित्व करता है। |

| [`GroupDocsRedactionException`](/redaction/python-net/groupdocs.redaction/groupdocsredactionexception/) | सभी GroupDocs.Redaction अपवादों के लिए आधारभूत अपवाद का प्रतिनिधित्व करता है। |

| [`PasswordRequiredException`](/redaction/python-net/groupdocs.redaction/passwordrequiredexception/) | जब दस्तावेज़ लोड करने के लिए पासवर्ड आवश्यक हो, तब फेंका जाने वाला अपवाद। |
| [`TrialLimitationsException`](/redaction/python-net/groupdocs.redaction/triallimitationsexception/) | जब उपयोगकर्ता ट्रायल मोड की सीमाओं का उल्लंघन करता है, तब फेंका जाने वाला अपवाद। |
