## RedactionResult class

रेडैक्शन ऑपरेशन के परिणाम को दर्शाता है।

और अधिक जानें

- More details about redaction results: https://docs.groupdocs.com/redaction/net/redaction-basics/

RedactionResult प्रकार निम्नलिखित सदस्यों को उजागर करता है:

### विधियाँ
| विधि | विवरण |
| :- | :- |
| [failed](/redaction/python-net/groupdocs.redaction/redactionresult/failed/#description) | एक नया RedactionResult उदाहरण विफल स्थिति के साथ आरंभ करता है। |
| [partial](/redaction/python-net/groupdocs.redaction/redactionresult/partial/#description) | एक नया [`RedactionResult`](/redaction/python-net/groupdocs.redaction/redactionresult/) उदाहरण आंशिक रूप से लागू स्थिति के साथ बनाता है। |
| [skipped](/redaction/python-net/groupdocs.redaction/redactionresult/skipped/#description) | RedactionResult क्लास का नया उदाहरण स्किप्ड स्थिति के साथ आरंभ करता है। |
| [successful](/redaction/python-net/groupdocs.redaction/redactionresult/successful/) | RedactionResult का नया उदाहरण लागू (सफल) स्थिति के साथ आरंभ करता है। |
