## Metered class

मीटरड (पे‑पर‑यूज़) लाइसेंसिंग को प्रबंधित करता है।

Metered लाइसेंस वास्तविक उपयोग (आमतौर पर पृष्ठ या
प्रसंस्कृत दस्तावेज़) पर बिल करते हैं। सार्वजनिक/निजी कुंजी जोड़ी को एक बार सेट करें
एप्लिकेशन स्टार्टअप पर; रैपर उपयोग को GroupDocs को वापस रिपोर्ट करता है
पृष्ठभूमि में लाइसेंस सर्वर।

Metered प्रकार निम्नलिखित सदस्यों को उजागर करता है:

### विधियाँ
| विधि | विवरण |
| :- | :- |
| [get_consumption_credit](/redaction/python-net/groupdocs.redaction/metered/get_consumption_credit/) | वर्तमान कुंजी के लिए शेष मीटरेड क्रेडिट लौटाएँ। |
| [get_consumption_quantity](/redaction/python-net/groupdocs.redaction/metered/get_consumption_quantity/) | अब तक उपयोग की गई कुल मीटरेड मात्रा लौटाएँ। |
| [set_metered_key](/redaction/python-net/groupdocs.redaction/metered/set_metered_key/#public_key-private_key) | दिए गए सार्वजनिक/निजी कुंजी जोड़े के साथ मीटरेड बिलिंग सक्रिय करें। |
