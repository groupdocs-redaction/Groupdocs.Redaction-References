## RedactionStatus class

RedactionStatus प्रकार निम्नलिखित सदस्यों को उजागर करता है:

### फ़ील्ड्स
| फ़ील्ड | विवरण |
| :- | :- |
| [APPLIED](/redaction/python-net/groupdocs.redaction/redactionstatus/applied/) | रेडैक्शन पूरी तरह और सफलतापूर्वक लागू किया गया। |
| [PARTIALLY_APPLIED](/redaction/python-net/groupdocs.redaction/redactionstatus/partially_applied/) | रेडैक्शन केवल उसके मिलानों के एक भाग पर लागू किया गया। |
| [SKIPPED](/redaction/python-net/groupdocs.redaction/redactionstatus/skipped/) | रेडैक्शन को स्किप किया गया (लागू नहीं किया गया)। |
| [FAILED](/redaction/python-net/groupdocs.redaction/redactionstatus/failed/) | रेडैक्शन अपवाद के साथ विफल रहा। |
