कन्वर्ज़न और ऑपरेशन्स को कॉन्फ़िगर करने के लिए विकल्प क्लासेस।

### क्लासेस
| क्लास | विवरण |
| :- | :- |
| [`CreatePageStream`](/redaction/python-net/groupdocs.redaction.options/createpagestream/) | एक मेथड को दर्शाता है जो पेज प्रीव्यू डेटा लिखने के लिए स्ट्रीम लौटाता है। |
| [`ILogger`](/redaction/python-net/groupdocs.redaction.options/ilogger/) | रेडैक्शन के दौरान इवेंट्स और त्रुटियों को रिकॉर्ड करने वाले लॉगर के लिए एक इंटरफ़ेस को परिभाषित करता है। |
| [`LoadOptions`](/redaction/python-net/groupdocs.redaction.options/loadoptions/) | फ़ाइल खोलने के लिए उपयोग किए जाने वाले विकल्प प्रदान करता है। |
| [`PreviewOptions`](/redaction/python-net/groupdocs.redaction.options/previewoptions/) | प्रीव्यू जनरेशन के लिए आवश्यकताओं और स्ट्रीम डेलीगेट्स सेट करने के विकल्प प्रदान करता है। |
| [`RasterizationOptions`](/redaction/python-net/groupdocs.redaction.options/rasterizationoptions/) | फ़ाइलों को PDF में कनवर्ट करने के विकल्प प्रदान करता है। |
| [`RedactorSettings`](/redaction/python-net/groupdocs.redaction.options/redactorsettings/) | रेडैक्शन सेटिंग्स को दर्शाता है, जिससे रेडैक्शन प्रक्रिया को अनुकूलित किया जा सकता है। |
| [`ReleasePageStream`](/redaction/python-net/groupdocs.redaction.options/releasepagestream/) | [`CreatePageStream`](/redaction/python-net/groupdocs.redaction.options/createpagestream/) डेलीगेट द्वारा बनाई गई स्ट्रीम को रिलीज़ करने वाले मेथड को दर्शाता है। |
| [`SaveOptions`](/redaction/python-net/groupdocs.redaction.options/saveoptions/) | आउटपुट फ़ाइल नाम बदलने और/या दस्तावेज़ को इमेज‑आधारित PDF (रास्टराइज़ेशन) में बदलने के विकल्प प्रदान करता है। |
