### उदाहरण

निम्न उदाहरण दर्शाता है कि दस्तावेज़ से शब्द \"use\", \"show\" या \"describe\" वाले सभी एनोटेशन को कैसे हटाया जाए (और अन्य को छोड़ दिया जाए)।

```csharp
using (Redactor redactor = new Redactor(@"D:\test.docx"))
{
   redactor.Apply(new DeleteAnnotationRedaction("(?im:(use|show|describe))"));
   redactor.Save()
}
```
