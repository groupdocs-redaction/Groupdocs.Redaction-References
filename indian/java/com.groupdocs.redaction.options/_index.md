पैकेज लोड और सेव विकल्प क्लास प्रदान करता है।



## क्लासेस

| क्लास | विवरण |
| --- | --- |
| [LoadOptions](../com.groupdocs.redaction.options/loadoptions) | फ़ाइल खोलने के लिए उपयोग किए जाने वाले विकल्प प्रदान करता है। |
| [PreviewOptions](../com.groupdocs.redaction.options/previewoptions) | पूर्वावलोकन जनरेशन के लिए आवश्यकताओं और स्ट्रीम डेलीगेट सेट करने के विकल्प प्रदान करता है। |
| [RasterizationOptions](../com.groupdocs.redaction.options/rasterizationoptions) | फ़ाइलों को PDF में परिवर्तित करने के विकल्प प्रदान करता है। |
| [RedactorSettings](../com.groupdocs.redaction.options/redactorsettings) | रेडैक्शन सेटिंग्स को दर्शाता है, जिससे रेडैक्शन प्रक्रिया को अनुकूलित किया जा सकता है। |
| [SaveOptions](../com.groupdocs.redaction.options/saveoptions) | आउटपुट फ़ाइल नाम बदलने और/या दस्तावेज़ को इमेज-आधारित PDF (रास्टराइज़ेशन) में परिवर्तित करने के विकल्प प्रदान करता है। |
| [WordprocessingSaveOptions](../com.groupdocs.redaction.options/wordprocessingsaveoptions) | वर्ड प्रोसेसिंग सहेजने के विकल्प। |

## इंटरफ़ेस

| इंटरफ़ेस | विवरण |
| --- | --- |
| [ICreatePageStream](../com.groupdocs.redaction.options/icreatepagestream) | एक मेथड प्रदान करता है जो पेज प्रीव्यू डेटा लिखने के लिए स्ट्रीम लौटाता है। |
| [ILogger](../com.groupdocs.redaction.options/ilogger) | रेडैक्शन प्रक्रिया में घटनाओं और त्रुटियों को लॉग करने के लिए उपयोग किए जा सकने वाले लॉगर के इंटरफ़ेस को परिभाषित करता है। |
| [IReleasePageStream](../com.groupdocs.redaction.options/ireleasepagestream) | एक मेथड को दर्शाता है जो CreatePageStream डेलीगेट द्वारा बनाई गई स्ट्रीम को रिलीज़ करता है। |

## एन्यूमरेशन

| एन्यूम | विवरण |

| [AdvancedRasterizationOptions](../com.groupdocs.redaction.options/advancedrasterizationoptions) | लागू किए जाने वाले उन्नत रास्टराइज़ेशन विकल्पों को प्रबंधित करने के लिए एक एन्यूमरेशन। |
| [PdfComplianceLevel](../com.groupdocs.redaction.options/pdfcompliancelevel) | समर्थित PDF अनुपालन स्तरों की सूची को दर्शाता है। |
| [PreviewFormats](../com.groupdocs.redaction.options/previewformats) | समर्थित प्रीव्यू फ़ॉर्मेट को दर्शाता है। |
| [WordProcessingComplianceLevel](../com.groupdocs.redaction.options/wordprocessingcompliancelevel) | वर्ड प्रोसेसिंग दस्तावेज़ों के लिए OOXML अनुपालन स्तर। |
