### Kelas
| Kelas | Deskripsi |
| :- | :- |
| [`DocumentFormatInstance`](/redaction/python-net/groupdocs.redaction.integration/documentformatinstance/) | Mewakili format khusus dari sebuah dokumen dan dapat diimplementasikan untuk menambahkan tipe dokumen khusus. |
| [`IAnnotatedDocument`](/redaction/python-net/groupdocs.redaction.integration/iannotateddocument/) | Mendefinisikan metode yang diperlukan untuk mengakses anotasi, seperti komentar, dan harus diimplementasikan oleh kelas turunan [`DocumentFormatInstance`](/redaction/python-net/groupdocs.redaction.integration/documentformatinstance/) untuk melakukan redaksi anotasi. |
| [`ICellularFormatInstance`](/redaction/python-net/groupdocs.redaction.integration/icellularformatinstance/) | Mendefinisikan metode yang diperlukan untuk mengakses format spreadsheet yang berisi satu atau banyak lembar kerja. |
| [`IFixedFormatDocument`](/redaction/python-net/groupdocs.redaction.integration/ifixedformatdocument/) | Mendefinisikan metode yang diperlukan untuk mengakses format dengan struktur tetap, seperti PDF atau presentasi. |
| [`IImageFormatInstance`](/redaction/python-net/groupdocs.redaction.integration/iimageformatinstance/) | Mendefinisikan metode yang diperlukan untuk redaksi format gambar raster. |
| [`IMetadataAccess`](/redaction/python-net/groupdocs.redaction.integration/imetadataaccess/) | Mendefinisikan metode yang diperlukan untuk mengakses metadata sebuah dokumen, jika format tersebut mendukungnya. |
| [`IPaginatedDocument`](/redaction/python-net/groupdocs.redaction.integration/ipaginateddocument/) | Mendefinisikan metode yang diperlukan untuk memanipulasi halaman dokumen. | [`IPreviewable`](/redaction/python-net/groupdocs.redaction.integration/ipreviewable/) | Mendefinisikan metode untuk membuat pratinjau dokumen. |
| [`IRasterizableDocument`](/redaction/python-net/groupdocs.redaction.integration/irasterizabledocument/) | Mendefinisikan metode yang diperlukan untuk menyimpan dokumen dalam bentuk biner apa pun. Tipe bawaan menyimpan dokumen sebagai PDF dengan gambar halaman-halamannya. |
| [`ITextualFormatInstance`](/redaction/python-net/groupdocs.redaction.integration/itextualformatinstance/) | Mewakili antarmuka yang mendefinisikan metode yang diperlukan untuk meredaksi data teks dalam dokumen apa pun yang berisi teks. |
| [`MetadataCollection`](/redaction/python-net/groupdocs.redaction.integration/metadatacollection/) | Mewakili kamus dari [`MetadataItem`](/redaction/python-net/groupdocs.redaction.integration/metadataitem/) dengan judulnya sebagai kunci. |
| [`MetadataItem`](/redaction/python-net/groupdocs.redaction.integration/metadataitem/) | Mewakili item metadata, umum untuk semua format yang didukung dan digunakan dalam redaksi metadata. |
