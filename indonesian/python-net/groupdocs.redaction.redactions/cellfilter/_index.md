## CellFilter class

Menyediakan opsi untuk membatasi ruang lingkup sebuah [`CellColumnRedaction`](/redaction/python-net/groupdocs.redaction.redactions/cellcolumnredaction/) ke lembar kerja dan kolom.

Pelajari lebih lanjut

- More details about spreadsheet redactions: https://docs.groupdocs.com/redaction/net/spreadsheet-redactions/

### Properti
| Properti | Deskripsi |
| :- | :- |
| [column_index](/redaction/python-net/groupdocs.redaction.redactions/cellfilter/column_index/) | Indeks kolom berbasis nol. |

| [work_sheet_index](/redaction/python-net/groupdocs.redaction.redactions/cellfilter/work_sheet_index/) | Indeks lembar kerja (berbasis nol). |
