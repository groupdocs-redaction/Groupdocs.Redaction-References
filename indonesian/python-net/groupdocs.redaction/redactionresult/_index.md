## RedactionResult class

Mewakili hasil operasi redaksi.

Pelajari lebih lanjut

- More details about redaction results: https://docs.groupdocs.com/redaction/net/redaction-basics/

Tipe RedactionResult menampilkan anggota-anggota berikut:

### Metode
| Metode | Deskripsi |
| :- | :- |
| [failed](/redaction/python-net/groupdocs.redaction/redactionresult/failed/#description) | Menginisialisasi instance RedactionResult baru dengan status gagal. |
| [partial](/redaction/python-net/groupdocs.redaction/redactionresult/partial/#description) | Membuat instance [`RedactionResult`](/redaction/python-net/groupdocs.redaction/redactionresult/) baru dengan status sebagian diterapkan. |
| [skipped](/redaction/python-net/groupdocs.redaction/redactionresult/skipped/#description) | Menginisialisasi instance baru dari kelas RedactionResult dengan status Dilewati. |
| [successful](/redaction/python-net/groupdocs.redaction/redactionresult/successful/) | Menginisialisasi instance baru RedactionResult dengan status diterapkan (berhasil). |
