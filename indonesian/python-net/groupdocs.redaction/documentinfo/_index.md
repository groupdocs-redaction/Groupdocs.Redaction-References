## DocumentInfo class

Mewakili informasi tentang dokumen.

Pelajari lebih lanjut:

- Get file info: https://docs.groupdocs.com/redaction/net/get-file-info/

Tipe DocumentInfo menampilkan anggota-anggota berikut:

### Properti
| Properti | Deskripsi |
| :- | :- |
| [file_type](/redaction/python-net/groupdocs.redaction/documentinfo/file_type/) | Deskripsi format file. |
| [page_count](/redaction/python-net/groupdocs.redaction/documentinfo/page_count/) | Jumlah total halaman. |
| [pages](/redaction/python-net/groupdocs.redaction/documentinfo/pages/) | Daftar informasi halaman [`PageInfo`](/redaction/python-net/groupdocs.redaction/pageinfo/). |
| [size](/redaction/python-net/groupdocs.redaction/documentinfo/size/) | Ukuran dokumen dalam byte. |
