- https://docs.groupdocs.com/redaction/net/supported-document-formats/

### Properti
| Properti | Deskripsi |
| :- | :- |
| [extension](/redaction/python-net/groupdocs.redaction/filetype/extension/) | Akhiran nama file, termasuk titik di depannya, misalnya ".doc". |
| [file_format](/redaction/python-net/groupdocs.redaction/filetype/file_format/) | Nama format file, misalnya "Microsoft Word Document". |
