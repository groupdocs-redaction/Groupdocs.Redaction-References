Kelas opsi untuk mengonfigurasi konversi dan operasi.

### Kelas
| Kelas | Deskripsi |
| :- | :- |
| [`CreatePageStream`](/redaction/python-net/groupdocs.redaction.options/createpagestream/) | Mewakili metode yang mengembalikan aliran untuk menulis data pratinjau halaman. |
| [`ILogger`](/redaction/python-net/groupdocs.redaction.options/ilogger/) | Mendefinisikan antarmuka untuk logger yang digunakan merekam peristiwa dan kesalahan selama redaksi. |
| [`LoadOptions`](/redaction/python-net/groupdocs.redaction.options/loadoptions/) | Menyediakan opsi yang akan digunakan untuk membuka file. |
| [`PreviewOptions`](/redaction/python-net/groupdocs.redaction.options/previewoptions/) | Menyediakan opsi untuk mengatur persyaratan dan delegasi aliran untuk pembuatan pratinjau. |
| [`RasterizationOptions`](/redaction/python-net/groupdocs.redaction.options/rasterizationoptions/) | Menyediakan opsi untuk mengonversi file menjadi PDF. |
| [`RedactorSettings`](/redaction/python-net/groupdocs.redaction.options/redactorsettings/) | Mewakili pengaturan redaksi, memungkinkan menyesuaikan proses redaksi. |
| [`ReleasePageStream`](/redaction/python-net/groupdocs.redaction.options/releasepagestream/) | Mewakili metode yang melepaskan aliran yang dibuat oleh delegasi [`CreatePageStream`](/redaction/python-net/groupdocs.redaction.options/createpagestream/). |
| [`SaveOptions`](/redaction/python-net/groupdocs.redaction.options/saveoptions/) | Menyediakan opsi untuk mengubah nama file output dan/atau mengonversi dokumen menjadi PDF berbasis gambar (rasterisasi). |
