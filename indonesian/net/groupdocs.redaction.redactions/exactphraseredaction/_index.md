### Contoh

Contoh berikut menunjukkan cara melakukan pencarian dan penggantian frasa dengan peka huruf besar/kecil.

```csharp
using (Redactor redactor = new Redactor(@"C:\sample.pdf"))
{
  // Secara default, isCaseSensitive = false;
  doc.Apply(new ExactPhraseRedaction("John Doe", true /*isCaseSensitive*/, new ReplacementOptions("[personal]")));
  doc.Save();
}
```

Contoh berikut menunjukkan cara mengganti frasa (tanpa memperhatikan huruf besar/kecil) dengan persegi panjang merah solid.

```csharp
using (Redactor redactor = new Redactor(@"C:\sample.pdf"))
{
  // Secara default, isCaseSensitive = false;
  doc.Apply(new ExactPhraseRedaction("John Doe", new ReplacementOptions(GroupDocs.Redaction.Options.Drawing.Color.Red)));
  doc.Save();
}
```
