### Contoh

Contoh berikut menunjukkan cara mengganti nama "John" dengan "[redacted]" dalam semua anotasi.

```csharp
using (Redactor redactor = new Redactor(@"C:\test.pdf"))
{
   redactor.Apply(new AnnotationRedaction("(?im:john)", "[redacted]"));
   redactor.Save()
}
```
