### Contoh

Contoh berikut menunjukkan cara menghapus semua anotasi yang berisi kata "use", "show", atau "describe" dari dokumen (dan membiarkan yang lain).

```csharp
using (Redactor redactor = new Redactor(@"D:\test.docx"))
{
   redactor.Apply(new DeleteAnnotationRedaction("(?im:(use|show|describe))"));
   redactor.Save()
}
```
