Namespace Integration menyediakan antarmuka dan kelas, yang digunakan untuk mengintegrasikan dokumen dengan format berbeda dengan GroupDocs.Redaction.

## Kelas

| Kelas | Deskripsi |
| --- | --- |
| [DocumentFormatInstance](./documentformatinstance) | Mewakili format spesifik dari sebuah dokumen. Implementasikan kelas ini untuk menambahkan tipe dokumen Anda sendiri. |
| [MetadataCollection](./metadatacollection) | Mewakili kamus dari [`MetadataItem`](../groupdocs.redaction.integration/metadataitem) dengan judulnya sebagai kunci. |
| [MetadataItem](./metadataitem) | Mewakili item metadata, umum untuk semua format yang didukung dan digunakan dalam penyuntingan metadata. |
## Antarmuka

| Antarmuka | Deskripsi |
| --- | --- |
| [IAnnotatedDocument](./iannotateddocument) | Mendefinisikan metode yang diperlukan untuk mengakses anotasi, seperti komentar. Perlu diimplementasikan oleh kelas turunan dari [`DocumentFormatInstance`](../groupdocs.redaction.integration/documentformatinstance) untuk melakukan penyuntingan anotasi. |
| [ICellularFormatInstance](./icellularformatinstance) | Mendefinisikan metode yang diperlukan untuk mengakses format spreadsheet, yang memiliki satu atau banyak lembar kerja. |
| [IFixedFormatDocument](./ifixedformatdocument) | Mendefinisikan metode yang diperlukan untuk format akses struktur tetap, seperti PDF atau presentasi. |
| [IImageFormatInstance](./iimageformatinstance) | Mendefinisikan metode yang diperlukan untuk redaksi format gambar raster. |
| [IMetadataAccess](./imetadataaccess) | Menetapkan metode yang diperlukan untuk mengakses metadata dokumen, jika format mendukungnya. |
| [IPaginatedDocument](./ipaginateddocument) | Mendefinisikan metode yang diperlukan untuk memanipulasi halaman dokumen. Harus diimplementasikan oleh kelas turunan [`DocumentFormatInstance`](../groupdocs.redaction.integration/documentformatinstance) untuk melakukan redaksi halaman. |
| [IPreviewable](./ipreviewable) | Menetapkan metode untuk membuat pratinjau dokumen. |

| [ITextualFormatInstance](./itextualformatinstance) | Menetapkan metode yang diperlukan untuk meredaksi data tekstual dalam dokumen apa pun yang berisi teks. |
