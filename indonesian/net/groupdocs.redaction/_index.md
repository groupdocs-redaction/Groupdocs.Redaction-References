Namespace Redaction menyediakan kelas untuk menyunting informasi sensitif dari dokumen dalam format PDF, gambar raster, dan dokumen kantor. Kelas utama dalam namespace ini adalah:

## Kelas

| Kelas | Deskripsi |
| --- | --- |

| [FileType](./filetype) | Mewakili tipe file. Menyediakan metode untuk memperoleh daftar semua tipe file yang didukung oleh GroupDocs.Redaction, mendeteksi tipe file berdasarkan ekstensi, dll. |
| [License](./license) | Menyediakan metode untuk menerapkan lisensi. |
| [Metered](./metered) | Menyediakan metode yang memungkinkan mengaktifkan produk dengan lisensi Metered dan mengambil jumlah MB yang diproses. Pelajari lebih lanjut tentang lisensi Metered [di sini](https://purchase.groupdocs.com/faqs/licensing/metered). |
| [PageInfo](./pageinfo) | Mewakili informasi halaman singkat. |
| [Redaction](./redaction) | Mewakili kelas abstrak dasar untuk semua tipe redaksi. |
| [RedactionPolicy](./redactionpolicy) | Mewakili kebijakan sanitasi, berisi sekumpulan redaksi spesifik yang akan diterapkan. |
| [RedactionResult](./redactionresult) | Mewakili hasil operasi redaksi. |
| [Redactor](./redactor) | Mewakili kelas utama yang mengontrol proses redaksi dokumen, memungkinkan membuka, meredaksi, dan menyimpan dokumen. |
| [RedactorChangeLog](./redactorchangelog) | Mewakili hasil untuk daftar redaksi, yang diteruskan ke metode Apply() dari kelas [`Redactor`](../groupdocs.redaction/redactor). |
| [RedactorLogEntry](./redactorlogentry) | Mewakili hasil penerapan redaksi. |
