Paket ini menyediakan antarmuka dan kelas, yang digunakan untuk mengintegrasikan dokumen dengan format berbeda dengan GroupDocs.Redactions.



## Kelas

| Kelas | Deskripsi |
| --- | --- |
| [DocumentFormatInstance](../com.groupdocs.redaction.integration/documentformatinstance) | Mewakili format spesifik sebuah dokumen. |
| [MetadataCollection](../com.groupdocs.redaction.integration/metadatacollection) | Mewakili kamus MetadataItem dengan judulnya sebagai kunci. |
| [MetadataItem](../com.groupdocs.redaction.integration/metadataitem) | Mewakili item metadata, umum untuk semua format yang didukung dan digunakan dalam redaksi metadata. |
| [RecognizedImage](../com.groupdocs.redaction.integration/recognizedimage) | Mewakili teks, diekstrak dari gambar sebagai hasil proses pengenalan. |
| [RedactableImage](../com.groupdocs.redaction.integration/redactableimage) | Menyediakan antarmuka untuk semua operasi redaksi gambar raster. |
| [TextFragment](../com.groupdocs.redaction.integration/textfragment) | Mewakili bagian dari teks yang dikenali (kata, simbol, dll), diekstrak oleh mesin OCR. |
| [TextLine](../com.groupdocs.redaction.integration/textline) | Mewakili baris teks, diekstrak oleh mesin OCR dari gambar. |

## Antarmuka

| Antarmuka | Deskripsi |
| --- | --- |
| [IAnnotatedDocument](../com.groupdocs.redaction.integration/iannotateddocument) | Mendefinisikan metode yang diperlukan untuk mengakses anotasi, seperti komentar. |
| [ICellularFormatInstance](../com.groupdocs.redaction.integration/icellularformatinstance) | Mendefinisikan metode yang diperlukan untuk mengakses format spreadsheet, yang memiliki satu atau banyak lembar kerja. |
| [IFixedFormatDocument](../com.groupdocs.redaction.integration/ifixedformatdocument) | Mendefinisikan metode yang diperlukan untuk mengakses format dengan struktur tetap, seperti PDF atau presentasi. |
| [IImageFormatInstance](../com.groupdocs.redaction.integration/iimageformatinstance) | Mendefinisikan metode yang diperlukan untuk redaksi format gambar raster. |
| [IMetadataAccess](../com.groupdocs.redaction.integration/imetadataaccess) | Mendefinisikan metode yang diperlukan untuk mengakses metadata dokumen, jika format mendukungnya. |
| [IMultipleAreaRedactable](../com.groupdocs.redaction.integration/imultiplearearedactable) | Mendefinisikan metode yang diperlukan untuk meredaksi beberapa area gambar sekaligus dengan warna yang sama. |
| [IOcrConnector](../com.groupdocs.redaction.integration/iocrconnector) | Mendefinisikan metode yang diperlukan untuk menerapkan redaksi teks pada dokumen gambar dan gambar tersemat. |
| [IPaginatedDocument](../com.groupdocs.redaction.integration/ipaginateddocument) | Mendefinisikan metode yang diperlukan untuk memanipulasi halaman dokumen. |
| [IPreviewable](../com.groupdocs.redaction.integration/ipreviewable) | Mendefinisikan metode untuk membuat pratinjau dokumen. |
| [IRasterizableDocument](../com.groupdocs.redaction.integration/irasterizabledocument) | Mendefinisikan metode yang diperlukan untuk menyimpan dokumen dalam bentuk biner apa pun. |
| [ITextualFormatInstance](../com.groupdocs.redaction.integration/itextualformatinstance) | Mendefinisikan metode yang diperlukan untuk meredaksi data teks dalam dokumen apa pun yang berisi teks. |
