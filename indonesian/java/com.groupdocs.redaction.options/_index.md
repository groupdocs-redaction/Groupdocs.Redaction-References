Paket ini menyediakan kelas opsi muat dan simpan.



## Kelas

| Kelas | Deskripsi |
| --- | --- |
| [LoadOptions](../com.groupdocs.redaction.options/loadoptions) | Menyediakan opsi yang akan digunakan untuk membuka file. |
| [PreviewOptions](../com.groupdocs.redaction.options/previewoptions) | Menyediakan opsi untuk mengatur persyaratan dan delegasi aliran untuk pembuatan pratinjau. |
| [RasterizationOptions](../com.groupdocs.redaction.options/rasterizationoptions) | Menyediakan opsi untuk mengonversi file menjadi PDF. |
| [RedactorSettings](../com.groupdocs.redaction.options/redactorsettings) | Mewakili pengaturan redaksi, memungkinkan untuk menyesuaikan proses redaksi. |
| [SaveOptions](../com.groupdocs.redaction.options/saveoptions) | Menyediakan opsi untuk mengubah nama file output dan/atau mengonversi dokumen menjadi PDF berbasis gambar (rasterisasi). |
| [WordprocessingSaveOptions](../com.groupdocs.redaction.options/wordprocessingsaveoptions) | Opsi penyimpanan pengolah kata. |

## Antarmuka

| Antarmuka | Deskripsi |
