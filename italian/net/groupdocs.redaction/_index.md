Lo spazio dei nomi Redaction fornisce classi per la rimozione di informazioni sensibili dai documenti in formati PDF, immagine raster e documenti Office. Le classi principali in questo spazio dei nomi sono:

## Classi

| Classe | Descrizione |
| --- | --- |
| [DocumentInfo](./documentinfo) | Rappresenta un'informazione sul documento. Implementa l'interfaccia IDocumentInfo. Vedi [`IDocumentInfo`](../groupdocs.redaction/idocumentinfo) per esempi. |
| [FileType](./filetype) | Rappresenta un tipo di file. Fornisce metodi per ottenere un elenco di tutti i tipi di file supportati da GroupDocs.Redaction, rilevare il tipo di file per estensione, ecc. |
| [License](./license) | Fornisce metodi per applicare la licenza. |
| [Metered](./metered) | Fornisce metodi che consentono di attivare il prodotto con licenza a consumo e recuperare la quantità di MB elaborati. Scopri di più sulle licenze a consumo [qui](https://purchase.groupdocs.com/faqs/licensing/metered). |
| [PageInfo](./pageinfo) | Rappresenta una breve informazione di pagina. |
| [Redaction](./redaction) | Rappresenta una classe astratta di base per tutti i tipi di redazione. |
| [RedactionPolicy](./redactionpolicy) | Rappresenta una politica di sanitizzazione, contenente un insieme di redazioni specifiche da applicare. |
| [RedactionResult](./redactionresult) | Rappresenta il risultato dell'operazione di redazione. |
| [Redactor](./redactor) | Rappresenta la classe principale che controlla il processo di redazione dei documenti, consentendo di aprire, redigere e salvare i documenti. |
| [RedactorChangeLog](./redactorchangelog) | Rappresenta i risultati per un elenco di redazioni, passati al metodo Apply() della classe [`Redactor`](../groupdocs.redaction/redactor). |
| [RedactorLogEntry](./redactorlogentry) | Rappresenta i risultati dell'applicazione della redazione. |
