Tipi sotto `groupdocs.redaction.integration`.

### Classi
| Classe | Descrizione |
| :- | :- |
| [`DocumentFormatInstance`](/redaction/python-net/groupdocs.redaction.integration/documentformatinstance/) | Rappresenta un formato specifico di un documento e può essere implementato per aggiungere tipi di documento personalizzati. |
| [`IAnnotatedDocument`](/redaction/python-net/groupdocs.redaction.integration/iannotateddocument/) | Definisce i metodi necessari per accedere alle annotazioni, come i commenti, e deve essere implementato da una classe derivata da [`DocumentFormatInstance`](/redaction/python-net/groupdocs.redaction.integration/documentformatinstance/) per eseguire le redazioni delle annotazioni. |
| [`ICellularFormatInstance`](/redaction/python-net/groupdocs.redaction.integration/icellularformatinstance/) | Definisce i metodi necessari per accedere ai formati di fogli di calcolo che contengono uno o più fogli di lavoro. |
| [`IFixedFormatDocument`](/redaction/python-net/groupdocs.redaction.integration/ifixedformatdocument/) | Definisce i metodi necessari per accedere a formati di struttura fissa, come PDF o presentazioni. |
| [`IImageFormatInstance`](/redaction/python-net/groupdocs.redaction.integration/iimageformatinstance/) | Definisce i metodi necessari per le redazioni di formati di immagini raster. |
| [`IMetadataAccess`](/redaction/python-net/groupdocs.redaction.integration/imetadataaccess/) | Definisce i metodi necessari per accedere ai metadati di un documento, se il formato lo supporta. |
| [`IPaginatedDocument`](/redaction/python-net/groupdocs.redaction.integration/ipaginateddocument/) | Definisce i metodi necessari per manipolare le pagine di un documento. Deve essere implementato da una classe derivata da [`DocumentFormatInstance`](/redaction/python-net/groupdocs.redaction.integration/documentformatinstance/) per eseguire le redazioni delle pagine. |
| [`IPreviewable`](/redaction/python-net/groupdocs.redaction.integration/ipreviewable/) | Definisce i metodi per creare un'anteprima del documento. |
| [`IRasterizableDocument`](/redaction/python-net/groupdocs.redaction.integration/irasterizabledocument/) | Definisce i metodi necessari per salvare un documento in qualsiasi forma binaria. I tipi integrati salvano un documento come PDF con le immagini delle sue pagine. |
| [`ITextualFormatInstance`](/redaction/python-net/groupdocs.redaction.integration/itextualformatinstance/) | Rappresenta un'interfaccia che definisce i metodi necessari per redigere dati testuali in qualsiasi documento contenente testo. |
| [`MetadataCollection`](/redaction/python-net/groupdocs.redaction.integration/metadatacollection/) | Rappresenta un dizionario di [`MetadataItem`](/redaction/python-net/groupdocs.redaction.integration/metadataitem/) con il suo titolo come chiave. |
| [`MetadataItem`](/redaction/python-net/groupdocs.redaction.integration/metadataitem/) | Rappresenta un elemento di metadati, comune a tutti i formati supportati e utilizzato nelle redazioni di metadati. |
