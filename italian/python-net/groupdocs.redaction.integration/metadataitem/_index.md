## MetadataItem class

Rappresenta un elemento di metadati, comune a tutti i formati supportati e utilizzato nelle redazioni di metadati.

Il tipo MetadataItem espone i seguenti membri:

### Costruttori
| Costruttore | Descrizione |
| :- | :- |
| [__init__](/redaction/python-net/groupdocs.redaction.integration/metadataitem/__init__/) | Inizializza una nuova istanza. |

### Metodi
| Metodo | Descrizione |
| :- | :- |
| [create_clone](/redaction/python-net/groupdocs.redaction.integration/metadataitem/create_clone/) | Crea una copia profonda dell'istanza corrente. |
| [get_object_data](/redaction/python-net/groupdocs.redaction.integration/metadataitem/get_object_data/#info-context) | Restituisce informazioni sulle proprietà serializzabili. |
| [get_object_data_serialization_info](/redaction/python-net/groupdocs.redaction.integration/metadataitem/get_object_data_serialization_info/) |  |

### Proprietà
| Proprietà | Descrizione |
| :- | :- |
| [actual_value](/redaction/python-net/groupdocs.redaction.integration/metadataitem/actual_value/) | La rappresentazione stringa del valore dell'elemento di metadati. |
| [category](/redaction/python-net/groupdocs.redaction.integration/metadataitem/category/) | La categoria dell'elemento di metadati, ad esempio l'ID risorsa per un elemento di metadati di risorsa incorporata. |
| [dictionary_key](/redaction/python-net/groupdocs.redaction.integration/metadataitem/dictionary_key/) | La chiave del dizionario per una [`MetadataCollection`](/redaction/python-net/groupdocs.redaction.integration/metadatacollection/), derivata dal suo OriginalName e da altri dati. |
| [filter](/redaction/python-net/groupdocs.redaction.integration/metadataitem/filter/) | Il filtro assegnato a questo elemento di metadati, rappresentato da un valore `MetadataFilters`, utilizzato per la filtrazione degli elementi. |
| [is_custom](/redaction/python-net/groupdocs.redaction.integration/metadataitem/is_custom/) | L'elemento è personalizzato (aggiunto dagli autori del documento). |
| [original_name](/redaction/python-net/groupdocs.redaction.integration/metadataitem/original_name/) | Il nome originale dell'elemento di metadati così come appare nel documento. |
| [values](/redaction/python-net/groupdocs.redaction.integration/metadataitem/values/) | Il valore dell'elemento di metadati. |
