## IMetadataAccess class

Definisce i metodi necessari per accedere ai metadati di un documento, se il formato lo supporta.

Per saperne di più

- More details about applying redactions: https://docs.groupdocs.com/redaction/net/redaction-basics/
- More details about document metadata redactions: https://docs.groupdocs.com/redaction/net/metadata-redactions/
- More details about implementing custom formats: https://docs.groupdocs.com/redaction/net/create-custom-format-handler/

Il tipo IMetadataAccess espone i seguenti membri:

### Metodi
| Metodo | Descrizione |
| :- | :- |
| [change_metadata](/redaction/python-net/groupdocs.redaction.integration/imetadataaccess/change_metadata/#metadata_item) | Modifica l'elemento di metadati specificato da [`MetadataCollection`](/redaction/python-net/groupdocs.redaction.integration/metadatacollection/) o ne aggiunge uno nuovo se non presente. |
| [change_metadata_metadata_item](/redaction/python-net/groupdocs.redaction.integration/imetadataaccess/change_metadata_metadata_item/) |  |
| [get_metadata](/redaction/python-net/groupdocs.redaction.integration/imetadataaccess/get_metadata/) | Recupera un dizionario con i metadati del documento. |
