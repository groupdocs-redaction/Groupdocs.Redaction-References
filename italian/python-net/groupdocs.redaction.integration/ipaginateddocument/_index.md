## IPaginatedDocument class

Definisce i metodi necessari per manipolare le pagine di un documento. Deve essere implementato da una classe derivata da [`DocumentFormatInstance`](/redaction/python-net/groupdocs.redaction.integration/documentformatinstance/) per eseguire le redazioni delle pagine.

- More details about applying redactions: https://docs.groupdocs.com/redaction/net/redaction-basics/
- More details about manipulating pages: https://docs.groupdocs.com/redaction/net/remove-page-redaction/

Il tipo IPaginatedDocument espone i seguenti membri:

### Metodi
| Metodo | Descrizione |
| :- | :- |
| [remove_pages](/redaction/python-net/groupdocs.redaction.integration/ipaginateddocument/remove_pages/#origin-index-count) | Rimuove una o più pagine a seconda della posizione iniziale, dell'offset e del conteggio. |
| [remove_pages_page_seek_origin](/redaction/python-net/groupdocs.redaction.integration/ipaginateddocument/remove_pages_page_seek_origin/) |  |
