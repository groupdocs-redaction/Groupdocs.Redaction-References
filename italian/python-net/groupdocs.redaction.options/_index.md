Classi di opzione per configurare conversioni e operazioni.

### Classi
| Classe | Descrizione |
| :- | :- |
| [`CreatePageStream`](/redaction/python-net/groupdocs.redaction.options/createpagestream/) | Rappresenta un metodo che restituisce uno stream per scrivere i dati dell'anteprima della pagina. |
| [`ILogger`](/redaction/python-net/groupdocs.redaction.options/ilogger/) | Definisce un'interfaccia per un logger utilizzato per registrare eventi ed errori durante la redazione. |
| [`LoadOptions`](/redaction/python-net/groupdocs.redaction.options/loadoptions/) | Fornisce opzioni che saranno utilizzate per aprire un file. |
| [`PreviewOptions`](/redaction/python-net/groupdocs.redaction.options/previewoptions/) | Fornisce opzioni per impostare requisiti e delegati di stream per la generazione dell'anteprima. |
| [`RasterizationOptions`](/redaction/python-net/groupdocs.redaction.options/rasterizationoptions/) | Fornisce opzioni per convertire i file in PDF. |
| [`RedactorSettings`](/redaction/python-net/groupdocs.redaction.options/redactorsettings/) | Rappresenta le impostazioni di redazione, consentendo di personalizzare il processo di redazione. |
| [`ReleasePageStream`](/redaction/python-net/groupdocs.redaction.options/releasepagestream/) | Rappresenta un metodo che rilascia uno stream creato dal delegato [`CreatePageStream`](/redaction/python-net/groupdocs.redaction.options/createpagestream/). |
| [`SaveOptions`](/redaction/python-net/groupdocs.redaction.options/saveoptions/) | Fornisce opzioni per modificare il nome del file di output e/o convertire il documento in PDF basato su immagine (rasterizzazione). |
