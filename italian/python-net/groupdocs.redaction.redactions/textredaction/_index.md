## TextRedaction class

Rappresenta una classe astratta di base per le redazioni del testo del documento.

Per saperne di più

- More details about applying redactions: https://docs.groupdocs.com/redaction/net/redaction-basics/
- More details about document text redactions: https://docs.groupdocs.com/redaction/net/text-redactions/

Il tipo TextRedaction espone i seguenti membri:

### Metodi
| Metodo | Descrizione |
| :- | :- |
| [apply_to](/redaction/python-net/groupdocs.redaction/redaction/apply_to/) | Applica la redazione a una determinata istanza di formato. (eredita da [`Redaction`](/redaction/python-net/groupdocs.redaction/redaction/)) |
| [apply_to_document_format_instance](/redaction/python-net/groupdocs.redaction/redaction/apply_to_document_format_instance/) | (eredita da [`Redaction`](/redaction/python-net/groupdocs.redaction/redaction/)) |

### Proprietà
| Proprietà | Descrizione |
| :- | :- |
| [action_options](/redaction/python-net/groupdocs.redaction.redactions/textredaction/action_options/) | L'istanza [`ReplacementOptions`](/redaction/python-net/groupdocs.redaction.redactions/replacementoptions/) specifica il tipo di sostituzione del testo. |
| [ocr_connector](/redaction/python-net/groupdocs.redaction.redactions/textredaction/ocr_connector/) | L'implementazione IOcrConnector utilizzata per estrarre testo da contenuti grafici. |
| [description](/redaction/python-net/groupdocs.redaction/redaction/description/) | La descrizione della redazione, contenente il suo nome e i parametri. (eredita da [`Redaction`](/redaction/python-net/groupdocs.redaction/redaction/)) |
