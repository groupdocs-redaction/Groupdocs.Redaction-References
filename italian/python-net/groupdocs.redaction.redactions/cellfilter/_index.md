## CellFilter class

Fornisce un'opzione per limitare l'ambito di un [`CellColumnRedaction`](/redaction/python-net/groupdocs.redaction.redactions/cellcolumnredaction/) a un foglio di lavoro e a una colonna.

Per saperne di più

- More details about spreadsheet redactions: https://docs.groupdocs.com/redaction/net/spreadsheet-redactions/

Il tipo CellFilter espone i seguenti membri:

### Costruttori
| Costruttore | Descrizione |
| :- | :- |
| [__init__](/redaction/python-net/groupdocs.redaction.redactions/cellfilter/__init__/) | Inizializza una nuova istanza di CellFilter. |

### Proprietà
| Proprietà | Descrizione |
| :- | :- |
| [column_index](/redaction/python-net/groupdocs.redaction.redactions/cellfilter/column_index/) | L'indice della colonna basato su zero. |
| [has_work_sheet_index](/redaction/python-net/groupdocs.redaction.redactions/cellfilter/has_work_sheet_index/) | La proprietà indica se WorkSheetIndex è impostato. |
| [work_sheet_index](/redaction/python-net/groupdocs.redaction.redactions/cellfilter/work_sheet_index/) | L'indice del foglio di lavoro (basato su zero). |
| [work_sheet_name](/redaction/python-net/groupdocs.redaction.redactions/cellfilter/work_sheet_name/) | Il nome del foglio di lavoro, se applicabile. |

### Campi
| Campo | Descrizione |
| :- | :- |
| [NO_INDEX](/redaction/python-net/groupdocs.redaction.redactions/cellfilter/no_index/) | Rappresenta un valore predefinito per il filtro, che è -1. |
