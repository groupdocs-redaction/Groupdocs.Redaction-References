| [`PageAreaFilter`](/redaction/python-net/groupdocs.redaction.redactions/pageareafilter/) | Rappresenta un filtro di redazione, impostando un'area all'interno di una pagina di un documento per applicare la redazione. |

| [`PageRangeFilter`](/redaction/python-net/groupdocs.redaction.redactions/pagerangefilter/) | Rappresenta un filtro di redazione, impostando l'intervallo di pagine all'interno di un documento per applicare la redazione. |

| [`ReplacementOptions`](/redaction/python-net/groupdocs.redaction.redactions/replacementoptions/) | Rappresenta le opzioni per la sostituzione del testo corrispondente. |
| [`TextRedaction`](/redaction/python-net/groupdocs.redaction.redactions/textredaction/) | Rappresenta una classe astratta di base per le redazioni del testo del documento. |
