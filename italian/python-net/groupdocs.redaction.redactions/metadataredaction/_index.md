## MetadataRedaction class

Rappresenta una classe astratta di base per le redazioni dei metadati del documento.

Per saperne di più

- More details about document metadata redactions: https://docs.groupdocs.com/redaction/net/metadata-redactions/

Il tipo MetadataRedaction espone i seguenti membri:

### Metodi
| Metodo | Descrizione |
| :- | :- |
| [apply_to](/redaction/python-net/groupdocs.redaction.redactions/metadataredaction/apply_to/#format_instance) | Applica la redazione a una data istanza di formato. |
| [apply_to_document_format_instance](/redaction/python-net/groupdocs.redaction.redactions/metadataredaction/apply_to_document_format_instance/) |  |

### Proprietà
| Proprietà | Descrizione |
| :- | :- |
| [filter](/redaction/python-net/groupdocs.redaction.redactions/metadataredaction/filter/) | Il filtro utilizzato per selezionare tutti o specifici metadati, come Autore o Azienda. |
| [description](/redaction/python-net/groupdocs.redaction/redaction/description/) | La descrizione della redazione, contenente il suo nome e i parametri. (eredita da [`Redaction`](/redaction/python-net/groupdocs.redaction/redaction/)) |
