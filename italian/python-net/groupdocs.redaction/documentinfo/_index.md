## DocumentInfo class

Rappresenta informazioni su un documento.

Per saperne di più:

- Get file info: https://docs.groupdocs.com/redaction/net/get-file-info/

Il tipo DocumentInfo espone i seguenti membri:

### Proprietà
| Proprietà | Descrizione |
| :- | :- |
| [file_type](/redaction/python-net/groupdocs.redaction/documentinfo/file_type/) | La descrizione del formato file. |
| [page_count](/redaction/python-net/groupdocs.redaction/documentinfo/page_count/) | Il conteggio totale delle pagine. |
| [pages](/redaction/python-net/groupdocs.redaction/documentinfo/pages/) | L'elenco delle informazioni della pagina [`PageInfo`](/redaction/python-net/groupdocs.redaction/pageinfo/). |
| [size](/redaction/python-net/groupdocs.redaction/documentinfo/size/) | La dimensione del documento in byte. |
