## Metered class

Gestisce la licenza a consumo (pay‑per‑use).

Le licenze Metered fatturano in base al consumo reale (tipicamente pagine o
documenti elaborati). Imposta la coppia di chiavi pubblica/privata una sola volta al
avvio dell'applicazione; il wrapper riporta l'utilizzo al GroupDocs
server di licenza in background.

Il tipo Metered espone i seguenti membri:

### Metodi
| Metodo | Descrizione |
| :- | :- |
| [get_consumption_credit](/redaction/python-net/groupdocs.redaction/metered/get_consumption_credit/) | Restituisci il credito a consumo rimanente per la chiave corrente. |
| [get_consumption_quantity](/redaction/python-net/groupdocs.redaction/metered/get_consumption_quantity/) | Restituisci la quantità totale a consumo consumata finora. |
| [set_metered_key](/redaction/python-net/groupdocs.redaction/metered/set_metered_key/#public_key-private_key) | Attiva la fatturazione a consumo con la coppia di chiavi pubblica/privata fornita. |
