## RedactionResult class

Rappresenta il risultato dell'operazione di redazione.

Per saperne di più

- More details about redaction results: https://docs.groupdocs.com/redaction/net/redaction-basics/

Il tipo RedactionResult espone i seguenti membri:

### Metodi
| Metodo | Descrizione |
| :- | :- |
| [failed](/redaction/python-net/groupdocs.redaction/redactionresult/failed/#description) | Inizializza una nuova istanza di RedactionResult con uno stato fallito. |
| [partial](/redaction/python-net/groupdocs.redaction/redactionresult/partial/#description) | Crea una nuova istanza di [`RedactionResult`](/redaction/python-net/groupdocs.redaction/redactionresult/) con uno stato parzialmente applicato. |
| [skipped](/redaction/python-net/groupdocs.redaction/redactionresult/skipped/#description) | Inizializza una nuova istanza della classe RedactionResult con stato Saltato. |
| [successful](/redaction/python-net/groupdocs.redaction/redactionresult/successful/) | Inizializza una nuova istanza di RedactionResult con uno stato applicato (riuscito). |

### Proprietà
| Proprietà | Descrizione |
| :- | :- |
| [error_message](/redaction/python-net/groupdocs.redaction/redactionresult/error_message/) | Il messaggio di errore per la diagnostica. |
| [status](/redaction/python-net/groupdocs.redaction/redactionresult/status/) | Lo stato di esecuzione. |
