## FileType class

Rappresenta un tipo di file.

Per saperne di più:
- https://docs.groupdocs.com/redaction/net/supported-document-formats/
- https://docs.groupdocs.com/redaction/net/get-supported-file-formats/
- https://docs.groupdocs.com/redaction/net/get-file-info/

Il tipo FileType espone i seguenti membri:

### Metodi
| Metodo | Descrizione |
| :- | :- |
| [equals](/redaction/python-net/groupdocs.redaction/filetype/equals/#other) | Determina se il FileType corrente è lo stesso dell'oggetto FileType specificato. |
| [equals](/redaction/python-net/groupdocs.redaction/filetype/equals/#obj) | Determina se il [`FileType`](/redaction/python-net/groupdocs.redaction/filetype/) corrente è lo stesso dell'oggetto specificato. |
| [equals_file_type](/redaction/python-net/groupdocs.redaction/filetype/equals_file_type/) |  |
| [equals_object](/redaction/python-net/groupdocs.redaction/filetype/equals_object/) |  |
| [from_extension](/redaction/python-net/groupdocs.redaction/filetype/from_extension/#extension) | Mappa l'estensione del file al tipo di file. |
| [get_hash_code](/redaction/python-net/groupdocs.redaction/filetype/get_hash_code/) | Restituisce il codice hash per l'oggetto [`FileType`](/redaction/python-net/groupdocs.redaction/filetype/) corrente. |
| [get_supported_file_types](/redaction/python-net/groupdocs.redaction/filetype/get_supported_file_types/) | Recupera i tipi di file supportati. |
| [to_string](/redaction/python-net/groupdocs.redaction/filetype/to_string/) | Restituisce una stringa che rappresenta l'oggetto corrente. |

### Proprietà
| Proprietà | Descrizione |
| :- | :- |
| [extension](/redaction/python-net/groupdocs.redaction/filetype/extension/) | Il suffisso del nome file, includendo il punto iniziale, ad es., ".doc". |
| [file_format](/redaction/python-net/groupdocs.redaction/filetype/file_format/) | Il nome del formato file, per esempio "Microsoft Word Document". |
