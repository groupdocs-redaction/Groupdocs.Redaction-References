Il pacchetto fornisce classi di opzioni di caricamento e salvataggio.



## Classi

| Classe | Descrizione |
| --- | --- |
| [LoadOptions](../com.groupdocs.redaction.options/loadoptions) | Fornisce opzioni che saranno utilizzate per aprire un file. |
| [PreviewOptions](../com.groupdocs.redaction.options/previewoptions) | Fornisce opzioni per impostare i requisiti e i delegati di stream per la generazione dell'anteprima. |
| [RasterizationOptions](../com.groupdocs.redaction.options/rasterizationoptions) | Fornisce opzioni per convertire i file in PDF. |
| [RedactorSettings](../com.groupdocs.redaction.options/redactorsettings) | Rappresenta le impostazioni di redazione, consentendo di personalizzare il processo di redazione. |
| [SaveOptions](../com.groupdocs.redaction.options/saveoptions) | Fornisce opzioni per modificare il nome del file di output e/o convertire il documento in PDF basato su immagine (rasterizzazione). |
| [WordprocessingSaveOptions](../com.groupdocs.redaction.options/wordprocessingsaveoptions) | Opzioni di salvataggio per l'elaborazione testi. |

## Interfacce

| Interfaccia | Descrizione |
| --- | --- |
| [ICreatePageStream](../com.groupdocs.redaction.options/icreatepagestream) | Fornisce un metodo che restituisce uno stream per scrivere i dati dell'anteprima della pagina. |
| [ILogger](../com.groupdocs.redaction.options/ilogger) | Definisce l'interfaccia di un logger che può essere utilizzato per registrare eventi ed errori nel processo di redazione. |
| [IReleasePageStream](../com.groupdocs.redaction.options/ireleasepagestream) | Rappresenta un metodo che rilascia lo stream creato dal delegato CreatePageStream. |
