Redaction‑namnrymden tillhandahåller klasser för att maskera känslig information i dokument i PDF-, rasterbild- och kontorsdokumentformat. De viktigaste klasserna i denna namnrymd är:

## Klasser

| Klass | Beskrivning |
| --- | --- |
| [DocumentInfo](./documentinfo) | Representerar information om ett dokument. Implementerar IDocumentInfo‑gränssnittet. Se [`IDocumentInfo`](../groupdocs.redaction/idocumentinfo) för exempel. |
| [FileType](./filetype) | Representerar en filtyp. Tillhandahåller metoder för att hämta en lista över alla filtyper som stöds av GroupDocs.Redaction, upptäcka filtyp efter filändelse, etc. |
| [License](./license) | Tillhandahåller metoder för att tillämpa licens. |
| [Metered](./metered) | Tillhandahåller metoder som möjliggör att aktivera produkten med en Metered-licens och hämta mängden MB som bearbetats. Läs mer om Metered-licenser [här](https://purchase.groupdocs.com/faqs/licensing/metered). |
| [PageInfo](./pageinfo) | Representerar kort information om en sida. |
| [Redaction](./redaction) | Representerar en basabstrakt klass för alla raderingstyper. |
| [RedactionPolicy](./redactionpolicy) | Representerar en saneringspolicy som innehåller en uppsättning specifika raderingar att tillämpa. |
| [RedactionResult](./redactionresult) | Representerar resultatet av raderingsoperationen. |
| [Redactor](./redactor) | Representerar huvudklassen som styr dokumentraderingsprocessen, vilket möjliggör att öppna, radera och spara dokument. |
| [RedactorChangeLog](./redactorchangelog) | Representerar resultat för en lista av raderingar som skickas till Apply()-metoden i klassen [`Redactor`](../groupdocs.redaction/redactor). |
| [RedactorLogEntry](./redactorlogentry) | Representerar resultatet av att tillämpa radering. |
