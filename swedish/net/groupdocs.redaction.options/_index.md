Options‑namnrymden tillhandahåller klasser för laddnings- och sparalternativ.

## Klasser

| Klass | Beskrivning |
| --- | --- |
| [CreatePageStream](./createpagestream) | Representerar en metod som returnerar en ström för att skriva data för sidförhandsgranskning. |
| [LoadOptions](./loadoptions) | Tillhandahåller alternativ som kommer att användas för att öppna en fil. |
| [PreviewOptions](./previewoptions) | Tillhandahåller alternativ för att ange krav och strömsdelegeringar för generering av förhandsgranskning. |
| [RasterizationOptions](./rasterizationoptions) | Tillhandahåller alternativ för att konvertera filer till PDF. |
| [RedactorSettings](./redactorsettings) | Representerar redigeringsinställningar som möjliggör anpassning av redigeringsprocessen. |
| [ReleasePageStream](./releasepagestream) | Representerar en metod som frigör ström skapad av delegaten [`CreatePageStream`](../groupdocs.redaction.options/createpagestream). |
| [SaveOptions](./saveoptions) | Tillhandahåller alternativ för att ändra ett utdatafilnamn och/eller konvertera dokumentet till bildbaserad PDF (rasterisering). |
| [WordprocessingSaveOptions](./wordprocessingsaveoptions) | Tillhandahåller sparalternativ för ordbehandlingsdokument. |
## Gränssnitt
