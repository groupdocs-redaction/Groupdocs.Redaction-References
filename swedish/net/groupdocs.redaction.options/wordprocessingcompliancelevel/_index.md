## WordProcessingComplianceLevel enumeration

Representerar de stödjade OOXML‑kompatibilitetsnivåerna för ordbehandlingsdokument. Den strikta kompatibilitetsnivån kan endast nedgraderas till Transitional, inte till Ecma.

```csharp
public enum WordProcessingComplianceLevel
```

### Värden

| Namn | Värde | Beskrivning |
| --- | --- | --- |
| Ecma | `0` | Anger ECMA-376 1:a upplagan, 2006-efterlevnadsnivå. |
| Transitional | `1` | Anger ISO/IEC 29500:2008 Transitional-efterlevnadsnivå. |
| Strict | `2` | Anger ISO/IEC 29500:2008 Strict-efterlevnadsnivå. |
