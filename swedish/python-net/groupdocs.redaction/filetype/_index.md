## FileType class

Representerar en filtyp.

Läs mer:
- https://docs.groupdocs.com/redaction/net/supported-document-formats/

| Metod | Beskrivning |

| [equals](/redaction/python-net/groupdocs.redaction/filetype/equals/#obj) | Bestämmer om den aktuella [`FileType`](/redaction/python-net/groupdocs.redaction/filetype/) är densamma som det angivna objektet. |
| [equals_file_type](/redaction/python-net/groupdocs.redaction/filetype/equals_file_type/) |  |
| [equals_object](/redaction/python-net/groupdocs.redaction/filetype/equals_object/) |  |
| [from_extension](/redaction/python-net/groupdocs.redaction/filetype/from_extension/#extension) | Kopplar filändelse till filtyp. |
| [get_hash_code](/redaction/python-net/groupdocs.redaction/filetype/get_hash_code/) | Returnerar hashkoden för det aktuella [`FileType`](/redaction/python-net/groupdocs.redaction/filetype/) objektet. |
| [get_supported_file_types](/redaction/python-net/groupdocs.redaction/filetype/get_supported_file_types/) | Hämtar stödda filtyper. |
| [to_string](/redaction/python-net/groupdocs.redaction/filetype/to_string/) | Returnerar en sträng som representerar det aktuella objektet. |

| Egenskap | Beskrivning |

| [extension](/redaction/python-net/groupdocs.redaction/filetype/extension/) | Filnamnstillägget, inklusive den inledande punkten, t.ex. ".doc". |
