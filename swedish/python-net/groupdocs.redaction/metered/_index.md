## Metered class

Hantera mätbaserad (betala-per-användning) licensiering.

Metered‑licenser faktureras baserat på faktisk konsumtion (vanligtvis sidor eller
dokument som bearbetas). Ställ in det offentliga/privata nyckelparet en gång vid
applikationsstart; omslaget rapporterar användning tillbaka till GroupDocs
licensservern i bakgrunden.

Metered‑typen exponerar följande medlemmar:

### Metoder
| Metod | Beskrivning |
| :- | :- |
| [get_consumption_credit](/redaction/python-net/groupdocs.redaction/metered/get_consumption_credit/) | Returnera den återstående mätta krediten för den aktuella nyckeln. |
| [get_consumption_quantity](/redaction/python-net/groupdocs.redaction/metered/get_consumption_quantity/) | Returnera den totala mätta mängden som har förbrukats hittills. |
| [set_metered_key](/redaction/python-net/groupdocs.redaction/metered/set_metered_key/#public_key-private_key) | Aktivera mätt fakturering med det angivna offentliga/privata nyckelparet. |
