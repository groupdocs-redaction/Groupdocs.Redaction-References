## IPaginatedDocument class

Definierar metoder som krävs för att manipulera ett dokuments sidor. Måste implementeras av en [`DocumentFormatInstance`](/redaction/python-net/groupdocs.redaction.integration/documentformatinstance/)-avledd klass för att utföra sidredigeringar.

- More details about applying redactions: https://docs.groupdocs.com/redaction/net/redaction-basics/
- More details about manipulating pages: https://docs.groupdocs.com/redaction/net/remove-page-redaction/

IPaginatedDocument-typen exponerar följande medlemmar:

### Metoder
| Metod | Beskrivning |
| :- | :- |
| [remove_pages](/redaction/python-net/groupdocs.redaction.integration/ipaginateddocument/remove_pages/#origin-index-count) | Tar bort en eller flera sidor beroende på dess startposition, offset och antal. |
| [remove_pages_page_seek_origin](/redaction/python-net/groupdocs.redaction.integration/ipaginateddocument/remove_pages_page_seek_origin/) |  |
