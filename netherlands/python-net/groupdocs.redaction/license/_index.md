## License class

Beheert de licenties van GroupDocs.Redaction.

Gelicentieerde builds ontgrendelen de volledige functionaliteit van de wrapper op
runtime. Ongelicentieerde builds draaien in evaluatiemodus met dezelfde API
oppervlak, maar met limieten op de uitvoergrootte en watergemarkeerde inhoud.
