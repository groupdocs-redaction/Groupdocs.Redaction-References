## DocumentInfo class

Stelt informatie over een document voor.

Meer informatie:

- Get file info: https://docs.groupdocs.com/redaction/net/get-file-info/

Het DocumentInfo-type geeft de volgende leden weer:

### Eigenschappen
| Eigenschap | Beschrijving |
| :- | :- |
| [file_type](/redaction/python-net/groupdocs.redaction/documentinfo/file_type/) | De beschrijving van het bestandsformaat. |
| [page_count](/redaction/python-net/groupdocs.redaction/documentinfo/page_count/) | Het totale aantal pagina's. |
| [pages](/redaction/python-net/groupdocs.redaction/documentinfo/pages/) | De lijst met [`PageInfo`](/redaction/python-net/groupdocs.redaction/pageinfo/) paginainformatie. |
| [size](/redaction/python-net/groupdocs.redaction/documentinfo/size/) | De documentgrootte in bytes. |
