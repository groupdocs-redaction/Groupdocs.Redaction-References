## RedactionStatus class

Het RedactionStatus-type bevat de volgende leden:

### Velden
| Veld | Beschrijving |
| :- | :- |
| [APPLIED](/redaction/python-net/groupdocs.redaction/redactionstatus/applied/) | Redactie was volledig en succesvol toegepast. |
| [PARTIALLY_APPLIED](/redaction/python-net/groupdocs.redaction/redactionstatus/partially_applied/) | Redactie werd alleen toegepast op een deel van de overeenkomsten. |

| [FAILED](/redaction/python-net/groupdocs.redaction/redactionstatus/failed/) | Redactie mislukte met een uitzondering. |
