## FileType class

Stelt een bestandstype voor.

Meer informatie:
- https://docs.groupdocs.com/redaction/net/supported-document-formats/
- https://docs.groupdocs.com/redaction/net/get-supported-file-formats/
- https://docs.groupdocs.com/redaction/net/get-file-info/

Het FileType-type maakt de volgende leden beschikbaar:

### Methoden
| Methode | Beschrijving |
| :- | :- |
| [equals](/redaction/python-net/groupdocs.redaction/filetype/equals/#other) | Bepaalt of het huidige FileType hetzelfde is als het opgegeven FileType-object. |
| [equals](/redaction/python-net/groupdocs.redaction/filetype/equals/#obj) | Bepaalt of het huidige [`FileType`](/redaction/python-net/groupdocs.redaction/filetype/) hetzelfde is als het opgegeven object. |
| [equals_file_type](/redaction/python-net/groupdocs.redaction/filetype/equals_file_type/) |  |
| [equals_object](/redaction/python-net/groupdocs.redaction/filetype/equals_object/) |  |
| [from_extension](/redaction/python-net/groupdocs.redaction/filetype/from_extension/#extension) | Koppelt bestandsextensie aan bestandstype. |
| [get_hash_code](/redaction/python-net/groupdocs.redaction/filetype/get_hash_code/) | Retourneert de hashcode voor het huidige [`FileType`](/redaction/python-net/groupdocs.redaction/filetype/) object. |
| [get_supported_file_types](/redaction/python-net/groupdocs.redaction/filetype/get_supported_file_types/) | Haalt ondersteunde bestandstypen op. |
| [to_string](/redaction/python-net/groupdocs.redaction/filetype/to_string/) | Retourneert een string die het huidige object vertegenwoordigt. |

### Eigenschappen
| Eigenschap | Beschrijving |
| :- | :- |
| [extension](/redaction/python-net/groupdocs.redaction/filetype/extension/) | Het bestandsnaamsuffix, inclusief de leidende punt, bijv. ".doc". |
| [file_format](/redaction/python-net/groupdocs.redaction/filetype/file_format/) | De bestandsformaatnaam, bijvoorbeeld "Microsoft Word Document". |
