## IPaginatedDocument class

Definieert de methoden die nodig zijn om de pagina's van een document te manipuleren. Moet worden geïmplementeerd door een van [`DocumentFormatInstance`](/redaction/python-net/groupdocs.redaction.integration/documentformatinstance/)-afgeleide klasse om paginaredacties uit te voeren.

- More details about applying redactions: https://docs.groupdocs.com/redaction/net/redaction-basics/
- More details about manipulating pages: https://docs.groupdocs.com/redaction/net/remove-page-redaction/

Het type IPaginatedDocument exposeert de volgende leden:

| Methode | Beschrijving |
| :- | :- |
| [remove_pages](/redaction/python-net/groupdocs.redaction.integration/ipaginateddocument/remove_pages/#origin-index-count) | Verwijdert één of meerdere pagina's afhankelijk van de startpositie, offset en aantal. |
