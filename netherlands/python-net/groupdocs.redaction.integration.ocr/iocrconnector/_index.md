## IOcrConnector class

Stelt een connector voor die de benodigde methoden biedt om tekstuele redacties toe te passen op afbeeldingsdocumenten en ingesloten afbeeldingen.

- An example of implementation using Aspose.OCR for Cloud: https://docs.groupdocs.com/redaction/net/use-aspose-ocr-for-cloud/
