De Ocr namespace biedt interfaces en klassen die nodig zijn voor ondersteuning van Optical Character Recognition (OCR).

## Klassen

| Klasse | Beschrijving |
| --- | --- |
| [RecognizedImage](./recognizedimage) | Stelt tekst voor, geëxtraheerd uit een afbeelding als resultaat van het herkenningsproces. |
| [TextFragment](./textfragment) | Stelt een deel van herkende tekst (woord, symbool, enz.) voor, geëxtraheerd door de OCR-engine. |
| [TextLine](./textline) | Stelt een regel tekst voor, geëxtraheerd door de OCR-engine uit een afbeelding. |
## Interfaces

| Interface | Beschrijving |
| --- | --- |
| [IOcrConnector](./iocrconnector) | Definieert methoden die nodig zijn om tekstuele redacties toe te passen op afbeeldingsdocumenten en ingesloten afbeeldingen. |
