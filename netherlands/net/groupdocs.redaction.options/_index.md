De Options namespace biedt klassen voor laad- en opslagopties.

## Klassen

| Klasse | Beschrijving |
| --- | --- |
| [CreatePageStream](./createpagestream) | Stelt een methode voor die een stream retourneert om paginavoorbeeldgegevens te schrijven. |
| [LoadOptions](./loadoptions) | Biedt opties die worden gebruikt om een bestand te openen. |
| [PreviewOptions](./previewoptions) | Biedt opties om vereisten en streamdelegaten in te stellen voor het genereren van een voorbeeld. |
| [RasterizationOptions](./rasterizationoptions) | Biedt opties voor het converteren van bestanden naar PDF. |
| [RedactorSettings](./redactorsettings) | Stelt redactie-instellingen voor, waarmee het redactieproces kan worden aangepast. |
| [ReleasePageStream](./releasepagestream) | Stelt een methode voor die de stream vrijgeeft die is gemaakt door de [`CreatePageStream`](../groupdocs.redaction.options/createpagestream)-delegate. |
| [SaveOptions](./saveoptions) | Biedt opties om de naam van een uitvoerbestand te wijzigen en/of het document te converteren naar een op afbeeldingen gebaseerde PDF (rasterisatie). |
| [WordprocessingSaveOptions](./wordprocessingsaveoptions) | Biedt opslagopties voor tekstverwerkingsdocumenten. |
## Interfaces

| Interface | Beschrijving |
| --- | --- |
| [ILogger](./ilogger) | Definieert de interface van een logger die kan worden gebruikt voor het loggen van gebeurtenissen en fouten tijdens het redactieproces. |
