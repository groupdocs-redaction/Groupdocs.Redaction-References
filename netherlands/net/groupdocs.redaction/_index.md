De Redaction namespace biedt klassen voor het redigeren van gevoelige informatie uit documenten in PDF-, rasterafbeeldings- en kantoordocumentformaten. De belangrijkste klassen in deze namespace zijn:

## Klassen

| Klasse | Beschrijving |
| --- | --- |
| [DocumentInfo](./documentinfo) | Stelt informatie over een document voor. Implementeert de IDocumentInfo-interface. Zie [`IDocumentInfo`](../groupdocs.redaction/idocumentinfo) voor voorbeelden. |
| [FileType](./filetype) | Stelt een bestandstype voor. Biedt methoden om een lijst van alle bestandstypen die door GroupDocs.Redaction worden ondersteund op te halen, het bestandstype te detecteren op basis van extensie, enz. |
| [License](./license) | Biedt methoden voor het toepassen van een licentie. |
| [Metered](./metered) | Biedt methoden waarmee het product kan worden geactiveerd met een Metered-licentie en het aantal verwerkte MB's kan worden opgehaald. Meer informatie over Metered-licenties [hier](https://purchase.groupdocs.com/faqs/licensing/metered). |
| [PageInfo](./pageinfo) | Stelt beknopte paginainformatie voor. |
| [Redaction](./redaction) | Stelt een basis abstracte klasse voor alle redactietypen voor. |
| [RedactionPolicy](./redactionpolicy) | Stelt een sanitatiebeleid voor, dat een reeks specifieke redacties bevat die moeten worden toegepast. |
| [RedactionResult](./redactionresult) | Stelt een resultaat van de redactiebewerking voor. |
| [Redactor](./redactor) | Stelt een hoofdklasse voor die het documentredactietraject beheert, waardoor documenten kunnen worden geopend, geredigeerd en opgeslagen. |
| [RedactorChangeLog](./redactorchangelog) | Stelt resultaten voor een lijst van redacties voor, die worden doorgegeven aan de Apply()-methode van de [`Redactor`](../groupdocs.redaction/redactor) klasse. |
| [RedactorLogEntry](./redactorlogentry) | Stelt resultaten van het toepassen van redacties voor. |
## Interfaces

| Interface | Beschrijving |
| --- | --- |
| [IDocumentInfo](./idocumentinfo) | Definieert methoden die nodig zijn om basisdocumentinformatie op te halen. |
## Enumeratie

| Enumeratie | Beschrijving |
| --- | --- |
| [RedactionStatus](./redactionstatus) | Stelt een status van voltooiing van de redactie voor. |
