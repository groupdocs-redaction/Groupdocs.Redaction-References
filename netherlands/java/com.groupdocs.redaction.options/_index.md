Het pakket biedt klassen voor laad- en opslagopties.



## Klassen

| Klasse | Beschrijving |
| --- | --- |
| [LoadOptions](../com.groupdocs.redaction.options/loadoptions) | Biedt opties die worden gebruikt om een bestand te openen. |
| [PreviewOptions](../com.groupdocs.redaction.options/previewoptions) | Biedt opties om vereisten en streamdelegaten in te stellen voor het genereren van een preview. |
| [RasterizationOptions](../com.groupdocs.redaction.options/rasterizationoptions) | Biedt opties voor het converteren van bestanden naar PDF. |
| [RedactorSettings](../com.groupdocs.redaction.options/redactorsettings) | Stelt redactiesettings voor, waarmee het redactieproces kan worden aangepast. |
| [SaveOptions](../com.groupdocs.redaction.options/saveoptions) | Biedt opties om de naam van een uitvoerbestand te wijzigen en/of het document te converteren naar een op afbeeldingen gebaseerde PDF (rasterisatie). |
| [WordprocessingSaveOptions](../com.groupdocs.redaction.options/wordprocessingsaveoptions) | Opslagopties voor tekstverwerking. |

| Interface | Beschrijving |
