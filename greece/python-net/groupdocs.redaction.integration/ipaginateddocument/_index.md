## IPaginatedDocument class

Ορίζει τις μεθόδους που απαιτούνται για τη διαχείριση των σελίδων ενός εγγράφου. Πρέπει να υλοποιηθεί από μια κλάση που προέρχεται από το [`DocumentFormatInstance`](/redaction/python-net/groupdocs.redaction.integration/documentformatinstance/)-derived για την εκτέλεση διαγραφών σελίδων.

- More details about applying redactions: https://docs.groupdocs.com/redaction/net/redaction-basics/
- More details about manipulating pages: https://docs.groupdocs.com/redaction/net/remove-page-redaction/

Ο τύπος IPaginatedDocument εκθέτει τα ακόλουθα μέλη:
