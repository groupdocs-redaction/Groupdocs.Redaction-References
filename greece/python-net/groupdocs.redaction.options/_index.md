Κλάσεις επιλογών για τη διαμόρφωση μετατροπών και λειτουργιών.

### Κλάσεις
| Κλάση | Περιγραφή |
| :- | :- |
| [`CreatePageStream`](/redaction/python-net/groupdocs.redaction.options/createpagestream/) | Αντιπροσωπεύει μια μέθοδο που επιστρέφει ένα ρεύμα για την εγγραφή δεδομένων προεπισκόπησης σελίδας. |
| [`ILogger`](/redaction/python-net/groupdocs.redaction.options/ilogger/) | Ορίζει μια διεπαφή για έναν καταγραφέα που χρησιμοποιείται για την καταγραφή συμβάντων και σφαλμάτων κατά τη διάρκεια της επεξεργασίας. |
| [`LoadOptions`](/redaction/python-net/groupdocs.redaction.options/loadoptions/) | Παρέχει επιλογές που θα χρησιμοποιηθούν για το άνοιγμα ενός αρχείου. |
| [`PreviewOptions`](/redaction/python-net/groupdocs.redaction.options/previewoptions/) | Παρέχει επιλογές για τον καθορισμό απαιτήσεων και αντιπροσώπων ροής για τη δημιουργία προεπισκόπησης. |
| [`RasterizationOptions`](/redaction/python-net/groupdocs.redaction.options/rasterizationoptions/) | Παρέχει επιλογές για τη μετατροπή αρχείων σε PDF. |
| [`RedactorSettings`](/redaction/python-net/groupdocs.redaction.options/redactorsettings/) | Αντιπροσωπεύει τις ρυθμίσεις επεμβάσεων, επιτρέποντας την προσαρμογή της διαδικασίας επεξεργασίας. |
| [`ReleasePageStream`](/redaction/python-net/groupdocs.redaction.options/releasepagestream/) | Αντιπροσωπεύει μια μέθοδο που απελευθερώνει ένα ρεύμα που δημιουργήθηκε από τον αντιπρόσωπο [`CreatePageStream`](/redaction/python-net/groupdocs.redaction.options/createpagestream/). |
| [`SaveOptions`](/redaction/python-net/groupdocs.redaction.options/saveoptions/) | Παρέχει επιλογές για την αλλαγή του ονόματος του εξαγόμενου αρχείου και/ή τη μετατροπή του εγγράφου σε PDF βασισμένο σε εικόνα (rasterization). |
