## RedactionResult class

Αντιπροσωπεύει το αποτέλεσμα της λειτουργίας επεξεργασίας.

Μάθετε περισσότερα

- More details about redaction results: https://docs.groupdocs.com/redaction/net/redaction-basics/

Ο τύπος RedactionResult εκθέτει τα ακόλουθα μέλη:

### Μέθοδοι
| Μέθοδος | Περιγραφή |
| :- | :- |
| [failed](/redaction/python-net/groupdocs.redaction/redactionresult/failed/#description) | Αρχικοποιεί ένα νέο αντικείμενο RedactionResult με κατάσταση αποτυχίας. |
| [partial](/redaction/python-net/groupdocs.redaction/redactionresult/partial/#description) | Δημιουργεί ένα νέο αντικείμενο [`RedactionResult`](/redaction/python-net/groupdocs.redaction/redactionresult/) με κατάσταση μερικής εφαρμογής. |
| [skipped](/redaction/python-net/groupdocs.redaction/redactionresult/skipped/#description) | Αρχικοποιεί ένα νέο αντικείμενο της κλάσης RedactionResult με κατάσταση Παράλειψη. |
| [successful](/redaction/python-net/groupdocs.redaction/redactionresult/successful/) | Αρχικοποιεί ένα νέο αντικείμενο RedactionResult με κατάσταση εφαρμογής (επιτυχής). |
