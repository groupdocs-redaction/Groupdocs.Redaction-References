Κύριος ονοματικός χώρος GroupDocs.Redaction με κλάσεις API υψηλού επιπέδου.

### Κλάσεις
| Κλάση | Περιγραφή |
| :- | :- |
| [`DocumentInfo`](/redaction/python-net/groupdocs.redaction/documentinfo/) | Αντιπροσωπεύει πληροφορίες σχετικά με ένα έγγραφο. |
| [`FileType`](/redaction/python-net/groupdocs.redaction/filetype/) | Αντιπροσωπεύει έναν τύπο αρχείου. |
| [`IDocumentInfo`](/redaction/python-net/groupdocs.redaction/idocumentinfo/) | Παρέχει τις απαιτούμενες μεθόδους για την λήψη βασικών πληροφοριών εγγράφου. |
| [`License`](/redaction/python-net/groupdocs.redaction/license/) | Διαχειρίζεται την άδεια χρήσης του GroupDocs.Redaction. |
| [`Metered`](/redaction/python-net/groupdocs.redaction/metered/) | Διαχειρίζεται την αδειοδότηση με μέτρηση (πληρωμή ανά χρήση). |
| [`PageInfo`](/redaction/python-net/groupdocs.redaction/pageinfo/) | Αντιπροσωπεύει σύντομες πληροφορίες σελίδας. |
| [`Redaction`](/redaction/python-net/groupdocs.redaction/redaction/) | Αντιπροσωπεύει μια βασική αφηρημένη κλάση για όλους τους τύπους επεμβάσεων. |
| [`RedactionPolicy`](/redaction/python-net/groupdocs.redaction/redactionpolicy/) | Αντιπροσωπεύει μια πολιτική εξαγνισμού, που περιέχει ένα σύνολο συγκεκριμένων επεμβάσεων προς εφαρμογή. |
| [`RedactionResult`](/redaction/python-net/groupdocs.redaction/redactionresult/) | Αντιπροσωπεύει το αποτέλεσμα της λειτουργίας επεξεργασίας. |
| [`Redactor`](/redaction/python-net/groupdocs.redaction/redactor/) | Αντιπροσωπεύει την κύρια κλάση που ελέγχει τη διαδικασία επεξεργασίας εγγράφων, επιτρέποντας το άνοιγμα, την επεξεργασία και την αποθήκευση εγγράφων. |
| [`RedactorChangeLog`](/redaction/python-net/groupdocs.redaction/redactorchangelog/) | Αντιπροσωπεύει τα αποτελέσματα για μια λίστα επεμβάσεων που περάστηκαν στη μέθοδο `Redactor.apply()` method. |
| [`RedactorLogEntry`](/redaction/python-net/groupdocs.redaction/redactorlogentry/) | Αντιπροσωπεύει τα αποτελέσματα της εφαρμογής της απόκρυψης. |
