## RedactionStatus class

Ο τύπος RedactionStatus εκθέτει τα ακόλουθα μέλη:

### Πεδία
| Πεδίο | Περιγραφή |
| :- | :- |
| [APPLIED](/redaction/python-net/groupdocs.redaction/redactionstatus/applied/) | Η Redaction εφαρμόστηκε πλήρως και επιτυχώς. |
| [PARTIALLY_APPLIED](/redaction/python-net/groupdocs.redaction/redactionstatus/partially_applied/) | Η Redaction εφαρμόστηκε μόνο σε μέρος των αντιστοιχίων της. |
| [SKIPPED](/redaction/python-net/groupdocs.redaction/redactionstatus/skipped/) | Η Redaction παραλήφθηκε (δεν εφαρμόστηκε). |
| [FAILED](/redaction/python-net/groupdocs.redaction/redactionstatus/failed/) | Η Redaction απέτυχε με εξαίρεση. |
