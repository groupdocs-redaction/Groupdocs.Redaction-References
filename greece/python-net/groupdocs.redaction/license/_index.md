## License class

Διαχειρίζεται την άδεια χρήσης του GroupDocs.Redaction.

Οι αδειοδοτημένες εκδόσεις ξεκλειδώνουν το πλήρες σύνολο λειτουργιών του wrapper στο
runtime. Οι μη αδειοδοτημένες εκδόσεις λειτουργούν σε λειτουργία αξιολόγησης με το ίδιο API
surface αλλά με περιορισμούς στο μέγεθος εξόδου και το υδατογράφημα περιεχομένου.

Ο τύπος License εκθέτει τα ακόλουθα μέλη:
