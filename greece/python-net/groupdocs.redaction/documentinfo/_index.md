## DocumentInfo class

Αντιπροσωπεύει πληροφορίες σχετικά με ένα έγγραφο.

Μάθετε περισσότερα:

- Get file info: https://docs.groupdocs.com/redaction/net/get-file-info/

Ο τύπος DocumentInfo εκθέτει τα ακόλουθα μέλη:

### Ιδιότητες
| Ιδιότητα | Περιγραφή |
| :- | :- |
| [file_type](/redaction/python-net/groupdocs.redaction/documentinfo/file_type/) | Η περιγραφή μορφής αρχείου. |
| [page_count](/redaction/python-net/groupdocs.redaction/documentinfo/page_count/) | Το συνολικό πλήθος σελίδων. |
| [pages](/redaction/python-net/groupdocs.redaction/documentinfo/pages/) | Η λίστα των πληροφοριών σελίδας [`PageInfo`](/redaction/python-net/groupdocs.redaction/pageinfo/). |
| [size](/redaction/python-net/groupdocs.redaction/documentinfo/size/) | Το μέγεθος του εγγράφου σε byte. |
