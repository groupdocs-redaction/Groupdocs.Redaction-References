## TextRedaction class

Αντιπροσωπεύει μια βασική αφηρημένη κλάση για κειμενικές επεξεργασίες εγγράφου.

Μάθετε περισσότερα

- More details about applying redactions: https://docs.groupdocs.com/redaction/net/redaction-basics/
- More details about document text redactions: https://docs.groupdocs.com/redaction/net/text-redactions/

Ο τύπος TextRedaction εκθέτει τα ακόλουθα μέλη:

### Μέθοδοι
| Μέθοδος | Περιγραφή |
| :- | :- |
| [apply_to](/redaction/python-net/groupdocs.redaction/redaction/apply_to/) | Εφαρμόζει τη διαγραφή σε ένα δεδομένο παράδειγμα μορφής. (κληρονομείται από [`Redaction`](/redaction/python-net/groupdocs.redaction/redaction/)) |
| [apply_to_document_format_instance](/redaction/python-net/groupdocs.redaction/redaction/apply_to_document_format_instance/) | (κληρονομείται από [`Redaction`](/redaction/python-net/groupdocs.redaction/redaction/)) |

### Ιδιότητες
| Ιδιότητα | Περιγραφή |
| :- | :- |
| [action_options](/redaction/python-net/groupdocs.redaction.redactions/textredaction/action_options/) | Το παράδειγμα [`ReplacementOptions`](/redaction/python-net/groupdocs.redaction.redactions/replacementoptions/) που καθορίζει τον τύπο αντικατάστασης κειμένου. |
| [ocr_connector](/redaction/python-net/groupdocs.redaction.redactions/textredaction/ocr_connector/) | Η υλοποίηση IOcrConnector που χρησιμοποιείται για την εξαγωγή κειμένου από γραφικό περιεχόμενο. |
| [description](/redaction/python-net/groupdocs.redaction/redaction/description/) | Η περιγραφή της διαγραφής, που περιέχει το όνομά της και τις παραμέτρους. (κληρονομείται από [`Redaction`](/redaction/python-net/groupdocs.redaction/redaction/)) |
