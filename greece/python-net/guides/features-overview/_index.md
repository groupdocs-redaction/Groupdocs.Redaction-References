Το GroupDocs.Redaction for Python μέσω .NET αφαιρεί ή μόνιμα κρύβει ευαίσθητες πληροφορίες σε ένα ευρύ φάσμα [supported document formats](). Κάθε αφαίρεση ακολουθεί την ίδια ροή εργασίας: ανοίξτε ένα έγγραφο με [`Redactor`](/redaction/python-net/groupdocs.redaction/redactor/), εφαρμόστε μία ή περισσότερες αφαίρεσεις με `apply()`, έπειτα `save()` το καθαρισμένο αποτέλεσμα είτε στην αρχική μορφή του είτε ως εξαγορευμένο PDF. Οι δυνατότητες παρακάτω μπορούν να συνδυαστούν ελεύθερα σε μία μόνο διέλευση.

## Text redaction

Βρείτε και αντικαταστήστε κείμενο με ακριβή φράση ή με κανονική έκφραση, καλύπτοντας τόσο ολόκληρες λέξεις όσο και σύνθετα μοτίβα όπως διευθύνσεις email, αριθμούς τηλεφώνου ή αριθμούς εθνικού ταυτοπροσωπίου. Το αντιστοιχισμένο κείμενο μπορεί να αντικατασταθεί με εναλλακτικό κείμενο ή να καλυφθεί με χρωματιστό πλαίσιο ώστε το αρχικό περιεχόμενο να μην μπορεί να ανακτηθεί. Σε λογιστικά φύλλα μπορείτε να περιορίσετε την αναζήτηση σε ένα μόνο φύλλο εργασίας ή στήλη. Δείτε [Text Redactions]().

## Metadata redaction

Διαγράψτε ή ξαναγράψτε τα μεταδεδομένα του εγγράφου — συγγραφέας, τίτλος, εταιρεία, σχόλια και δεδομένα EXIF στις εικόνες — ώστε καμία ευαίσθητη πληροφορία να μην διαρρεύσει μέσω των ιδιοτήτων του εγγράφου. Μπορείτε να διαγράψετε όλα τα μεταδεδομένα, να στοχεύσετε συγκεκριμένα πεδία ή να αντικαταστήσετε τις τιμές με νέες. Δείτε [Metadata Redactions]().

## Image-area redaction

Σκοτεινιάστε μια ορθογώνια περιοχή μιας ενσωματωμένης εικόνας ή μιας σαρωμένης σελίδας σχεδιάζοντας ένα γεμάτο πλαίσιο πάνω σε μια καθορισμένη περιοχή — χρήσιμο για την απόκρυψη υπογραφών, φωτογραφιών, κεφαλίδων ή υποσέλιδων όπου αναμένεται να εμφανιστούν εμπιστευτικά δεδομένα. Δείτε [Image Redactions]().

## Annotation redaction

Ξαναγράψτε ή διαγράψτε τις σημειώσεις, τα σχόλια και τις σημειώσεις. Μπορείτε να αφαιρέσετε κάθε σημείωση ή να χρησιμοποιήσετε κανονική έκφραση για να ταιριάξετε μόνο αυτές που περιέχουν ευαίσθητο κείμενο. Δείτε [Annotation Redactions]().

## Page removal

Αφαιρέστε ολόκληρες σελίδες από έγγραφα PDF, διαφάνειες από παρουσιάσεις και φύλλα εργασίας από λογιστικά φύλλα. Καθορίζετε μια αρχική σελίδα και έναν αριθμό, μαζί με την κατεύθυνση σε σχέση με το σημείο έναρξης. Δείτε [Remove Page Redactions]().

## Rasterization to PDF

Αποθηκεύστε το καθαρισμένο έγγραφο ως PDF του οποίου οι σελίδες αποδίδονται ως raster εικόνες. Το προκύπτον αρχείο δεν περιέχει αναζητήσιμο κείμενο ούτε τα αρχικά μεταδεδομένα, ώστε το αφαιρεθέν περιεχόμενο να μην μπορεί να ανακτηθεί. Η rasterization είναι η σωστή επιλογή όταν πρέπει να παραδώσετε ένα έγγραφο σε τρίτους ή να συμμορφωθείτε με κανονισμούς που απαιτούν PDF. Μπορείτε να επιλέξετε συγκεκριμένες σελίδες και να ζητήσετε συμμόρφωση με PDF/A μέσω των προχωρημένων επιλογών rasterization. Δείτε [Save in Rasterized PDF]() και [Advanced Rasterization Options]().

## Redaction policies

Ομαδοποιήστε πολλές επεμβάσεις σε μια επαναχρησιμοποιήσιμη πολιτική και εφαρμόστε το ίδιο σύνολο κανόνων σταθερά σε πολλά έγγραφα — ιδανικό για επαναλαμβανόμενες εργασίες όπως ο καθαρισμός ενός τυπικού συνόλου πεδίων πριν τη δημοσίευση. Δείτε [Use Redaction Policies]().

## Loading and saving

Φορτώστε έγγραφα από τοπική διαδρομή ή από ροή, συμπεριλαμβανομένων αρχείων με προστασία κωδικού, και προαιρετικά προ‑rasterize ένα έγγραφο πριν την επεξεργασία. Κατά την αποθήκευση, διατηρήστε την αρχική μορφή για περαιτέρω επεξεργασία, αντικαταστήστε το αρχικό αρχείο, rasterize σε PDF ή γράψτε σε ροή. Δείτε [Loading Documents]() και [Saving Documents]().

## On-premise

Το GroupDocs.Redaction for Python via .NET εκτελείται πλήρως στην δική σας υποδομή — τα έγγραφά σας δεν αφήνουν ποτέ το περιβάλλον σας. Το πακέτο είναι ένας αυτόνομος wheel που περιλαμβάνει όλα όσα χρειάζεται, ώστε να μην χρειάζεται να εγκατασταθεί το Microsoft Office, OpenOffice, Adobe Acrobat ή ξεχωριστό runtime. Δείτε [System Requirements]() για τις υποστηριζόμενες πλατφόρμες και τις εγγενείς εξαρτήσεις.
