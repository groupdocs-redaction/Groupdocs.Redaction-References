Το πακέτο παρέχει διεπαφές και κλάσεις, που χρησιμοποιούνται για την ενσωμάτωση εγγράφων διαφορετικών μορφών με το GroupDocs.Redactions.



## Κλάσεις

| Κλάση | Περιγραφή |
| --- | --- |
| [DocumentFormatInstance](../com.groupdocs.redaction.integration/documentformatinstance) | Αντιπροσωπεύει μια συγκεκριμένη μορφή εγγράφου. |
| [MetadataCollection](../com.groupdocs.redaction.integration/metadatacollection) | Αντιπροσωπεύει ένα λεξικό των MetadataItem με τον τίτλο του ως κλειδί. |
| [MetadataItem](../com.groupdocs.redaction.integration/metadataitem) | Αντιπροσωπεύει ένα στοιχείο μεταδεδομένων, κοινό για όλες τις υποστηριζόμενες μορφές και χρησιμοποιείται σε διαγραφές μεταδεδομένων. |
| [RecognizedImage](../com.groupdocs.redaction.integration/recognizedimage) | Αντιπροσωπεύει κείμενο, εξαγόμενο από μια εικόνα ως αποτέλεσμα της διαδικασίας αναγνώρισής της. |
| [RedactableImage](../com.groupdocs.redaction.integration/redactableimage) | Παρέχει διεπαφή για όλες τις λειτουργίες διαγραφής ραστερ εικόνων. |
| [TextFragment](../com.groupdocs.redaction.integration/textfragment) | Αντιπροσωπεύει ένα μέρος του αναγνωρισμένου κειμένου (λέξη, σύμβολο κ.λπ.), εξαγόμενο από τη μηχανή OCR. |
| [TextLine](../com.groupdocs.redaction.integration/textline) | Αντιπροσωπεύει μια γραμμή κειμένου, εξαγόμενη από τη μηχανή OCR από μια εικόνα. |

## Διεπαφές

| Διεπαφή | Περιγραφή |

| [IAnnotatedDocument](../com.groupdocs.redaction.integration/iannotateddocument) | Ορίζει μεθόδους που απαιτούνται για πρόσβαση σε σημειώσεις, όπως σχόλια. |
| [ICellularFormatInstance](../com.groupdocs.redaction.integration/icellularformatinstance) | Ορίζει μεθόδους που απαιτούνται για πρόσβαση σε μορφές λογιστικών φύλλων, με ένα ή πολλά φύλλα εργασίας. |
| [IFixedFormatDocument](../com.groupdocs.redaction.integration/ifixedformatdocument) | Ορίζει μεθόδους που απαιτούνται για πρόσβαση σε μορφές σταθερής δομής, όπως PDF ή παρουσιάσεις. |
| [IImageFormatInstance](../com.groupdocs.redaction.integration/iimageformatinstance) | Ορίζει μεθόδους που απαιτούνται για διαγραφές μορφής ραστερ εικόνας. |
| [IMetadataAccess](../com.groupdocs.redaction.integration/imetadataaccess) | Ορίζει μεθόδους που απαιτούνται για πρόσβαση στα μεταδεδομένα ενός εγγράφου, εάν η μορφή το υποστηρίζει. |
| [IMultipleAreaRedactable](../com.groupdocs.redaction.integration/imultiplearearedactable) | Ορίζει μεθόδους που απαιτούνται για διαγραφή πολλαπλών περιοχών εικόνας ταυτόχρονα με το ίδιο χρώμα. |
| [IOcrConnector](../com.groupdocs.redaction.integration/iocrconnector) | Ορίζει μεθόδους που απαιτούνται για εφαρμογή κειμενικών διαγραφών σε έγγραφα εικόνας και ενσωματωμένες εικόνες. |
| [IPaginatedDocument](../com.groupdocs.redaction.integration/ipaginateddocument) | Ορίζει μεθόδους που απαιτούνται για τη διαχείριση των σελίδων ενός εγγράφου. |
| [IPreviewable](../com.groupdocs.redaction.integration/ipreviewable) | Ορίζει μεθόδους για τη δημιουργία προεπισκόπησης του εγγράφου. |
| [IRasterizableDocument](../com.groupdocs.redaction.integration/irasterizabledocument) | Ορίζει μεθόδους που απαιτούνται για αποθήκευση εγγράφου σε οποιαδήποτε δυαδική μορφή. |
| [ITextualFormatInstance](../com.groupdocs.redaction.integration/itextualformatinstance) | Ορίζει μεθόδους που απαιτούνται για διαγραφή κειμενικών δεδομένων σε οποιοδήποτε έγγραφο που περιέχει κείμενο. |
