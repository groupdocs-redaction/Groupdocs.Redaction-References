Το πακέτο παρέχει κλάσεις για τη διαγραφή ευαίσθητων πληροφοριών από έγγραφα σε μορφές PDF, raster εικόνας και έγγραφα γραφείου.

Οι κύριες κλάσεις σε αυτό το πακέτο είναι:

<br />

* [Redactor](../../com.groupdocs.redaction/redactor) is the entry point for redaction process.
* [Redaction](../../com.groupdocs.redaction/redaction) is abstract base class for all types of document redactions.
* [RedactionPolicy](../../com.groupdocs.redaction/redactionpolicy) is pre-configured in XML set of redaction rules.
* [RedactorChangeLog](../../com.groupdocs.redaction/redactorchangelog) provides information about redaction process results.

<br />




## Κλάσεις

| Κλάση | Περιγραφή |
| --- | --- |
| [DocumentInfo](../com.groupdocs.redaction/documentinfo) | Αντιπροσωπεύει πληροφορίες σχετικά με το έγγραφο. |
| [FileType](../com.groupdocs.redaction/filetype) | Αντιπροσωπεύει έναν τύπο αρχείου. |
| [PageInfo](../com.groupdocs.redaction/pageinfo) | Αντιπροσωπεύει σύντομες πληροφορίες σελίδας. |
| [Redaction](../com.groupdocs.redaction/redaction) | Αντιπροσωπεύει μια βασική αφηρημένη κλάση για όλους τους τύπους απόκρυψης. |
| [RedactionPolicy](../com.groupdocs.redaction/redactionpolicy) | Αντιπροσωπεύει μια πολιτική εξαγνισμού, η οποία περιέχει ένα σύνολο συγκεκριμένων αποκρύψεων προς εφαρμογή. |
| [RedactionResult](../com.groupdocs.redaction/redactionresult) | Αντιπροσωπεύει το αποτέλεσμα της λειτουργίας απόκρυψης. |
| [Redactor](../com.groupdocs.redaction/redactor) | Αντιπροσωπεύει την κύρια κλάση που ελέγχει τη διαδικασία απόκρυψης εγγράφων, επιτρέποντας το άνοιγμα, την απόκρυψη και την αποθήκευση εγγράφων. |
| [RedactorChangeLog](../com.groupdocs.redaction/redactorchangelog) | Αντιπροσωπεύει τα αποτελέσματα για μια λίστα αποκρύψεων, που περνιούνται στη μέθοδο Apply() της κλάσης Redactor. |
| [RedactorLogEntry](../com.groupdocs.redaction/redactorlogentry) | Αντιπροσωπεύει τα αποτελέσματα της εφαρμογής της απόκρυψης. |
