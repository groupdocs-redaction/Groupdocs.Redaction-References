Το πακέτο παρέχει κλάσεις επιλογών φόρτωσης και αποθήκευσης.



## Κλάσεις

| Κλάση | Περιγραφή |
| --- | --- |
| [LoadOptions](../com.groupdocs.redaction.options/loadoptions) | Παρέχει επιλογές που θα χρησιμοποιηθούν για το άνοιγμα ενός αρχείου. |
| [PreviewOptions](../com.groupdocs.redaction.options/previewoptions) | Παρέχει επιλογές για τον καθορισμό απαιτήσεων και διαχειριστών ροής για τη δημιουργία προεπισκόπησης. |
| [RasterizationOptions](../com.groupdocs.redaction.options/rasterizationoptions) | Παρέχει επιλογές για τη μετατροπή αρχείων σε PDF. |
| [RedactorSettings](../com.groupdocs.redaction.options/redactorsettings) | Αντιπροσωπεύει τις ρυθμίσεις επεξεργασίας, επιτρέποντας την προσαρμογή της διαδικασίας επεξεργασίας. |
| [SaveOptions](../com.groupdocs.redaction.options/saveoptions) | Παρέχει επιλογές για την αλλαγή του ονόματος του αρχείου εξόδου και/ή τη μετατροπή του εγγράφου σε PDF βασισμένο σε εικόνες (rasterization). |
| [WordprocessingSaveOptions](../com.groupdocs.redaction.options/wordprocessingsaveoptions) | Επιλογές αποθήκευσης επεξεργασίας κειμένου. |

## Διεπαφές

| Διεπαφή | Περιγραφή |
| --- | --- |
| [ICreatePageStream](../com.groupdocs.redaction.options/icreatepagestream) | Παρέχει μέθοδο που επιστρέφει μια ροή για την εγγραφή δεδομένων προεπισκόπησης σελίδας. |
| [ILogger](../com.groupdocs.redaction.options/ilogger) | Ορίζει τη διεπαφή ενός καταγραφέα που μπορεί να χρησιμοποιηθεί για την καταγραφή συμβάντων και σφαλμάτων στη διαδικασία επεξεργασίας. |
| [IReleasePageStream](../com.groupdocs.redaction.options/ireleasepagestream) | Αντιπροσωπεύει μια μέθοδο που απελευθερώνει τη ροή που δημιουργήθηκε από τον delegate CreatePageStream. |

## Απαριθμήσεις

| Απαρίθμηση | Περιγραφή |
| --- | --- |
| [AdvancedRasterizationOptions](../com.groupdocs.redaction.options/advancedrasterizationoptions) | Μια απαρίθμηση για τη διαχείριση των προχωρημένων επιλογών rasterization που θα εφαρμοστούν. |
| [PdfComplianceLevel](../com.groupdocs.redaction.options/pdfcompliancelevel) | Αντιπροσωπεύει μια λίστα με τα υποστηριζόμενα επίπεδα συμμόρφωσης PDF. |
| [PreviewFormats](../com.groupdocs.redaction.options/previewformats) | Αντιπροσωπεύει τα υποστηριζόμενα μορφότυπα προεπισκόπησης. |
| [WordProcessingComplianceLevel](../com.groupdocs.redaction.options/wordprocessingcompliancelevel) | Επίπεδα συμμόρφωσης OOXML για έγγραφα επεξεργασίας κειμένου. |
