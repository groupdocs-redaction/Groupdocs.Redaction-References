Το πακέτο παρέχει κλάσεις για διαφορετικούς τύπους διαγραφών.



## Κλάσεις

| Κλάση | Περιγραφή |
| --- | --- |
| [AnnotationRedaction](../com.groupdocs.redaction.redactions/annotationredaction) | Αντιπροσωπεύει μια επεξεργασία που αντικαθιστά το κείμενο σχολίων (σχόλια κ.λπ.) που ταιριάζει με μια δεδομένη κανονική έκφραση. |
| [CellColumnRedaction](../com.groupdocs.redaction.redactions/cellcolumnredaction) | Αντιπροσωπεύει μια επεξεργασία κειμένου που αντικαθιστά κείμενο σε έγγραφα λογιστικού φύλλου (CSV, Excel κ.λπ.). |
| [CellFilter](../com.groupdocs.redaction.redactions/cellfilter) | Παρέχει μια επιλογή για τον περιορισμό του πεδίου μιας CellColumnRedaction σε ένα φύλλο εργασίας και μια στήλη. |
| [CustomRedactionContext](../com.groupdocs.redaction.redactions/customredactioncontext) | Παρέχει δεδομένα εισόδου για [ICustomRedactionHandler](../com.groupdocs.redaction.redactions/icustomredactionhandler). |
| [CustomRedactionResult](../com.groupdocs.redaction.redactions/customredactionresult) | Αντιπροσωπεύει ένα αποτέλεσμα που επιστρέφεται από το [ICustomRedactionHandler](../com.groupdocs.redaction.redactions/icustomredactionhandler). |
| [DeleteAnnotationRedaction](../com.groupdocs.redaction.redactions/deleteannotationredaction) | Αντιπροσωπεύει μια επεξεργασία κειμένου που διαγράφει σχόλια εάν το κείμενο ταιριάζει με τη δεδομένη κανονική έκφραση (προαιρετικά διαγράφει όλα τα σχόλια). |
| [EraseMetadataRedaction](../com.groupdocs.redaction.redactions/erasemetadataredaction) | Αντιπροσωπεύει μια επεξεργασία μεταδεδομένων που διαγράφει όλα τα μεταδεδομένα ή τα μεταδεδομένα που ταιριάζουν με συγκεκριμένα MetadataFilters από το έγγραφο. |
| [ExactPhraseRedaction](../com.groupdocs.redaction.redactions/exactphraseredaction) | Αντιπροσωπεύει μια επεξεργασία κειμένου που αντικαθιστά ακριβή φράση στο κείμενο του εγγράφου, χωρίς διάκριση πεζών-κεφαλαίων από προεπιλογή. |
| [ImageAreaRedaction](../com.groupdocs.redaction.redactions/imagearearedaction) | Αντιπροσωπεύει μια επεξεργασία που τοποθετεί χρωματιστό ορθογώνιο στην καθορισμένη περιοχή ενός εγγράφου εικόνας. |
| [MetadataFilters](../com.groupdocs.redaction.redactions/metadatafilters) | Αντιπροσωπεύει μια λίστα με τους πιο συνηθισμένους τύπους μεταδεδομένων εγγράφου. |
| [MetadataRedaction](../com.groupdocs.redaction.redactions/metadataredaction) | Αντιπροσωπεύει μια βασική αφηρημένη κλάση για διαγραφές μεταδεδομένων εγγράφου. |
| [MetadataSearchRedaction](../com.groupdocs.redaction.redactions/metadatasearchredaction) | Αντιπροσωπεύει μια διαγραφή μεταδεδομένων που αναζητά και διαγράφει μεταδεδομένα χρησιμοποιώντας κανονικές εκφράσεις, ταιριάζοντας κλειδιά και/ή τιμές. |
| [PageAreaFilter](../com.groupdocs.redaction.redactions/pageareafilter) | Αντιπροσωπεύει φίλτρο διαγραφής, ορίζοντας μια περιοχή μέσα σε μια σελίδα εγγράφου για την εφαρμογή διαγραφής. |
| [PageAreaRedaction](../com.groupdocs.redaction.redactions/pagearearedaction) | Αντιπροσωπεύει μια σύνθετη κειμενική διαγραφή που επηρεάζει κείμενο, εικόνες και σημειώσεις σε μια περιοχή της σελίδας. |
| [PageRangeFilter](../com.groupdocs.redaction.redactions/pagerangefilter) | Αντιπροσωπεύει φίλτρο διαγραφής, ορίζοντας εύρος σελίδων μέσα σε ένα έγγραφο για την εφαρμογή διαγραφής. |
| [RedactionDescription](../com.groupdocs.redaction.redactions/redactiondescription) | Αντιπροσωπεύει πληροφορίες μιας μοναδικής ενέργειας αλλαγής που εκτελέστηκε κατά τη διαδικασία διαγραφής. |
| [RedactionFilter](../com.groupdocs.redaction.redactions/redactionfilter) | Αντιπροσωπεύει φίλτρο διαγραφής, ορίζοντας το πεδίο μέσα σε ένα έγγραφο για την εφαρμογή διαγραφών. |
| [RedactionType](../com.groupdocs.redaction.redactions/redactiontype) | Αντιπροσωπεύει έναν τύπο δεδομένων εγγράφου, που επηρεάζεται από τη διαγραφή. |
| [RegexRedaction](../com.groupdocs.redaction.redactions/regexredaction) | Αντιπροσωπεύει μια κειμενική διαγραφή που αναζητά και αντικαθιστά κείμενο στο έγγραφο ταιριάζοντας με την παρεχόμενη κανονική έκφραση. |
| [RegionReplacementOptions](../com.groupdocs.redaction.redactions/regionreplacementoptions) | Αντιπροσωπεύει παραμέτρους χρώματος και περιοχής για αντικατάσταση περιοχής εικόνας. |
| [RemovePageRedaction](../com.groupdocs.redaction.redactions/removepageredaction) | Αντιπροσωπεύει μια διαγραφή που αφαιρεί μια σελίδα (διαφάνεια, φύλλο εργασίας κ.λπ.) από ένα έγγραφο. |
| [ReplacementOptions](../com.groupdocs.redaction.redactions/replacementoptions) | Αντιπροσωπεύει επιλογές για αντικατάσταση ταιριασμένου κειμένου. |
| [TextRedaction](../com.groupdocs.redaction.redactions/textredaction) | Αντιπροσωπεύει μια βασική αφηρημένη κλάση για κειμενικές διαγραφές εγγράφου. |
| [TextReplacement](../com.groupdocs.redaction.redactions/textreplacement) | Αντιπροσωπεύει πληροφορίες κειμενικής αντικατάστασης. |
