Το namespace Options παρέχει κλάσεις επιλογών φόρτωσης και αποθήκευσης.

## Κλάσεις

| Κλάση | Περιγραφή |
| --- | --- |
| [CreatePageStream](./createpagestream) | Αντιπροσωπεύει τη μέθοδο που επιστρέφει ένα stream για την εγγραφή δεδομένων προεπισκόπησης σελίδας. |
| [LoadOptions](./loadoptions) | Παρέχει επιλογές που θα χρησιμοποιηθούν για το άνοιγμα ενός αρχείου. |
| [PreviewOptions](./previewoptions) | Παρέχει επιλογές για τον ορισμό απαιτήσεων και των delegates του stream για τη δημιουργία προεπισκόπησης. |
| [RasterizationOptions](./rasterizationoptions) | Παρέχει επιλογές για τη μετατροπή αρχείων σε PDF. |
| [RedactorSettings](./redactorsettings) | Αντιπροσωπεύει τις ρυθμίσεις διαγραφής, επιτρέποντας την προσαρμογή της διαδικασίας διαγραφής. |
| [ReleasePageStream](./releasepagestream) | Αντιπροσωπεύει μια μέθοδο που απελευθερώνει το stream που δημιουργήθηκε από τον delegate [`CreatePageStream`](../groupdocs.redaction.options/createpagestream). |
| [SaveOptions](./saveoptions) | Παρέχει επιλογές για την αλλαγή του ονόματος του αρχείου εξόδου και/ή τη μετατροπή του εγγράφου σε PDF βασισμένο σε εικόνα (rasterization). |
| [WordprocessingSaveOptions](./wordprocessingsaveoptions) | Παρέχει επιλογές αποθήκευσης για έγγραφα επεξεργασίας κειμένου. |
## Διεπαφές

| Διεπαφή | Περιγραφή |
| --- | --- |
| [ILogger](./ilogger) | Ορίζει τη διεπαφή ενός καταγραφέα που μπορεί να χρησιμοποιηθεί για την καταγραφή συμβάντων και σφαλμάτων στη διαδικασία διαγραφής. |
## Απαρίθμηση

| Απαρίθμηση | Περιγραφή |
| --- | --- |
| [AdvancedRasterizationOptions](./advancedrasterizationoptions) | Απαρίθμηση σημαίας για τη διαχείριση των προχωρημένων επιλογών rasterization που θα εφαρμοστούν. |
| [PdfComplianceLevel](./pdfcompliancelevel) | Αντιπροσωπεύει μια λίστα με τα υποστηριζόμενα επίπεδα συμμόρφωσης PDF. |
| [PreviewOptions.PreviewFormats](./previewoptions.previewformats) | Αντιπροσωπεύει τις υποστηριζόμενες μορφές προεπισκόπησης. |
| [WordProcessingComplianceLevel](./wordprocessingcompliancelevel) | Αντιπροσωπεύει τα υποστηριζόμενα επίπεδα συμμόρφωσης OOXML για έγγραφα επεξεργασίας κειμένου. Το επίπεδο Strict μπορεί να υποβαθμιστεί μόνο σε Transitional, όχι σε Ecma. |
