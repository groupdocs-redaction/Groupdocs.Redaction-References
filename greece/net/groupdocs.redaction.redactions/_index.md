Το namespace Redactions παρέχει κλάσεις για διαφορετικούς τύπους διαγραφών.

## Κλάσεις

| Κλάση | Περιγραφή |
| --- | --- |
| [AnnotationRedaction](./annotationredaction) | Αντιπροσωπεύει μια απόκρυψη που αντικαθιστά το κείμενο σχολίων (σχόλια, κ.λπ.) που ταιριάζει με μια δεδομένη κανονική έκφραση. |
| [CellColumnRedaction](./cellcolumnredaction) | Αντιπροσωπεύει μια κειμενική απόκρυψη που αντικαθιστά κείμενο σε έγγραφα λογιστικού φύλλου (CSV, Excel, κ.λπ.). |
| [CellFilter](./cellfilter) | Παρέχει μια επιλογή για τον περιορισμό του πεδίου μιας [`CellColumnRedaction`](../groupdocs.redaction.redactions/cellcolumnredaction) σε ένα φύλλο εργασίας και μια στήλη. |
| [CustomRedactionContext](./customredactioncontext) | Παρέχει συμφραζόμενα για την προσαρμοσμένη επεξεργασία απόκρυψης. |
| [CustomRedactionResult](./customredactionresult) | Αντιπροσωπεύει το αποτέλεσμα μιας προσαρμοσμένης λειτουργίας απόκρυψης. |
| [DeleteAnnotationRedaction](./deleteannotationredaction) | Αντιπροσωπεύει μια κειμενική απόκρυψη που διαγράφει τα σχόλια εάν το κείμενο ταιριάζει με τη δεδομένη κανονική έκφραση (προαιρετικά διαγράφει όλα τα σχόλια). |
| [EraseMetadataRedaction](./erasemetadataredaction) | Αντιπροσωπεύει μια διαγραφή μεταδεδομένων που διαγράφει όλα τα μεταδεδομένα ή τα μεταδεδομένα που ταιριάζουν με συγκεκριμένα MetadataFilters από το έγγραφο. |
| [ExactPhraseRedaction](./exactphraseredaction) | Αντιπροσωπεύει μια διαγραφή κειμένου που αντικαθιστά ακριβή φράση στο κείμενο του εγγράφου, χωρίς διάκριση πεζών-κεφαλαίων από προεπιλογή. |
| [ImageAreaRedaction](./imagearearedaction) | Αντιπροσωπεύει μια διαγραφή που τοποθετεί χρωματιστό ορθογώνιο στην καθορισμένη περιοχή ενός εγγράφου εικόνας. |
| [MetadataRedaction](./metadataredaction) | Αντιπροσωπεύει μια βασική αφηρημένη κλάση για διαγραφές μεταδεδομένων εγγράφου. |
| [MetadataSearchRedaction](./metadatasearchredaction) | Αντιπροσωπεύει μια διαγραφή μεταδεδομένων που αναζητά και διαγράφει μεταδεδομένα χρησιμοποιώντας κανονικές εκφράσεις, ταιριάζοντας κλειδιά και/ή τιμές. |
| [PageAreaFilter](./pageareafilter) | Αντιπροσωπεύει φίλτρο διαγραφής, ορίζοντας μια περιοχή μέσα σε μια σελίδα εγγράφου για την εφαρμογή της διαγραφής. |
| [PageAreaRedaction](./pagearearedaction) | Αντιπροσωπεύει μια σύνθετη κειμενική διαγραφή που επηρεάζει κείμενο, εικόνες και σημειώσεις σε μια περιοχή της σελίδας. |
| [PageRangeFilter](./pagerangefilter) | Αντιπροσωπεύει φίλτρο διαγραφής, ορίζοντας εύρος σελίδων μέσα σε ένα έγγραφο για την εφαρμογή της διαγραφής. |
| [RedactionDescription](./redactiondescription) | Αντιπροσωπεύει πληροφορίες μιας μοναδικής ενέργειας αλλαγής που εκτελέστηκε κατά τη διαδικασία διαγραφής. |
| [RedactionFilter](./redactionfilter) | Αντιπροσωπεύει φίλτρο διαγραφής, ορίζοντας το πεδίο μέσα σε ένα έγγραφο για την εφαρμογή διαγραφών. |
| [RegexRedaction](./regexredaction) | Αντιπροσωπεύει μια διαγραφή κειμένου που αναζητά και αντικαθιστά κείμενο στο έγγραφο ταιριάζοντας με την παρεχόμενη κανονική έκφραση. |
| [RegionReplacementOptions](./regionreplacementoptions) | Αντιπροσωπεύει παραμέτρους χρώματος και περιοχής για αντικατάσταση περιοχής εικόνας. Δείτε [`ImageAreaRedaction`](../groupdocs.redaction.redactions/imagearearedaction). |
| [RemovePageRedaction](./removepageredaction) | Αντιπροσωπεύει μια διαγραφή που αφαιρεί μια σελίδα (διαφάνεια, φύλλο εργασίας κ.λπ.) από ένα έγγραφο. |
| [ReplacementOptions](./replacementoptions) | Αντιπροσωπεύει επιλογές για αντικατάσταση ταιριασμένου κειμένου. |
| [TextRedaction](./textredaction) | Αντιπροσωπεύει μια βασική αφηρημένη κλάση για διαγραφές κειμένου εγγράφου. |
| [TextReplacement](./textreplacement) | Αντιπροσωπεύει πληροφορίες αντικατάστασης κειμένου. |
## Διεπαφές

| Διεπαφή | Περιγραφή |
| --- | --- |
| [ICustomRedactionHandler](./icustomredactionhandler) | Παρέχει μια διεπαφή για την υλοποίηση προσαρμοσμένης λογικής διαγραφής. |
| [IRedactionCallback](./iredactioncallback) | Ορίζει μεθόδους που απαιτούνται για τη λήψη πληροφοριών για κάθε αλλαγή διαγραφής και προαιρετικά την αποτροπή της. |
