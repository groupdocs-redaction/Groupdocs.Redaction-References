Το namespace Redaction παρέχει κλάσεις για τη διαγραφή ευαίσθητων πληροφοριών από έγγραφα σε μορφές PDF, raster image και έγγραφα γραφείου. Οι κύριες κλάσεις σε αυτό το namespace είναι:

## Κλάσεις

| Κλάση | Περιγραφή |
| --- | --- |
| [DocumentInfo](./documentinfo) | Αντιπροσωπεύει πληροφορίες σχετικά με το έγγραφο. Υλοποιεί τη διεπαφή IDocumentInfo. Δείτε το [`IDocumentInfo`](../groupdocs.redaction/idocumentinfo) για παραδείγματα. |
| [FileType](./filetype) | Αντιπροσωπεύει έναν τύπο αρχείου. Παρέχει μεθόδους για την λήψη λίστας όλων των τύπων αρχείων που υποστηρίζονται από το GroupDocs.Redaction, την ανίχνευση τύπου αρχείου με βάση την επέκταση, κ.λπ. |
| [License](./license) | Παρέχει μεθόδους για την εφαρμογή άδειας. |
| [Metered](./metered) | Παρέχει μεθόδους που επιτρέπουν την ενεργοποίηση του προϊόντος με άδεια Metered και την ανάκτηση του ποσού των επεξεργασμένων MB. Μάθετε περισσότερα για τις άδειες Metered [εδώ](https://purchase.groupdocs.com/faqs/licensing/metered). |
| [PageInfo](./pageinfo) | Αντιπροσωπεύει σύντομες πληροφορίες σελίδας. |
| [Redaction](./redaction) | Αντιπροσωπεύει μια βασική αφηρημένη κλάση για όλους τους τύπους απόκρυψης. |
| [RedactionPolicy](./redactionpolicy) | Αντιπροσωπεύει μια πολιτική εξαγνισμού, που περιέχει ένα σύνολο συγκεκριμένων απόκρυψεων προς εφαρμογή. |
| [RedactionResult](./redactionresult) | Αντιπροσωπεύει το αποτέλεσμα της λειτουργίας απόκρυψης. |
| [Redactor](./redactor) | Αντιπροσωπεύει την κύρια κλάση που ελέγχει τη διαδικασία απόκρυψης εγγράφων, επιτρέποντας το άνοιγμα, την απόκρυψη και την αποθήκευση εγγράφων. |
| [RedactorChangeLog](./redactorchangelog) | Αντιπροσωπεύει τα αποτελέσματα για μια λίστα απόκρυψεων, που περνιούνται στη μέθοδο Apply() της κλάσης [`Redactor`](../groupdocs.redaction/redactor). |
| [RedactorLogEntry](./redactorlogentry) | Αντιπροσωπεύει τα αποτελέσματα της εφαρμογής απόκρυψης. |
## Διεπαφές

| Διεπαφή | Περιγραφή |
| --- | --- |
| [IDocumentInfo](./idocumentinfo) | Ορίζει μεθόδους που απαιτούνται για την λήψη βασικών πληροφοριών εγγράφου. |

| Απαρίθμηση | Περιγραφή |
| --- | --- |
| [RedactionStatus](./redactionstatus) | Αντιπροσωπεύει την κατάσταση ολοκλήρωσης της απόκρυψης. |
