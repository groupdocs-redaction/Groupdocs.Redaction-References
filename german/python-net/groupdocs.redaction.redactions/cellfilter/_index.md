## CellFilter class

Bietet eine Option, den Geltungsbereich einer [`CellColumnRedaction`](/redaction/python-net/groupdocs.redaction.redactions/cellcolumnredaction/) auf ein Arbeitsblatt und eine Spalte zu beschränken.
