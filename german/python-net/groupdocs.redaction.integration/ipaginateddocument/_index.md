## IPaginatedDocument class

Definiert Methoden, die für die Manipulation von Dokumentseiten erforderlich sind. Muss von einer von [`DocumentFormatInstance`](/redaction/python-net/groupdocs.redaction.integration/documentformatinstance/)-abgeleiteten Klasse implementiert werden, um Seiten-Redaktionen durchzuführen.

- More details about applying redactions: https://docs.groupdocs.com/redaction/net/redaction-basics/
- More details about manipulating pages: https://docs.groupdocs.com/redaction/net/remove-page-redaction/

Der Typ IPaginatedDocument stellt die folgenden Mitglieder bereit:

| Methode | Beschreibung |
| :- | :- |
| [remove_pages](/redaction/python-net/groupdocs.redaction.integration/ipaginateddocument/remove_pages/#origin-index-count) | Entfernt eine oder mehrere Seiten abhängig von ihrer Startposition, dem Versatz und der Anzahl. |
