Typen unter `groupdocs.redaction.integration`.

### Klassen
| Klasse | Beschreibung |
| :- | :- |
| [`DocumentFormatInstance`](/redaction/python-net/groupdocs.redaction.integration/documentformatinstance/) | Stellt ein bestimmtes Format eines Dokuments dar und kann implementiert werden, um benutzerdefinierte Dokumenttypen hinzuzufügen. |
| [`IAnnotatedDocument`](/redaction/python-net/groupdocs.redaction.integration/iannotateddocument/) | Definiert Methoden, die für den Zugriff auf Anmerkungen, wie Kommentare, erforderlich sind, und muss von einer von [`DocumentFormatInstance`](/redaction/python-net/groupdocs.redaction.integration/documentformatinstance/)-abgeleiteten Klasse implementiert werden, um Anmerkungs-Redaktionen durchzuführen. |
| [`ICellularFormatInstance`](/redaction/python-net/groupdocs.redaction.integration/icellularformatinstance/) | Definiert Methoden, die für den Zugriff auf Tabellenkalkulationsformate erforderlich sind, die ein oder mehrere Arbeitsblätter enthalten. |
| [`IFixedFormatDocument`](/redaction/python-net/groupdocs.redaction.integration/ifixedformatdocument/) | Definiert Methoden, die für den Zugriff auf Formate mit fester Struktur erforderlich sind, wie PDF oder Präsentationen. |
| [`IImageFormatInstance`](/redaction/python-net/groupdocs.redaction.integration/iimageformatinstance/) | Definiert Methoden, die für Rasterbildformat-Redaktionen erforderlich sind. |
| [`IMetadataAccess`](/redaction/python-net/groupdocs.redaction.integration/imetadataaccess/) | Definiert Methoden, die für den Zugriff auf Metadaten eines Dokuments erforderlich sind, falls das Format dies unterstützt. |
| [`IPaginatedDocument`](/redaction/python-net/groupdocs.redaction.integration/ipaginateddocument/) | Definiert Methoden, die für die Manipulation von Dokumentseiten erforderlich sind. Muss von einer von [`DocumentFormatInstance`](/redaction/python-net/groupdocs.redaction.integration/documentformatinstance/)-abgeleiteten Klasse implementiert werden, um Seiten-Redaktionen durchzuführen. |
| [`IPreviewable`](/redaction/python-net/groupdocs.redaction.integration/ipreviewable/) | Definiert Methoden zur Erstellung einer Vorschau des Dokuments. |
| [`IRasterizableDocument`](/redaction/python-net/groupdocs.redaction.integration/irasterizabledocument/) | Definiert Methoden, die zum Speichern eines Dokuments in beliebiger Binärform erforderlich sind. Eingebaute Typen speichern ein Dokument als PDF mit Bildern seiner Seiten. |
| [`ITextualFormatInstance`](/redaction/python-net/groupdocs.redaction.integration/itextualformatinstance/) | Stellt eine Schnittstelle dar, die Methoden definiert, die für die Redaktion von Textdaten in jedem Dokument, das Text enthält, erforderlich sind. |
| [`MetadataCollection`](/redaction/python-net/groupdocs.redaction.integration/metadatacollection/) | Stellt ein Wörterbuch von [`MetadataItem`](/redaction/python-net/groupdocs.redaction.integration/metadataitem/) dar, wobei der Titel als Schlüssel dient. |
| [`MetadataItem`](/redaction/python-net/groupdocs.redaction.integration/metadataitem/) | Stellt ein Metadaten‑Element dar, das für alle unterstützten Formate üblich ist und bei Metadaten‑Redaktionen verwendet wird. |
