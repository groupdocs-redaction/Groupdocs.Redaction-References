## License class

Verwaltet die Lizenzierung von GroupDocs.Redaction.

Lizensierte Builds schalten den vollen Funktionsumfang des Wrappers frei bei
Laufzeit. Unlizenzierte Builds laufen im Evaluierungsmodus mit derselben API
Oberfläche, jedoch mit Beschränkungen der Ausgabengröße und wassergezeichneten Inhalten.

Der Lizenztyp stellt die folgenden Mitglieder bereit:
