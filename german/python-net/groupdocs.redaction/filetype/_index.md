## FileType class

Stellt einen Dateityp dar.

Mehr erfahren:
- https://docs.groupdocs.com/redaction/net/supported-document-formats/
- https://docs.groupdocs.com/redaction/net/get-supported-file-formats/
- https://docs.groupdocs.com/redaction/net/get-file-info/

Der FileType-Typ stellt die folgenden Mitglieder bereit:

### Methoden
| Methode | Beschreibung |
| :- | :- |
| [equals](/redaction/python-net/groupdocs.redaction/filetype/equals/#other) | Bestimmt, ob der aktuelle FileType derselbe ist wie das angegebene FileType-Objekt. |
| [equals](/redaction/python-net/groupdocs.redaction/filetype/equals/#obj) | Bestimmt, ob der aktuelle [`FileType`](/redaction/python-net/groupdocs.redaction/filetype/) derselbe ist wie das angegebene Objekt. |
| [equals_file_type](/redaction/python-net/groupdocs.redaction/filetype/equals_file_type/) |  |
| [equals_object](/redaction/python-net/groupdocs.redaction/filetype/equals_object/) |  |
| [from_extension](/redaction/python-net/groupdocs.redaction/filetype/from_extension/#extension) | Ordnet Dateierweiterungen dem Dateityp zu. |
| [get_hash_code](/redaction/python-net/groupdocs.redaction/filetype/get_hash_code/) | Gibt den Hashcode für das aktuelle [`FileType`](/redaction/python-net/groupdocs.redaction/filetype/) Objekt zurück. |
| [get_supported_file_types](/redaction/python-net/groupdocs.redaction/filetype/get_supported_file_types/) | Ruft unterstützte Dateitypen ab. |
| [to_string](/redaction/python-net/groupdocs.redaction/filetype/to_string/) | Gibt eine Zeichenkette zurück, die das aktuelle Objekt darstellt. |

### Eigenschaften
| Eigenschaft | Beschreibung |
| :- | :- |
| [extension](/redaction/python-net/groupdocs.redaction/filetype/extension/) | Der Dateinamensuffix, einschließlich des führenden Punktes, z. B. ".doc". |
| [file_format](/redaction/python-net/groupdocs.redaction/filetype/file_format/) | Der Dateiformatname, zum Beispiel "Microsoft Word Document". |
