## Metered class

Verwaltet die nutzungsbasierte (Pay‑per‑Use) Lizenzierung.

Metered-Lizenzen werden nach tatsächlichem Verbrauch abgerechnet (typischerweise Seiten oder
verarbeitete Dokumente). Setzen Sie das öffentliche/ private Schlüsselpaar einmal bei
Anwendungsstart; der Wrapper meldet die Nutzung zurück an die GroupDocs
Lizenzserver im Hintergrund.

Der Metered-Typ stellt die folgenden Mitglieder bereit:

### Methoden
| Methode | Beschreibung |
| :- | :- |
| [get_consumption_credit](/redaction/python-net/groupdocs.redaction/metered/get_consumption_credit/) | Geben Sie das verbleibende gemessene Guthaben für den aktuellen Schlüssel zurück. |
| [get_consumption_quantity](/redaction/python-net/groupdocs.redaction/metered/get_consumption_quantity/) | Geben Sie die bisher verbrauchte gesamte gemessene Menge zurück. |
| [set_metered_key](/redaction/python-net/groupdocs.redaction/metered/set_metered_key/#public_key-private_key) | Aktivieren Sie die gemessene Abrechnung mit dem angegebenen öffentlichen/privaten Schlüsselpaar. |
