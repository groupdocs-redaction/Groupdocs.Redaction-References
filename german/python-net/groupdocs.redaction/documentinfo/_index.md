## DocumentInfo class

Stellt Informationen über ein Dokument dar.

Mehr erfahren:

- Get file info: https://docs.groupdocs.com/redaction/net/get-file-info/

Der DocumentInfo-Typ stellt die folgenden Mitglieder bereit:

### Eigenschaften
| Eigenschaft | Beschreibung |
| :- | :- |
| [file_type](/redaction/python-net/groupdocs.redaction/documentinfo/file_type/) | Die Dateiformatbeschreibung. |
| [page_count](/redaction/python-net/groupdocs.redaction/documentinfo/page_count/) | Die Gesamtseitenzahl. |
| [pages](/redaction/python-net/groupdocs.redaction/documentinfo/pages/) | Die Liste der [`PageInfo`](/redaction/python-net/groupdocs.redaction/pageinfo/) Seiteninformationen. |
| [size](/redaction/python-net/groupdocs.redaction/documentinfo/size/) | Die Dokumentgröße in Bytes. |
