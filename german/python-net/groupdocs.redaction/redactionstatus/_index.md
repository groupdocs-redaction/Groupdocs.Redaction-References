## RedactionStatus class

Der Typ RedactionStatus stellt die folgenden Mitglieder bereit:

### Felder
| Feld | Beschreibung |
| :- | :- |
| [APPLIED](/redaction/python-net/groupdocs.redaction/redactionstatus/applied/) | Redaction wurde vollständig und erfolgreich angewendet. |
| [PARTIALLY_APPLIED](/redaction/python-net/groupdocs.redaction/redactionstatus/partially_applied/) | Redaction wurde nur auf einen Teil seiner Treffer angewendet. |
| [SKIPPED](/redaction/python-net/groupdocs.redaction/redactionstatus/skipped/) | Redaction wurde übersprungen (nicht angewendet). |
| [FAILED](/redaction/python-net/groupdocs.redaction/redactionstatus/failed/) | Redaction ist mit einer Ausnahme fehlgeschlagen. |
