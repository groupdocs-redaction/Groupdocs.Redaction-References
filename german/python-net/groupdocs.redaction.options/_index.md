Option-Klassen zur Konfiguration von Konvertierungen und Vorgängen.

### Klassen
| Klasse | Beschreibung |
| :- | :- |
| [`CreatePageStream`](/redaction/python-net/groupdocs.redaction.options/createpagestream/) | Stellt eine Methode dar, die einen Stream zurückgibt, um Seitenvorschau‑Daten zu schreiben. |
| [`ILogger`](/redaction/python-net/groupdocs.redaction.options/ilogger/) | Definiert ein Interface für einen Logger, der verwendet wird, um Ereignisse und Fehler während der Redaktion aufzuzeichnen. |
| [`LoadOptions`](/redaction/python-net/groupdocs.redaction.options/loadoptions/) | Stellt Optionen bereit, die zum Öffnen einer Datei verwendet werden. |
| [`PreviewOptions`](/redaction/python-net/groupdocs.redaction.options/previewoptions/) | Stellt Optionen bereit, um Anforderungen und Stream‑Delegaten für die Generierung von Vorschauen festzulegen. |
| [`RasterizationOptions`](/redaction/python-net/groupdocs.redaction.options/rasterizationoptions/) | Stellt Optionen zum Konvertieren von Dateien in PDF bereit. |
| [`RedactorSettings`](/redaction/python-net/groupdocs.redaction.options/redactorsettings/) | Stellt Redaktions‑Einstellungen dar, die eine Anpassung des Redaktionsprozesses ermöglichen. |
| [`ReleasePageStream`](/redaction/python-net/groupdocs.redaction.options/releasepagestream/) | Stellt eine Methode dar, die einen von dem [`CreatePageStream`](/redaction/python-net/groupdocs.redaction.options/createpagestream/)‑Delegaten erstellten Stream freigibt. |
| [`SaveOptions`](/redaction/python-net/groupdocs.redaction.options/saveoptions/) | Stellt Optionen zum Ändern eines Ausgabedateinamens und/oder zum Konvertieren des Dokuments in ein bildbasiertes PDF (Rasterisierung) bereit. |
