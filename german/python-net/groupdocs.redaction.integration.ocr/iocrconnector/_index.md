## IOcrConnector class

Stellt einen Connector dar, der die zum Anwenden von textuellen Redaktionen auf Bilddokumente und eingebettete Bilder erforderlichen Methoden bereitstellt.

Mehr erfahren:
- More details about using OCR in GroupDocs.Redaction: https://docs.groupdocs.com/redaction/net/ocr-usage-basics/
- An example of implementation using Aspose.OCR for Cloud: https://docs.groupdocs.com/redaction/net/use-aspose-ocr-for-cloud/
- An example of implementation using Microsoft Azure Cognitive Services: https://docs.groupdocs.com/redaction/net/use-microsoft-azure-computer-vision/

Der IOcrConnector-Typ stellt die folgenden Mitglieder bereit:
