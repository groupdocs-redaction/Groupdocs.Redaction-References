### Beispiele

Das folgende Beispiel zeigt die Durchführung einer groß‑ und kleinschreibungssensitiven Phrasensuche und -Ersetzung.

```csharp
using (Redactor redactor = new Redactor(@"C:\sample.pdf"))
{
  // Standardmäßig ist isCaseSensitive = false;
  doc.Apply(new ExactPhraseRedaction("John Doe", true /*isCaseSensitive*/, new ReplacementOptions("[personal]")));
  doc.Save();
}
```

Das folgende Beispiel zeigt das Ersetzen einer Phrase (ohne Groß‑ und Kleinschreibung) durch ein einfarbiges rotes Rechteck.

```csharp
using (Redactor redactor = new Redactor(@"C:\sample.pdf"))
{
  // Standardmäßig ist isCaseSensitive = false;
  doc.Apply(new ExactPhraseRedaction("John Doe", new ReplacementOptions(GroupDocs.Redaction.Options.Drawing.Color.Red)));
  doc.Save();
}
```
