## DeleteAnnotationRedaction class

### Beispiele

Das folgende Beispiel zeigt, wie man alle Anmerkungen, die die Wörter "use", "show" oder "describe" enthalten, aus dem Dokument entfernt (und andere beibehält).

```csharp
using (Redactor redactor = new Redactor(@"D:\test.docx"))
{
   redactor.Apply(new DeleteAnnotationRedaction("(?im:(use|show|describe))"));
   redactor.Save()
}
```
