## AdvancedRasterizationOptions enumeration

Flag‑Aufzählung zur Verwaltung der anzuwendenden erweiterten Rasterisierungsoptionen.

```csharp
public enum AdvancedRasterizationOptions
```

### Werte

| Name | Wert | Beschreibung |
| --- | --- | --- |
| None | `0` | Keine erweiterten Optionen anzuwenden. |
| Tilt | `1` | Neigen, um das rasterisierte Bild um einen zufälligen Winkel zu kippen. |
| Noise | `2` | Füge zufällige Punkte zu rasterisierten Seitenbildern hinzu. |
| Border | `4` | Füge eine Randlinie hinzu, um den Scan‑Effekt einer Seite zu imitieren. |
| Grayscale | `8` | Wandle Seitenbilder in Graustufen um, um einen Graustufen‑Scan zu imitieren. |

### Beispiele

Das folgende Beispiel zeigt, wie die erweiterten Rasterisierungsoptionen mit den Standardeinstellungen angewendet werden.

```csharp
    using (Redactor redactor = new Redactor(@"C:\sample.docx"))
    {
      // Dokument mit Standardoptionen speichern (Seiten in Bilder konvertieren, als PDF speichern)
      var so = new SaveOptions();
      so.Rasterization.Enabled = true;
      so.RedactedFileSuffix = "_scan";
      so.Rasterization.AddAdvancedOption(AdvancedRasterizationOptions.Border);
      so.Rasterization.AddAdvancedOption(AdvancedRasterizationOptions.Noise);
      so.Rasterization.AddAdvancedOption(AdvancedRasterizationOptions.Grayscale);
      so.Rasterization.AddAdvancedOption(AdvancedRasterizationOptions.Tilt);
      redactor.Save(so);
    }
```
