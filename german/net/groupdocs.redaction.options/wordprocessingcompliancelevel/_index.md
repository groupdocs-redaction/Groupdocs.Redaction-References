## WordProcessingComplianceLevel enumeration

Stellt die unterstützten OOXML‑Konformitätsstufen für Textverarbeitungsdokumente dar. Die strenge Konformitätsstufe kann nur auf Transitional herabgestuft werden, nicht auf Ecma.

```csharp
public enum WordProcessingComplianceLevel
```

### Werte

| Name | Wert | Beschreibung |
| --- | --- | --- |
| Ecma | `0` | Gibt die ECMA-376 1. Ausgabe, 2006, Konformitätsstufe an. |
| Transitional | `1` | Gibt die ISO/IEC 29500:2008 Transitional-Konformitätsstufe an. |
| Strict | `2` | Gibt das ISO/IEC 29500:2008 Strict‑Konformitätsniveau an. |
