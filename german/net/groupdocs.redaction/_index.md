Der Redaction-Namespace stellt Klassen zum Redigieren sensibler Informationen aus Dokumenten in PDF-, Rasterbild- und Office‑Dokumentenformaten bereit. Die wichtigsten Klassen in diesem Namespace sind:

## Klassen

| Klasse | Beschreibung |
| --- | --- |
| [DocumentInfo](./documentinfo) | Stellt Informationen über ein Dokument dar. Implementiert die IDocumentInfo‑Schnittstelle. Siehe [`IDocumentInfo`](../groupdocs.redaction/idocumentinfo) für Beispiele. |
| [FileType](./filetype) | Stellt einen Dateityp dar. Bietet Methoden, um eine Liste aller von GroupDocs.Redaction unterstützten Dateitypen zu erhalten, den Dateityp anhand der Erweiterung zu erkennen usw. |
| [License](./license) | Bietet Methoden zum Anwenden einer Lizenz. |
| [Metered](./metered) | Bietet Methoden, die es ermöglichen, das Produkt mit einer Metered-Lizenz zu aktivieren und die Menge der verarbeiteten MB abzurufen. Weitere Informationen zu Metered-Lizenzen [hier](https://purchase.groupdocs.com/faqs/licensing/metered). |
| [PageInfo](./pageinfo) | Stellt eine kurze Seiteninformation dar. |
| [Redaction](./redaction) | Stellt eine abstrakte Basisklasse für alle Redaktionstypen dar. |
| [RedactionPolicy](./redactionpolicy) | Stellt eine Bereinigungspolicy dar, die einen Satz spezifischer Redaktionen enthält, die angewendet werden sollen. |
| [RedactionResult](./redactionresult) | Stellt das Ergebnis der Redaktionsoperation dar. |
| [Redactor](./redactor) | Stellt die Hauptklasse dar, die den Dokumenten-Redaktionsprozess steuert und das Öffnen, Redigieren und Speichern von Dokumenten ermöglicht. |
| [RedactorChangeLog](./redactorchangelog) | Stellt Ergebnisse für eine Liste von Redaktionen dar, die an die Apply()-Methode der [`Redactor`](../groupdocs.redaction/redactor)-Klasse übergeben werden. |
| [RedactorLogEntry](./redactorlogentry) | Stellt die Ergebnisse der Anwendung einer Redaktion dar. |
