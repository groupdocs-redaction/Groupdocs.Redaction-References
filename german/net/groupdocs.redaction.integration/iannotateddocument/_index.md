## IAnnotatedDocument interface

Definiert Methoden, die für den Zugriff auf Anmerkungen, wie Kommentare, erforderlich sind. Muss von einer [`DocumentFormatInstance`](../documentformatinstance)-abgeleiteten Klasse implementiert werden, um Anmerkungs‑Redaktionen durchzuführen.
