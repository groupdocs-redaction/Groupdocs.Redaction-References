Der Integration-Namespace stellt Schnittstellen und Klassen bereit, die verwendet werden, um Dokumente verschiedener Formate mit GroupDocs.Redaction zu integrieren.

## Klassen

| Klasse | Beschreibung |
| --- | --- |
| [DocumentFormatInstance](./documentformatinstance) | Stellt ein spezifisches Format eines Dokuments dar. Implementieren Sie diese Klasse, um eigene Dokumenttypen hinzuzufügen. |
| [MetadataCollection](./metadatacollection) | Stellt ein Wörterbuch von [`MetadataItem`](../groupdocs.redaction.integration/metadataitem) mit dessen Titel als Schlüssel dar. |
| [MetadataItem](./metadataitem) | Stellt ein Metadaten‑Element dar, das für alle unterstützten Formate gemeinsam ist und in Metadaten‑Redaktionen verwendet wird. |
## Schnittstellen

| Schnittstelle | Beschreibung |
| --- | --- |
| [IAnnotatedDocument](./iannotateddocument) | Definiert Methoden, die für den Zugriff auf Anmerkungen, wie Kommentare, erforderlich sind. Muss von einer von [`DocumentFormatInstance`](../groupdocs.redaction.integration/documentformatinstance) abgeleiteten Klasse implementiert werden, um Anmerkungs‑Redaktionen durchzuführen. |
| [ICellularFormatInstance](./icellularformatinstance) | Definiert Methoden, die für den Zugriff auf Tabellenkalkulationsformate erforderlich sind und ein oder mehrere Arbeitsblätter enthalten. |
| [IFixedFormatDocument](./ifixedformatdocument) | Definiert Methoden, die für den Zugriff auf Formate mit fester Struktur, wie PDF oder Präsentationen, erforderlich sind. |
| [IImageFormatInstance](./iimageformatinstance) | Definiert Methoden, die für die Redaktion von Rasterbildformaten erforderlich sind. |
| [IMetadataAccess](./imetadataaccess) | Definiert Methoden, die für den Zugriff auf Metadaten eines Dokuments erforderlich sind, sofern das Format dies unterstützt. |

| [IPreviewable](./ipreviewable) | Definiert Methoden zur Erstellung einer Vorschau des Dokuments. |
| [IRasterizableDocument](./irasterizabledocument) | Definiert Methoden, die zum Speichern eines Dokuments in beliebiger Binärform erforderlich sind. Eingebaute Typen speichern ein Dokument als PDF mit Bildern seiner Seiten. |
| [ITextualFormatInstance](./itextualformatinstance) | Definiert Methoden, die für die Redaktion von Textdaten in jedem Dokument, das Text enthält, erforderlich sind. |
