Das Paket stellt Klassen zum Redigieren sensibler Informationen aus Dokumenten in PDF-, Rasterbild- und Office-Dokumentformaten bereit.

Die Hauptklassen in diesem Paket sind:

<br />

* [Redactor](../../com.groupdocs.redaction/redactor) is the entry point for redaction process.
* [Redaction](../../com.groupdocs.redaction/redaction) is abstract base class for all types of document redactions.
* [RedactionPolicy](../../com.groupdocs.redaction/redactionpolicy) is pre-configured in XML set of redaction rules.
* [RedactorChangeLog](../../com.groupdocs.redaction/redactorchangelog) provides information about redaction process results.

<br />




## Klassen

| Klasse | Beschreibung |
| --- | --- |
| [DocumentInfo](../com.groupdocs.redaction/documentinfo) | Stellt Informationen über ein Dokument dar. |
| [FileType](../com.groupdocs.redaction/filetype) | Stellt einen Dateityp dar. |
| [PageInfo](../com.groupdocs.redaction/pageinfo) | Stellt eine kurze Seiteninformation dar. |
| [Redaction](../com.groupdocs.redaction/redaction) | Stellt eine Basis-abstrakte Klasse für alle Redaktionsarten dar. |
| [RedactionPolicy](../com.groupdocs.redaction/redactionpolicy) | Stellt eine Bereinigungsrichtlinie dar, die einen Satz spezifischer Redaktionen enthält, die angewendet werden sollen. |
| [RedactionResult](../com.groupdocs.redaction/redactionresult) | Stellt ein Ergebnis der Redaktionsoperation dar. |
| [Redactor](../com.groupdocs.redaction/redactor) | Stellt die Hauptklasse dar, die den Dokumenten-Redaktionsprozess steuert und das Öffnen, Redigieren und Speichern von Dokumenten ermöglicht. |
| [RedactorChangeLog](../com.groupdocs.redaction/redactorchangelog) | Stellt Ergebnisse für eine Liste von Redaktionen dar, die an die Methode Apply() der Klasse Redactor übergeben werden. |
| [RedactorLogEntry](../com.groupdocs.redaction/redactorlogentry) | Stellt Ergebnisse der Anwendung von Redaktionen dar. |
