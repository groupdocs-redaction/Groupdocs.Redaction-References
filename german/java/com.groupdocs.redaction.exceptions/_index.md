Das Paket stellt verschiedene Ausnahme-Klassen bereit.



## Klassen

| Klasse | Beschreibung |
| --- | --- |
| [DocumentFormatException](../com.groupdocs.redaction.exceptions/documentformatexception) | Die Ausnahme, die ausgelöst wird, wenn das Dokumentformat nicht erkannt wird oder ungültig ist. |
| [GroupDocsRedactionException](../com.groupdocs.redaction.exceptions/groupdocsredactionexception) | Stellt die Basisausnahme für alle GroupDocs.Redaction-Ausnahmen dar. |
| [IncorrectPasswordException](../com.groupdocs.redaction.exceptions/incorrectpasswordexception) | Die Ausnahme, die ausgelöst wird, wenn das angegebene Passwort falsch ist. |
| [PasswordRequiredException](../com.groupdocs.redaction.exceptions/passwordrequiredexception) | Die Ausnahme, die ausgelöst wird, wenn zum Laden des Dokuments ein Passwort erforderlich ist. |
| [TrialLimitationsException](../com.groupdocs.redaction.exceptions/triallimitationsexception) | Die Ausnahme, die ausgelöst wird, wenn der Benutzer die Einschränkungen des Testmodus verletzt. |
