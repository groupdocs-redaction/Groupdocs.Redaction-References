Das Paket stellt Klassen für Lade- und Speicheroptionen bereit.



## Klassen

| Klasse | Beschreibung |
| --- | --- |
| [LoadOptions](../com.groupdocs.redaction.options/loadoptions) | Stellt Optionen bereit, die zum Öffnen einer Datei verwendet werden. |
| [PreviewOptions](../com.groupdocs.redaction.options/previewoptions) | Stellt Optionen bereit, um Anforderungen und Stream-Delegaten für die Vorschauerstellung festzulegen. |
| [RasterizationOptions](../com.groupdocs.redaction.options/rasterizationoptions) | Stellt Optionen zum Konvertieren von Dateien in PDF bereit. |
| [RedactorSettings](../com.groupdocs.redaction.options/redactorsettings) | Stellt Redaktions‑Einstellungen dar, die es ermöglichen, den Redaktionsprozess anzupassen. |
| [SaveOptions](../com.groupdocs.redaction.options/saveoptions) | Bietet Optionen zum Ändern eines Ausgabedateinamens und/oder zur Konvertierung des Dokuments in ein bildbasiertes PDF (Rasterisierung). |
| [WordprocessingSaveOptions](../com.groupdocs.redaction.options/wordprocessingsaveoptions) | Speicheroptionen für die Textverarbeitung. |

## Schnittstellen

| Schnittstelle | Beschreibung |
| --- | --- |
| [ICreatePageStream](../com.groupdocs.redaction.options/icreatepagestream) | Stellt eine Methode bereit, die einen Stream zurückgibt, um Seitenvorschau‑Daten zu schreiben. |
| [ILogger](../com.groupdocs.redaction.options/ilogger) | Definiert eine Schnittstelle eines Loggers, der für das Protokollieren von Ereignissen und Fehlern im Redaktionsprozess verwendet werden kann. |
| [IReleasePageStream](../com.groupdocs.redaction.options/ireleasepagestream) | Stellt eine Methode dar, die den von dem CreatePageStream‑Delegaten erstellten Stream freigibt. |

## Aufzählungen

| Aufzählung | Beschreibung |
| --- | --- |
| [AdvancedRasterizationOptions](../com.groupdocs.redaction.options/advancedrasterizationoptions) | Eine Aufzählung zur Verwaltung der anzuwendenden erweiterten Rasterisierungsoptionen. |
| [PdfComplianceLevel](../com.groupdocs.redaction.options/pdfcompliancelevel) | Stellt eine Liste der unterstützten PDF‑Konformitätsstufen dar. |
| [PreviewFormats](../com.groupdocs.redaction.options/previewformats) | Stellt unterstützte Vorschauformate dar. |
| [WordProcessingComplianceLevel](../com.groupdocs.redaction.options/wordprocessingcompliancelevel) | OOXML‑Konformitätsstufen für Textverarbeitungsdokumente. |
