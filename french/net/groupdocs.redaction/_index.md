L’espace de noms Redaction fournit des classes permettant de masquer les informations sensibles des documents au format PDF, image raster et documents bureautiques. Les principales classes de cet espace de noms sont :

## Classes

| Classe | Description |
| --- | --- |
| [DocumentInfo](./documentinfo) | Représente des informations sur le document. Implémente l'interface IDocumentInfo. Voir [`IDocumentInfo`](../groupdocs.redaction/idocumentinfo) pour des exemples. |
| [FileType](./filetype) | Représente un type de fichier. Fournit des méthodes pour obtenir une liste de tous les types de fichiers pris en charge par GroupDocs.Redaction, détecter le type de fichier par extension, etc. |
| [License](./license) | Fournit des méthodes pour appliquer une licence. |
| [Metered](./metered) | Fournit des méthodes qui permettent d'activer le produit avec une licence à la consommation et de récupérer la quantité de Mo traités. En savoir plus sur les licences à la consommation [ici](https://purchase.groupdocs.com/faqs/licensing/metered). |
| [PageInfo](./pageinfo) | Représente une brève information de page. |
| [Redaction](./redaction) | Représente une classe abstraite de base pour tous les types de rédaction. |
| [RedactionPolicy](./redactionpolicy) | Représente une politique de désinfection, contenant un ensemble de rédactions spécifiques à appliquer. |
| [RedactionResult](./redactionresult) | Représente le résultat de l'opération de rédaction. |
| [Redactor](./redactor) | Représente la classe principale qui contrôle le processus de rédaction de documents, permettant d'ouvrir, de rédiger et d'enregistrer des documents. |
| [RedactorChangeLog](./redactorchangelog) | Représente les résultats pour une liste de rédactions, transmis à la méthode Apply() de la classe [`Redactor`](../groupdocs.redaction/redactor). |
| [RedactorLogEntry](./redactorlogentry) | Représente les résultats de l'application de la rédaction. |
## Interfaces

| Interface | Description |
| --- | --- |
| [IDocumentInfo](./idocumentinfo) | Définit les méthodes nécessaires pour obtenir les informations de base du document. |
