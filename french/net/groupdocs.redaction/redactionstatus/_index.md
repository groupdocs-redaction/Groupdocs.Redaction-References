## RedactionStatus enumeration

Représente un statut d'achèvement de la rédaction.

```csharp
public enum RedactionStatus
```

### Valeurs

| Nom | Valeur | Description |
| --- | --- | --- |
| Applied | `0` | Redaction a été entièrement et avec succès appliquée. |
| PartiallyApplied | `1` | Redaction a été appliquée uniquement à une partie de ses correspondances. |
| Skipped | `2` | Redaction a été ignorée (non appliquée). |
| Failed | `3` | Redaction a échoué avec une exception. |
