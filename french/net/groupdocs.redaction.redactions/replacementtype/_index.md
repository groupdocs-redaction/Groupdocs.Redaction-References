## ReplacementType enumeration

Représente un type de remplacement pour le texte correspondant.

```csharp
public enum ReplacementType
```

### Valeurs

| Nom | Valeur | Description |
| --- | --- | --- |
| ReplaceString | `0` | Remplace le texte correspondant par une autre chaîne, par exemple le code d'exemption. |
| DrawBox | `1` | Dessine un rectangle d'une couleur spécifique (Noir par défaut) à la place du texte censuré. |
