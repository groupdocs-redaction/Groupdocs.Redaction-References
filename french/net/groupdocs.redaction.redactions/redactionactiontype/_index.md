## RedactionActionType enumeration

Représente les actions qui peuvent être effectuées pour réaliser une rédaction.

```csharp
public enum RedactionActionType
```

### Valeurs

| Nom | Valeur | Description |
| --- | --- | --- |
| Replacement | `0` | Le texte rédigé a été remplacé par un autre ou recouvert d'un bloc. |
| Cleanup | `1` | Les données ont été supprimées, mais un objet vide reste dans le document. |
| Deletion | `2` | Les données et les structures associées ont été supprimées du document. |
