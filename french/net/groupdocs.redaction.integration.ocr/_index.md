L’espace de noms Ocr fournit des interfaces et des classes requises pour la prise en charge de la reconnaissance optique de caractères (OCR).

## Classes

| Classe | Description |
| --- | --- |
| [RecognizedImage](./recognizedimage) | Représente le texte extrait d'une image à la suite de son processus de reconnaissance. |
| [TextFragment](./textfragment) | Représente une partie du texte reconnu (mot, symbole, etc.), extraite par le moteur OCR. |
| [TextLine](./textline) | Représente une ligne de texte extraite par le moteur OCR d'une image. |
## Interfaces

| Interface | Description |
| --- | --- |
| [IOcrConnector](./iocrconnector) | Définit les méthodes nécessaires pour appliquer des rédactions textuelles aux documents image et aux images intégrées. |
