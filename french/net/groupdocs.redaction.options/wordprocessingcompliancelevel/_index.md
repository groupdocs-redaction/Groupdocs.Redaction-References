## WordProcessingComplianceLevel enumeration

Représente les niveaux de conformité OOXML pris en charge pour les documents de traitement de texte. Le niveau de conformité Strict ne peut être rétrogradé qu'en Transitional, pas en Ecma.

```csharp
public enum WordProcessingComplianceLevel
```

### Valeurs

| Nom | Valeur | Description |
| --- | --- | --- |
| Ecma | `0` | Spécifie le niveau de conformité ECMA-376 1re édition, 2006. |
| Transitional | `1` | Spécifie le niveau de conformité ISO/IEC 29500:2008 Transitional. |
| Strict | `2` | Spécifie le niveau de conformité Strict ISO/IEC 29500:2008. |
