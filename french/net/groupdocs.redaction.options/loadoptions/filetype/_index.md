## LoadOptions.FileType property

Obtient ou définit le type de fichier à ouvrir.

```csharp
public FileType FileType { get; set; }
```

### Remarques

Lorsqu'il est défini sur une valeur différente de [`Unknown`](../../../groupdocs.redaction/filetype/unknown), GroupDocs.Redaction ignore la détection du type de fichier et utilise le type spécifié.
