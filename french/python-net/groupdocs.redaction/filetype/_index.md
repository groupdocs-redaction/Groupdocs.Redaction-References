## FileType class

Représente un type de fichier.

En savoir plus :
- https://docs.groupdocs.com/redaction/net/supported-document-formats/
- https://docs.groupdocs.com/redaction/net/get-supported-file-formats/
- https://docs.groupdocs.com/redaction/net/get-file-info/

Le type FileType expose les membres suivants :

### Méthodes
| Méthode | Description |
| :- | :- |
| [equals](/redaction/python-net/groupdocs.redaction/filetype/equals/#other) | Détermine si le FileType actuel est le même que l'objet FileType spécifié. |
| [equals](/redaction/python-net/groupdocs.redaction/filetype/equals/#obj) | Détermine si le [`FileType`](/redaction/python-net/groupdocs.redaction/filetype/) actuel est le même que l'objet spécifié. |
| [equals_file_type](/redaction/python-net/groupdocs.redaction/filetype/equals_file_type/) |  |
| [equals_object](/redaction/python-net/groupdocs.redaction/filetype/equals_object/) |  |
| [from_extension](/redaction/python-net/groupdocs.redaction/filetype/from_extension/#extension) | Mappe l'extension de fichier au type de fichier. |
| [get_hash_code](/redaction/python-net/groupdocs.redaction/filetype/get_hash_code/) | Renvoie le code de hachage pour l'objet [`FileType`](/redaction/python-net/groupdocs.redaction/filetype/) actuel. |
| [get_supported_file_types](/redaction/python-net/groupdocs.redaction/filetype/get_supported_file_types/) | Récupère les types de fichiers pris en charge. |
| [to_string](/redaction/python-net/groupdocs.redaction/filetype/to_string/) | Renvoie une chaîne qui représente l'objet actuel. |

### Propriétés
| Propriété | Description |
| :- | :- |
| [extension](/redaction/python-net/groupdocs.redaction/filetype/extension/) | Le suffixe du nom de fichier, incluant le point initial, par ex., ".doc". |
| [file_format](/redaction/python-net/groupdocs.redaction/filetype/file_format/) | Le nom du format de fichier, par exemple "Microsoft Word Document". |
