## RedactionResult class

Représente le résultat de l'opération de censure.

En savoir plus

- More details about redaction results: https://docs.groupdocs.com/redaction/net/redaction-basics/

Le type RedactionResult expose les membres suivants:

### Méthodes
| Méthode | Description |
| :- | :- |
| [failed](/redaction/python-net/groupdocs.redaction/redactionresult/failed/#description) | Initialise une nouvelle instance de RedactionResult avec un statut échoué. |
| [partial](/redaction/python-net/groupdocs.redaction/redactionresult/partial/#description) | Crée une nouvelle instance [`RedactionResult`](/redaction/python-net/groupdocs.redaction/redactionresult/) avec un statut partiellement appliqué. |
| [skipped](/redaction/python-net/groupdocs.redaction/redactionresult/skipped/#description) | Initialise une nouvelle instance de la classe RedactionResult avec le statut Ignoré. |
| [successful](/redaction/python-net/groupdocs.redaction/redactionresult/successful/) | Initialise une nouvelle instance de RedactionResult avec un statut appliqué (réussi). |
