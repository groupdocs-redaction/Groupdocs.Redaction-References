## Metered class

Gère la licence à la consommation (pay-per-use).

Les licences Metered facturent en fonction de la consommation réelle (généralement les pages ou
les documents traités). Définissez la paire de clés publique/privée une fois à
le démarrage de l'application ; le wrapper rapporte l'utilisation au GroupDocs
serveur de licence en arrière-plan.

Le type Metered expose les membres suivants :

### Méthodes
| Méthode | Description |
| :- | :- |
| [get_consumption_credit](/redaction/python-net/groupdocs.redaction/metered/get_consumption_credit/) | Retourner le crédit mesuré restant pour la clé actuelle. |
| [get_consumption_quantity](/redaction/python-net/groupdocs.redaction/metered/get_consumption_quantity/) | Retourner la quantité mesurée totale consommée jusqu'à présent. |
| [set_metered_key](/redaction/python-net/groupdocs.redaction/metered/set_metered_key/#public_key-private_key) | Activer la facturation mesurée avec la paire de clés publique/privée fournie. |
