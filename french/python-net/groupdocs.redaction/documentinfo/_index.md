## DocumentInfo class

Représente des informations sur un document.

En savoir plus :

- Get file info: https://docs.groupdocs.com/redaction/net/get-file-info/

Le type DocumentInfo expose les membres suivants :

### Propriétés
| Propriété | Description |
| :- | :- |
| [file_type](/redaction/python-net/groupdocs.redaction/documentinfo/file_type/) | La description du format de fichier. |
| [page_count](/redaction/python-net/groupdocs.redaction/documentinfo/page_count/) | Le nombre total de pages. |
| [pages](/redaction/python-net/groupdocs.redaction/documentinfo/pages/) | La liste des informations de page [`PageInfo`](/redaction/python-net/groupdocs.redaction/pageinfo/). |
| [size](/redaction/python-net/groupdocs.redaction/documentinfo/size/) | La taille du document en octets. |
