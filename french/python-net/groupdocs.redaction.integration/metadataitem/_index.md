## MetadataItem class

Représente un élément de métadonnées, commun à tous les formats pris en charge et utilisé dans les censures de métadonnées.

Le type MetadataItem expose les membres suivants:

### Constructeurs
| Constructeur | Description |
| :- | :- |
| [__init__](/redaction/python-net/groupdocs.redaction.integration/metadataitem/__init__/) | Initialise une nouvelle instance. |

### Méthodes
| Méthode | Description |
| :- | :- |
| [create_clone](/redaction/python-net/groupdocs.redaction.integration/metadataitem/create_clone/) | Crée une copie profonde de l'instance actuelle. |
| [get_object_data](/redaction/python-net/groupdocs.redaction.integration/metadataitem/get_object_data/#info-context) | Renvoie des informations sur les propriétés sérialisables. |
| [get_object_data_serialization_info](/redaction/python-net/groupdocs.redaction.integration/metadataitem/get_object_data_serialization_info/) |  |

### Propriétés
| Propriété | Description |
| :- | :- |
| [actual_value](/redaction/python-net/groupdocs.redaction.integration/metadataitem/actual_value/) | La représentation sous forme de chaîne de la valeur de l'élément de métadonnées. |
| [category](/redaction/python-net/groupdocs.redaction.integration/metadataitem/category/) | La catégorie de l'élément de métadonnées, par exemple l'ID de ressource pour un élément de métadonnées de ressource intégrée. |
| [dictionary_key](/redaction/python-net/groupdocs.redaction.integration/metadataitem/dictionary_key/) | La clé du dictionnaire pour une [`MetadataCollection`](/redaction/python-net/groupdocs.redaction.integration/metadatacollection/), dérivée de son OriginalName et d'autres données. |
| [filter](/redaction/python-net/groupdocs.redaction.integration/metadataitem/filter/) | Le filtre attribué à cet élément de métadonnées, représenté par une valeur `MetadataFilters`, utilisé pour le filtrage des éléments. |
| [is_custom](/redaction/python-net/groupdocs.redaction.integration/metadataitem/is_custom/) | L'élément est personnalisé (ajouté par les auteurs du document). |
| [original_name](/redaction/python-net/groupdocs.redaction.integration/metadataitem/original_name/) | Le nom original de l'élément de métadonnées tel qu'il apparaît dans le document. |
| [values](/redaction/python-net/groupdocs.redaction.integration/metadataitem/values/) | La valeur de l'élément de métadonnées. |
