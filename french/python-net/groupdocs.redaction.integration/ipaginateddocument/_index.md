## IPaginatedDocument class

Définit les méthodes requises pour manipuler les pages d'un document. Doit être implémentée par une classe dérivée de [`DocumentFormatInstance`](/redaction/python-net/groupdocs.redaction.integration/documentformatinstance/) pour effectuer les redactions de pages.

- More details about applying redactions: https://docs.groupdocs.com/redaction/net/redaction-basics/
- More details about manipulating pages: https://docs.groupdocs.com/redaction/net/remove-page-redaction/

Le type IPaginatedDocument expose les membres suivants:

### Méthodes
| Méthode | Description |
| :- | :- |
| [remove_pages](/redaction/python-net/groupdocs.redaction.integration/ipaginateddocument/remove_pages/#origin-index-count) | Supprime une ou plusieurs pages en fonction de sa position de départ, de son décalage et de son nombre. |
| [remove_pages_page_seek_origin](/redaction/python-net/groupdocs.redaction.integration/ipaginateddocument/remove_pages_page_seek_origin/) |  |
