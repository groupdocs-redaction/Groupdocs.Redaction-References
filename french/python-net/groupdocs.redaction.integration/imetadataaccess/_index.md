## IMetadataAccess class

Définit les méthodes requises pour accéder aux métadonnées d'un document, si le format les prend en charge.

En savoir plus

- More details about applying redactions: https://docs.groupdocs.com/redaction/net/redaction-basics/
- More details about document metadata redactions: https://docs.groupdocs.com/redaction/net/metadata-redactions/
- More details about implementing custom formats: https://docs.groupdocs.com/redaction/net/create-custom-format-handler/

Le type IMetadataAccess expose les membres suivants:

### Méthodes
| Méthode | Description |
| :- | :- |
| [change_metadata](/redaction/python-net/groupdocs.redaction.integration/imetadataaccess/change_metadata/#metadata_item) | Modifie l’élément de métadonnées spécifié provenant de [`MetadataCollection`](/redaction/python-net/groupdocs.redaction.integration/metadatacollection/) ou en ajoute un nouveau s’il n’est pas présent. |
| [change_metadata_metadata_item](/redaction/python-net/groupdocs.redaction.integration/imetadataaccess/change_metadata_metadata_item/) |  |
| [get_metadata](/redaction/python-net/groupdocs.redaction.integration/imetadataaccess/get_metadata/) | Récupère un dictionnaire contenant les métadonnées du document. |
