## CellFilter class

Fournit une option pour limiter la portée d'un [`CellColumnRedaction`](/redaction/python-net/groupdocs.redaction.redactions/cellcolumnredaction/) à une feuille de calcul et à une colonne.

En savoir plus

- More details about spreadsheet redactions: https://docs.groupdocs.com/redaction/net/spreadsheet-redactions/

Le type CellFilter expose les membres suivants :

### Constructeurs
| Constructeur | Description |
| :- | :- |
| [__init__](/redaction/python-net/groupdocs.redaction.redactions/cellfilter/__init__/) | Initialise une nouvelle instance de CellFilter. |

### Propriétés
| Propriété | Description |
| :- | :- |
| [column_index](/redaction/python-net/groupdocs.redaction.redactions/cellfilter/column_index/) | L’indice de colonne basé sur zéro. |
| [has_work_sheet_index](/redaction/python-net/groupdocs.redaction.redactions/cellfilter/has_work_sheet_index/) | La propriété indique si le WorkSheetIndex est défini. |
| [work_sheet_index](/redaction/python-net/groupdocs.redaction.redactions/cellfilter/work_sheet_index/) | L’indice de feuille de calcul (basé sur zéro). |
| [work_sheet_name](/redaction/python-net/groupdocs.redaction.redactions/cellfilter/work_sheet_name/) | Le nom de la feuille de calcul, le cas échéant. |
