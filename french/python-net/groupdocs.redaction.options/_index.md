Classes d'options pour configurer les conversions et les opérations.

### Classes
| Classe | Description |
| :- | :- |
| [`CreatePageStream`](/redaction/python-net/groupdocs.redaction.options/createpagestream/) | Représente une méthode qui renvoie un flux pour écrire les données d'aperçu de page. |
| [`ILogger`](/redaction/python-net/groupdocs.redaction.options/ilogger/) | Définit une interface pour un journaliseur utilisé pour enregistrer les événements et les erreurs pendant la censure. |
| [`LoadOptions`](/redaction/python-net/groupdocs.redaction.options/loadoptions/) | Fournit des options qui seront utilisées pour ouvrir un fichier. |
| [`PreviewOptions`](/redaction/python-net/groupdocs.redaction.options/previewoptions/) | Fournit des options pour définir les exigences et les délégués de flux pour la génération d'aperçus. |
| [`RasterizationOptions`](/redaction/python-net/groupdocs.redaction.options/rasterizationoptions/) | Fournit des options pour convertir des fichiers en PDF. |
| [`RedactorSettings`](/redaction/python-net/groupdocs.redaction.options/redactorsettings/) | Représente les paramètres de censure, permettant de personnaliser le processus de censure. |
| [`ReleasePageStream`](/redaction/python-net/groupdocs.redaction.options/releasepagestream/) | Représente une méthode qui libère un flux créé par le délégué [`CreatePageStream`](/redaction/python-net/groupdocs.redaction.options/createpagestream/). |
| [`SaveOptions`](/redaction/python-net/groupdocs.redaction.options/saveoptions/) | Fournit des options pour modifier le nom du fichier de sortie et/ou convertir le document en PDF basé sur image (rasterisation). |
