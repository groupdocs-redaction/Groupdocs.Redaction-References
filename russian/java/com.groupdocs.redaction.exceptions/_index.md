Пакет предоставляет различные классы исключений.



## Классы

| Класс | Описание |
| --- | --- |
| [DocumentFormatException](../com.groupdocs.redaction.exceptions/documentformatexception) | Исключение, которое выбрасывается, когда формат документа не распознан или недействителен. |
| [GroupDocsRedactionException](../com.groupdocs.redaction.exceptions/groupdocsredactionexception) | Представляет базовое исключение для всех **GroupDocs.Redaction** исключений. |
| [IncorrectPasswordException](../com.groupdocs.redaction.exceptions/incorrectpasswordexception) | Исключение, которое выбрасывается, когда указанный пароль неверен. |
| [PasswordRequiredException](../com.groupdocs.redaction.exceptions/passwordrequiredexception) | Исключение, которое выбрасывается, когда для загрузки документа требуется пароль. |
| [TrialLimitationsException](../com.groupdocs.redaction.exceptions/triallimitationsexception) | Исключение, которое выбрасывается, когда пользователь нарушает ограничения пробного режима. |
