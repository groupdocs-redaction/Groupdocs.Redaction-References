Пакет предоставляет классы конфигурации форматов документов.



## Классы

| Класс | Описание |
| --- | --- |
| [DocumentFormatConfiguration](../com.groupdocs.redaction.configuration/documentformatconfiguration) | Представляет ссылку на тип для класса, наследующего DocumentFormatInstance, и список поддерживаемых расширений файлов для более быстрого определения формата. |
| [RedactorConfiguration](../com.groupdocs.redaction.configuration/redactorconfiguration) | Обеспечивает доступ к списку поддерживаемых форматов, встроенных и пользовательских. |
