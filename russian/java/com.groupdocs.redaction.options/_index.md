Пакет предоставляет классы параметров загрузки и сохранения.



## Классы

| Класс | Описание |
| --- | --- |
| [LoadOptions](../com.groupdocs.redaction.options/loadoptions) | Предоставляет параметры, которые будут использоваться для открытия файла. |
| [PreviewOptions](../com.groupdocs.redaction.options/previewoptions) | Предоставляет параметры для установки требований и делегатов потоков для генерации предварительного просмотра. |
| [RasterizationOptions](../com.groupdocs.redaction.options/rasterizationoptions) | Предоставляет параметры для преобразования файлов в PDF. |
| [RedactorSettings](../com.groupdocs.redaction.options/redactorsettings) | Представляет настройки редактирования, позволяющие настраивать процесс редактирования. |
| [SaveOptions](../com.groupdocs.redaction.options/saveoptions) | Предоставляет параметры для изменения имени выходного файла и/или преобразования документа в PDF на основе изображений (растеризация). |
| [WordprocessingSaveOptions](../com.groupdocs.redaction.options/wordprocessingsaveoptions) | Параметры сохранения обработки текста. |

## Интерфейсы

| Интерфейс | Описание |
| --- | --- |
| [ICreatePageStream](../com.groupdocs.redaction.options/icreatepagestream) | Предоставляет метод, возвращающий поток для записи данных предварительного просмотра страниц. |
| [ILogger](../com.groupdocs.redaction.options/ilogger) | Определяет интерфейс логгера, который может использоваться для регистрации событий и ошибок в процессе редактирования. |
| [IReleasePageStream](../com.groupdocs.redaction.options/ireleasepagestream) | Представляет метод, который освобождает поток, созданный делегатом CreatePageStream. |
