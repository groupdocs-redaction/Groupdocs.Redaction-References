Перечисление для управления расширенными параметрами растеризации, которые будут применяться.

## Поля

| Поле | Описание |
| --- | --- |
|  | [Tilt](#Tilt) | Наклонить растровое изображение под случайным углом. |
|
|  | [Noise](#Noise) | Добавить случайные пятна к растровым изображениям страниц. |
|
|  | [Border](#Border) | Добавить границу, имитирующую эффект сканирования страницы. |
|
|  | [Grayscale](#Grayscale) | Сделать изображения страниц в градациях серого, имитируя сканирование в серых тонах. |
|
