## TextRedaction class

Представляет базовый абстрактный класс для редактирования текста документа.

Узнать больше

- More details about applying redactions: https://docs.groupdocs.com/redaction/net/redaction-basics/

| Метод | Описание |

| [apply_to](/redaction/python-net/groupdocs.redaction/redaction/apply_to/) | Применяет редактирование к заданному экземпляру формата. (унаследовано от [`Redaction`](/redaction/python-net/groupdocs.redaction/redaction/)) |
| [apply_to_document_format_instance](/redaction/python-net/groupdocs.redaction/redaction/apply_to_document_format_instance/) | (унаследовано от [`Redaction`](/redaction/python-net/groupdocs.redaction/redaction/)) |
