## CellFilter class

Предоставляет возможность ограничить область действия [`CellColumnRedaction`](/redaction/python-net/groupdocs.redaction.redactions/cellcolumnredaction/) листом и столбцом.

Узнать больше

- More details about spreadsheet redactions: https://docs.groupdocs.com/redaction/net/spreadsheet-redactions/

Тип CellFilter раскрывает следующие члены:

### Конструкторы
| Конструктор | Описание |
| :- | :- |
| [__init__](/redaction/python-net/groupdocs.redaction.redactions/cellfilter/__init__/) | Инициализирует новый экземпляр CellFilter. |

### Свойства
| Свойство | Описание |
| :- | :- |
| [column_index](/redaction/python-net/groupdocs.redaction.redactions/cellfilter/column_index/) | Индекс столбца, начиная с нуля. |
| [has_work_sheet_index](/redaction/python-net/groupdocs.redaction.redactions/cellfilter/has_work_sheet_index/) | Свойство указывает, установлен ли WorkSheetIndex. |
| [work_sheet_index](/redaction/python-net/groupdocs.redaction.redactions/cellfilter/work_sheet_index/) | Индекс листа (нумерация с нуля). |
| [work_sheet_name](/redaction/python-net/groupdocs.redaction.redactions/cellfilter/work_sheet_name/) | Имя листа, если применимо. |

### Поля
