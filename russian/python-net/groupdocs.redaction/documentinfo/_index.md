## DocumentInfo class

Представляет информацию о документе.

Узнать больше:

- Get file info: https://docs.groupdocs.com/redaction/net/get-file-info/

Тип DocumentInfo раскрывает следующие члены:

### Свойства
| Свойство | Описание |
| :- | :- |
| [file_type](/redaction/python-net/groupdocs.redaction/documentinfo/file_type/) | Описание формата файла. |
| [page_count](/redaction/python-net/groupdocs.redaction/documentinfo/page_count/) | Общее количество страниц. |
| [pages](/redaction/python-net/groupdocs.redaction/documentinfo/pages/) | Список информации о страницах [`PageInfo`](/redaction/python-net/groupdocs.redaction/pageinfo/). |
| [size](/redaction/python-net/groupdocs.redaction/documentinfo/size/) | Размер документа в байтах. |
