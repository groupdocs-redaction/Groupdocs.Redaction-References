## FileType class

Представляет тип файла.

Узнать больше:
- https://docs.groupdocs.com/redaction/net/supported-document-formats/
- https://docs.groupdocs.com/redaction/net/get-supported-file-formats/
- https://docs.groupdocs.com/redaction/net/get-file-info/

Тип FileType раскрывает следующие члены:

### Методы
| Метод | Описание |
| :- | :- |
| [equals](/redaction/python-net/groupdocs.redaction/filetype/equals/#other) | Определяет, является ли текущий FileType тем же, что и указанный объект FileType. |
| [equals](/redaction/python-net/groupdocs.redaction/filetype/equals/#obj) | Определяет, является ли текущий [`FileType`](/redaction/python-net/groupdocs.redaction/filetype/) тем же, что и указанный объект. |
| [equals_file_type](/redaction/python-net/groupdocs.redaction/filetype/equals_file_type/) |  |
| [equals_object](/redaction/python-net/groupdocs.redaction/filetype/equals_object/) |  |
| [from_extension](/redaction/python-net/groupdocs.redaction/filetype/from_extension/#extension) | Отображает расширение файла на тип файла. |
| [get_hash_code](/redaction/python-net/groupdocs.redaction/filetype/get_hash_code/) | Возвращает хеш-код для текущего [`FileType`](/redaction/python-net/groupdocs.redaction/filetype/) объекта. |
| [get_supported_file_types](/redaction/python-net/groupdocs.redaction/filetype/get_supported_file_types/) | Получает поддерживаемые типы файлов. |
| [to_string](/redaction/python-net/groupdocs.redaction/filetype/to_string/) | Возвращает строку, представляющую текущий объект. |

### Свойства
| Свойство | Описание |
| :- | :- |
| [extension](/redaction/python-net/groupdocs.redaction/filetype/extension/) | Суффикс имени файла, включая начальную точку, например, ".doc". |
| [file_format](/redaction/python-net/groupdocs.redaction/filetype/file_format/) | Название формата файла, например "Microsoft Word Document". |
