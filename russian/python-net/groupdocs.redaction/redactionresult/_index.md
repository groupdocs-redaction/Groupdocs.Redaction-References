## RedactionResult class

Представляет результат операции редактирования.

Узнать больше

- More details about redaction results: https://docs.groupdocs.com/redaction/net/redaction-basics/

Тип RedactionResult раскрывает следующие члены:

### Методы
| Метод | Описание |
| :- | :- |
| [failed](/redaction/python-net/groupdocs.redaction/redactionresult/failed/#description) | Инициализирует новый экземпляр RedactionResult со статусом «не удалось». |
| [partial](/redaction/python-net/groupdocs.redaction/redactionresult/partial/#description) | Создаёт новый экземпляр [`RedactionResult`](/redaction/python-net/groupdocs.redaction/redactionresult/) со статусом частично применённого. |
| [skipped](/redaction/python-net/groupdocs.redaction/redactionresult/skipped/#description) | Инициализирует новый экземпляр класса RedactionResult со статусом Skipped. |
| [successful](/redaction/python-net/groupdocs.redaction/redactionresult/successful/) | Инициализирует новый экземпляр RedactionResult со статусом applied (успешный). |
