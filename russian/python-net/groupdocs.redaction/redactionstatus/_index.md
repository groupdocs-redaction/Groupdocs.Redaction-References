## RedactionStatus class

Тип RedactionStatus раскрывает следующие члены:

### Поля
| Поле | Описание |
| :- | :- |
| [APPLIED](/redaction/python-net/groupdocs.redaction/redactionstatus/applied/) | Редактирование было полностью и успешно применено. |
| [PARTIALLY_APPLIED](/redaction/python-net/groupdocs.redaction/redactionstatus/partially_applied/) | Редактирование было применено только к части совпадений. |
| [SKIPPED](/redaction/python-net/groupdocs.redaction/redactionstatus/skipped/) | Редактирование было пропущено (не применено). |
| [FAILED](/redaction/python-net/groupdocs.redaction/redactionstatus/failed/) | Редактирование завершилось с исключением. |
