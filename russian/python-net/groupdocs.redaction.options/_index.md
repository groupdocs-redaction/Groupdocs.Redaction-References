Классы параметров для настройки конвертаций и операций.

### Классы
| Класс | Описание |
| :- | :- |
| [`CreatePageStream`](/redaction/python-net/groupdocs.redaction.options/createpagestream/) | Представляет метод, который возвращает поток для записи данных предварительного просмотра страницы. |
| [`ILogger`](/redaction/python-net/groupdocs.redaction.options/ilogger/) | Определяет интерфейс для логгера, используемого для записи событий и ошибок во время редактирования. |
| [`LoadOptions`](/redaction/python-net/groupdocs.redaction.options/loadoptions/) | Предоставляет параметры, которые будут использоваться для открытия файла. |
| [`PreviewOptions`](/redaction/python-net/groupdocs.redaction.options/previewoptions/) | Предоставляет параметры для установки требований и делегатов потоков при генерации предварительного просмотра. |
| [`RasterizationOptions`](/redaction/python-net/groupdocs.redaction.options/rasterizationoptions/) | Предоставляет параметры для конвертации файлов в PDF. |
| [`RedactorSettings`](/redaction/python-net/groupdocs.redaction.options/redactorsettings/) | Представляет настройки редактирования, позволяющие настроить процесс редактирования. |
| [`ReleasePageStream`](/redaction/python-net/groupdocs.redaction.options/releasepagestream/) | Представляет метод, который освобождает поток, созданный делегатом [`CreatePageStream`](/redaction/python-net/groupdocs.redaction.options/createpagestream/). |
| [`SaveOptions`](/redaction/python-net/groupdocs.redaction.options/saveoptions/) | Предоставляет параметры для изменения имени выходного файла и/или конвертации документа в PDF на основе изображений (растеризация). |
