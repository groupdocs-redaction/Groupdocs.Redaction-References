## AdvancedRasterizationOptions class

Тип AdvancedRasterizationOptions раскрывает следующие члены:

### Поля
| Поле | Описание |
| :- | :- |
| [NONE](/redaction/python-net/groupdocs.redaction.options/advancedrasterizationoptions/none/) | Нет продвинутых параметров для применения. |
| [TILT](/redaction/python-net/groupdocs.redaction.options/advancedrasterizationoptions/tilt/) | Наклонить растеризованное изображение под случайным углом. |
| [NOISE](/redaction/python-net/groupdocs.redaction.options/advancedrasterizationoptions/noise/) | Добавить случайные пятна к растеризованным изображениям страниц. |
| [BORDER](/redaction/python-net/groupdocs.redaction.options/advancedrasterizationoptions/border/) | Добавить границу, имитирующую эффект сканирования страницы. |
| [GRAYSCALE](/redaction/python-net/groupdocs.redaction.options/advancedrasterizationoptions/grayscale/) | Сделать изображения страниц черно‑белыми, имитируя сканирование в градациях серого. |
