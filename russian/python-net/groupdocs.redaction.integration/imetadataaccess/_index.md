## IMetadataAccess class

Определяет методы, необходимые для доступа к метаданным документа, если формат их поддерживает.

Узнать больше

- More details about applying redactions: https://docs.groupdocs.com/redaction/net/redaction-basics/
- More details about document metadata redactions: https://docs.groupdocs.com/redaction/net/metadata-redactions/
- More details about implementing custom formats: https://docs.groupdocs.com/redaction/net/create-custom-format-handler/

Тип IMetadataAccess предоставляет следующие члены:

### Методы
| Метод | Описание |
| :- | :- |
| [change_metadata](/redaction/python-net/groupdocs.redaction.integration/imetadataaccess/change_metadata/#metadata_item) | Изменяет указанный элемент метаданных из [`MetadataCollection`](/redaction/python-net/groupdocs.redaction.integration/metadatacollection/) или добавляет новый, если его нет. |
| [change_metadata_metadata_item](/redaction/python-net/groupdocs.redaction.integration/imetadataaccess/change_metadata_metadata_item/) |  |
| [get_metadata](/redaction/python-net/groupdocs.redaction.integration/imetadataaccess/get_metadata/) | Получает словарь с метаданными документа. |
