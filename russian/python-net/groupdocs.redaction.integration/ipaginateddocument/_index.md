## IPaginatedDocument class

Определяет методы, необходимые для манипулирования страницами документа. Должен быть реализован классом, производным от [`DocumentFormatInstance`](/redaction/python-net/groupdocs.redaction.integration/documentformatinstance/), для выполнения редактирования страниц.

- More details about applying redactions: https://docs.groupdocs.com/redaction/net/redaction-basics/
- More details about manipulating pages: https://docs.groupdocs.com/redaction/net/remove-page-redaction/

Тип IPaginatedDocument предоставляет следующие члены:

### Методы
| Метод | Описание |
| :- | :- |
| [remove_pages](/redaction/python-net/groupdocs.redaction.integration/ipaginateddocument/remove_pages/#origin-index-count) | Удаляет одну или несколько страниц в зависимости от их начальной позиции, смещения и количества. |
| [remove_pages_page_seek_origin](/redaction/python-net/groupdocs.redaction.integration/ipaginateddocument/remove_pages_page_seek_origin/) |  |
